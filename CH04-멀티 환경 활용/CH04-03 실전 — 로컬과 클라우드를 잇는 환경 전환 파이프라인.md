# CH04-03 실전 — 로컬과 클라우드를 잇는 환경 전환 파이프라인

## 📌 클립 정보
- **예상시간:** 14분
- **유형:** 화면 녹화 위주 (실전 실습)
- **준비물:** 깃허브 계정, 클로드 코드 API 키, 깃 CLI

---

## 환경 전환의 핵심 — 깃 (3분)

로컬에서 작업한 내용을 클라우드로 가져가는 방법이 필요합니다.
그 핵심이 깃입니다.

**예를 들면 이렇습니다.**

USB 드라이브로 파일을 옮기는 대신, 구글 드라이브를 쓰는 것과 같습니다.
어디서든 같은 파일을 최신 버전으로 열 수 있습니다.
클로드 코드 프로젝트도 깃으로 관리하면 환경 전환이 자유로워집니다.

환경 전환 워크플로 전체 흐름입니다.

```
[로컬 환경]
프로토타입 작성 → 테스트 →
git push

↓

[클라우드 환경, 코드스페이스]
git pull → 대용량 실행 →
결과 파일 생성 → git push

↓

[로컬 환경]
git pull → 결과 확인 → 리포트 작성
```

---

## 실전 워크플로 설계 (5분)

실제 마케팅 데이터 분석 시나리오로 진행합니다.

**시나리오:**
- 로컬에 소규모 샘플 데이터가 있습니다
- 로컬에서 에이전트 파이프라인을 프로토타입으로 만듭니다
- 클라우드에서 전체 데이터(1년치 12개 파일)를 처리합니다
- 결과를 로컬로 가져와서 리포트를 완성합니다

**1단계: 로컬 프로토타입 (클로드에게 지시)**

```bash
cd ~/my-analysis
claude
```

> "data/raw/sample.csv를 읽어서 채널별 알오아이를 계산하는 파이썬 스크립트를 scripts/analyze.py에 작성해줘. 결과는 data/output/result.json으로 저장."

스크립트가 완성되면 깃에 올립니다.

```bash
git add .
git commit -m "add analysis script"
git push
```

**2단계: 클라우드에서 전체 데이터 처리**

코드스페이스 터미널에서 진행합니다.

```bash
git pull
# 전체 씨에스브이 파일 업로드 (data/raw/ 폴더에)
claude
```

> "data/raw/ 폴더에 있는 씨에스브이 파일 전체를 서브에이전트로 병렬 처리해줘. scripts/analyze.py 로직 적용해서 각각 결과를 data/output/ 에 저장하고, 전체 통합 리포트를 reports/final_report.md에 작성해줘."

처리가 완료되면 결과를 올립니다.

```bash
git add .
git commit -m "add full analysis results"
git push
```

**3단계: 로컬에서 결과 확인**

```bash
git pull
# data/output/ 과 reports/ 폴더 확인
```

## 환경별 CLAUDE.md 분리 전략 (3분)

로컬과 클라우드 환경에 따라 에이전트 지시가 달라질 수 있습니다.

프로젝트 루트의 `CLAUDE.md`는 공통 규칙을 담습니다.
환경별 지시는 별도 파일로 분리합니다.

```
my-analysis/
├── CLAUDE.md           ← 공통 규칙
├── CLAUDE.local.md     ← 로컬 전용 지시 (gitignore에 추가)
└── CLAUDE.cloud.md     ← 클라우드 전용 지시
```

`CLAUDE.local.md` 예시:
```markdown
## 로컬 환경 규칙
- 샘플 데이터만 처리합니다 (data/raw/sample.csv)
- 처리 속도보다 정확성을 우선합니다
- 결과 검토를 위해 중간 결과물도 저장합니다
```

`CLAUDE.cloud.md` 예시:
```markdown
## 클라우드 환경 규칙
- data/raw/ 전체 파일을 처리합니다
- 서브에이전트를 최대한 활용해 병렬 처리합니다
- 처리 시간 최소화를 우선합니다
```

환경에 맞는 파일을 `CLAUDE.md`에 포함해서 실행합니다.

## 직접 해보기

**목표**: 로컬→깃허브→코드스페이스 전체 흐름을 경험합니다.

**로컬 단계 (터미널에 복붙)**
```bash
mkdir ~/pipeline-test && cd ~/pipeline-test
git init
mkdir -p data/raw data/output scripts
printf "채널,지출,전환\nSNS,1000000,150\n검색,800000,200\n디스플레이,500000,80" > data/raw/sample.csv
claude
```

**클로드에게 이렇게 말합니다**
```
data/raw/sample.csv를 읽어서 채널별 알오아이를 계산해줘.
알오아이 = (전환 × 50000 - 지출) / 지출 × 100
결과를 data/output/roi_result.json으로 저장하고
계산 로직을 scripts/calc_roi.py 로도 저장해줘.
```

**깃 동기화**
```bash
git add .
git commit -m "add roi analysis"
git push origin main   # 깃허브 레포 연결 후
```

→ 코드스페이스에서 `git pull`로 가져와서 전체 데이터에 동일하게 실행합니다.
