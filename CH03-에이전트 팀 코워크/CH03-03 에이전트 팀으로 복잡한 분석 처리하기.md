# CH03-03 에이전트 팀으로 복잡한 분석 처리하기

## 📌 클립 정보
- **예상시간:** 17분
- **유형:** 슬라이드 2장 + 화면 녹화 (실습 위주)
- **준비물:** CH03-02에서 작성한 클로드엠디, 샘플 마케팅 데이터

---

## 실습 시나리오 (2분)

**[화면: 파이프라인 도식]**

이번 실습은 3단계 마케팅 분석 파이프라인입니다.

```
1단계: 데이터 분석 에이전트
   → 5개 캠페인 씨에스브이 분석
   → 채널별 전환율, 알오아이 계산
   → output/analysis/에 결과 저장

2단계: 인사이트 에이전트
   → 분석 결과를 비즈니스 맥락으로 해석
   → 상위/하위 캠페인 이유 분석
   → output/insights/에 해석 저장

3단계: 리포트 에이전트
   → 마케팅팀 전달용 문서 작성
   → 수치 + 해석 + 다음 액션 포함
   → output/reports/에 최종 리포트 저장
```

---

## 실행 과정 상세 (10분)

**[화면: 터미널]**

프로젝트 폴더에서 클로드 코드를 시작합니다.

```bash
claude
```

지시합니다.

> "클로드엠디에 정의된 3-에이전트 팀 구조로 마케팅 분석을 실행해줘. 1단계 완료 확인 후 2단계, 2단계 완료 확인 후 3단계를 순서대로 진행해줘. 각 단계에서 오류가 나면 즉시 알려줘."

**1단계 실행 과정**

오케스트레이터가 1단계를 시작합니다.
데이터 분석 에이전트 Task를 생성합니다.

```
> [1단계] 데이터 분석 에이전트 시작
> campaign_a.csv 로딩...
> campaign_b.csv 로딩...
> 전환율 계산 완료
> 알오아이 계산 완료
> output/analysis/analysis_result.json 저장 완료
> [1단계] 완료 ✓
```

결과 파일 확인 후 2단계로 넘어갑니다.

**2단계 실행 과정**

```
> [2단계] 인사이트 에이전트 시작
> analysis_result.json 로딩...
> 패턴 분석 중...
> 캠페인 D 고성과 요인: 소셜 채널 집중 + 시즌 타이밍
> 캠페인 C 저성과 요인: 타겟 세그먼트 불일치
> output/insights/insights.md 저장 완료
> [2단계] 완료 ✓
```

**3단계 실행 과정**

```
> [3단계] 리포트 에이전트 시작
> 분석 결과 + 인사이트 통합 중...
> 마케팅팀 리포트 작성 중...
> output/reports/final_report.md 저장 완료
> [3단계] 완료 ✓
> 전체 파이프라인 완료
```

**[화면: 최종 리포트 내용]**

생성된 리포트를 확인합니다.

## 중간 오류 대응 방법 (3분)

**[화면: 오류 상황 시나리오]**

2단계에서 오류가 발생하는 경우를 가정합니다.

```
> [2단계] 인사이트 에이전트 시작
> analysis_result.json 로딩...
> 오류: 'conversion_rate' 컬럼이 없습니다
> [2단계] 실패
```

이 경우 대응 방법입니다.

**방법 1 — 오류 원인 수정 후 재실행**

1단계 결과물을 확인합니다.
```
> "analysis_result.json 파일 내용을 보여줘. conversion_rate 컬럼이 있는지 확인해줘."
```

오류 원인을 발견하면 1단계를 재실행합니다.
```
> "1단계 데이터 분석 에이전트를 다시 실행해줘. 이번에는 conversion_rate 컬럼을 포함해서 저장해줘."
```

**방법 2 — 인사이트 에이전트에게 직접 수정 지시**

```
> "2단계 인사이트 에이전트에게 conversion_rate 대신 conversions / clicks로 계산해서 사용하도록 수정하고 재실행해줘."
```

각 단계가 독립적이므로 오류가 난 단계만 재실행하면 됩니다.
전체를 처음부터 다시 시작할 필요가 없습니다.

---

## 직접 해보기

**목표**: 3단계 파이프라인 실행 중 중간 결과물을 직접 확인합니다.

**클로드에게 이렇게 말합니다**
```
CLAUDE.md에 정의된 팀 구조로 분석을 실행해줘.
1단계 완료 후 결과를 보여주고, 계속할지 확인해줘.
```

→ 1단계 결과를 확인하고 "계속해줘" 입력.
→ 2단계 결과 확인 후 "계속해줘" 입력.
→ 단계별로 검토하면서 진행하는 패턴을 익힙니다.

**오류 시 재실행**
```
2단계에서 오류가 났어. 2단계만 다시 실행해줘.
```

## 핵심 정리 (1분)

에이전트 팀 파이프라인은 각 단계 완료 후 다음 단계로 넘어가는 방식입니다.
중간 오류는 해당 단계만 수정해서 재실행하면 됩니다.
단계별 결과물을 파일로 저장하기 때문에 어느 지점에서든 재시작이 가능합니다.
