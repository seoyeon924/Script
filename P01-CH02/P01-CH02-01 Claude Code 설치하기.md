## [슬라이드 s4 — Claude 플랜 구매]

설치 전에 플랜 얘기를 먼저 해야 해요. 클로드코드는 claude.ai 구독이 있어야 쓸 수 있거든요.

플랜은 세 가지예요. Pro $20, Max $100, Max $200.

Pro $20은 체험용이라고 보시면 됩니다. 집중해서 작업하면 1시간 내로 한도가 차요. 강의 들으면서 실습하다 보면 금방 막히는 경우가 생겨서, 본격적으로 쓸 거라면 솔직히 추천하긴 어렵습니다.

저희가 권장하는 건 Max $100이에요. Pro 대비 사용량이 5배고, 멀티세션이나 에이전트팀 같은 기능도 제대로 쓸 수 있고, Opus 모델도 활용할 수 있거든요. 이 강의에서 다루는 데이터 시각화 작업 수준에서는 Max $100이면 충분합니다.

Max $200은 하루 종일 풀타임으로 쓰는 분들 대상이에요. Pro 대비 20배 사용량이고 제약 없이 풀 스펙으로 쓸 수 있는 구간입니다.

운영체제는 macOS 13 이상, Windows 10 이상, Ubuntu 20.04 이상이면 됩니다.

---

## [슬라이드 s5 — macOS 설치]

macOS 먼저 보겠습니다.

터미널 열고 이 명령어를 그대로 붙여넣으세요.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Homebrew가 이미 설치되어 있으시면 이 방법도 됩니다.

```bash
brew install --cask claude-code
```

설치가 끝나면 버전 확인해보세요.

```bash
claude --version
```

숫자가 나오면 설치 완료예요.

macOS 버전은 화면 왼쪽 위 사과 → 이 Mac에 관하여에서 확인하실 수 있어요.

## [슬라이드 s6 — Windows 설치]

Windows는 PowerShell을 관리자 권한으로 열고 실행합니다.

```powershell
irm https://claude.ai/install.ps1 | iex
```

winget으로도 됩니다.

```powershell
winget install Anthropic.ClaudeCode
```

설치 후 똑같이 버전 확인해보세요.

```
claude --version
```

## [슬라이드 s7 — 브라우저 로그인]

설치 후 처음 `claude`를 실행하면 브라우저가 자동으로 열려요.

claude.ai 계정으로 로그인하면 인증이 완료되고, 터미널로 돌아오면 프롬프트가 활성화됩니다.

로그인 확인 겸 첫 번째 명령을 해봅니다.

```
현재 폴더 경로를 알려줘.
```

경로가 출력되면 클로드코드가 정상 동작하는 거예요.

## [슬라이드 s8 — 설치가 안 될 때]

설치하다 막히는 경우가 있는데, 세 가지만 알아두시면 됩니다.

**케이스 01 — "command not found" 오류**

PATH 설정이 안 된 경우예요. 터미널을 닫고 다시 열어보고, 그래도 안 되면 이걸 실행해보세요.

```bash
source ~/.zshrc
```

**케이스 02 — 로그인이 안 되는 경우**

네트워크 문제일 수 있어요. `claude doctor` 명령으로 진단할 수 있습니다.

```bash
claude doctor
```

**케이스 03 — Windows에서 Git이 없다는 오류**

클로드코드는 로컬 세션 실행에 Git이 필요해요. git-scm.com에서 Git for Windows를 설치하고 다시 시도해보세요.

## [슬라이드 s9 — 보안 기초 규칙]

클로드코드 쓰기 전에 기본 수칙 네 가지만 짚고 넘어가겠습니다. 클로드코드는 파일 시스템에 직접 접근하는 도구라서 이 부분은 꼭 알고 계셔야 해요.

**첫 번째, API 키나 비밀번호 같은 민감한 정보는 채팅창에 직접 입력하지 마세요.**

AWS 키, DB 비밀번호, 개인 인증서 같은 건 절대 채팅창에 붙여넣지 않는 거예요. 환경변수나 .env 파일로 따로 관리하는 게 맞습니다.

**두 번째, sudo 권한을 요청하면 이유를 먼저 파악하세요.**

시스템 파일을 수정하거나 관리자 권한을 요청할 때는, 왜 필요한지 확인하고 허용 여부를 판단해야 합니다.

**세 번째, `--dangerously-skip-permissions` 옵션은 격리 환경 외에는 쓰지 마세요.**

이 옵션은 모든 권한 확인을 생략하는 옵션이에요. 컨테이너 같은 격리된 환경에서만 쓰는 거고, 일반 작업 환경에서는 쓰지 않는 게 맞습니다.

**네 번째, 대규모 작업 전에는 반드시 백업을 먼저 하세요.**

리팩토링이나 DB 마이그레이션 같은 작업 전에는 `git commit`이나 별도 백업을 먼저 해두는 게 습관이 되어야 해요.

이 네 가지만 지켜도 클로드코드를 안전하게 쓸 수 있습니다.
