# P01-CH02-01 Claude Code 설치하기

## 📌 클립 정보
- **예상시간:** 10분
- **유형:** 슬라이드 + 화면녹화
- **준비물:** 맥 또는 윈도우 PC, claude.ai 계정 (Pro $20 또는 Max $100 구독)

## 오프닝

이번 챕터는 바이브코딩 환경 세팅입니다. 이번 파트에서는 드디어 클로드코드를 설치해보겠습니다. 저희가 강의 내내 쓸 환경을 지금 세팅해둔다고 보시면 됩니다.

저희는 안티그래비티 에디터 안에서 클로드코드를 쓸 예정인데요. 간혹 터미널에서 하는 게 작업이 편한 경우도 있고, 특정 작업은 터미널에서 해야 하기도 하구요. 저희는 데이터 시각화 작업 특성상 안티그래비티 에디터에서 쓰는 게 편하고, 입문자분들한테도 훨씬 편리하기 때문에 안티그래비티를 씁니다. 이 에디터는 꼭 안티그래비티일 필요는 없구요. 커서, VS Code 등 상관없습니다. 다만 이후 챕터에서 안티그래비티를 병행해서 쓰는 방법을 알려드릴 거기 때문에 안티그래비티를 쓴다고 봐주시면 됩니다.

그러면 바로 클로드코드 설치부터 시작하도록 하겠습니다.

---

## Claude Code가 뭔지 30초 정리

설치 전에 클로드코드가 정확히 뭔지만 짚고 넘어가겠습니다.

클로드코드는 AI 에이전트예요. 단순히 질문에 답하는 게 아니라, 내 컴퓨터 파일을 직접 읽고, 코드를 실행하고, 결과물을 저장합니다.

ChatGPT랑 뭐가 다르냐면요.

| | ChatGPT (웹) | Claude Code |
|--|--|--|
| 파일 처리 | 업로드한 파일만 | 폴더 전체를 자동으로 읽음 |
| 코드 실행 | 직접 안 함 | 내 컴퓨터에서 직접 실행 |
| 결과 저장 | 복사해서 붙여넣기 | 파일로 자동 저장 |
| 기억 | 대화가 끝나면 초기화 | CLAUDE.md로 영구 기억 |

CSV 파일을 주면 읽고, 분석하고, 차트 만들고, 저장까지 혼자 합니다. 그게 클로드코드예요.

---

## 설치 전 준비

두 가지만 확인합니다.

**1. claude.ai 계정**

Pro ($20/월) 또는 Max ($100/월) 구독이 필요합니다. Pro는 집중해서 작업하면 1~2시간이면 한도가 차요. 본격적으로 쓸 거라면 Max를 추천합니다. Max $100이 가장 균형이 좋아요.

**2. 운영체제 확인**
- macOS 13 (Ventura) 이상
- Windows 10 (64비트) 이상
- 리눅스는 Ubuntu 20.04 이상

macOS 버전은 왼쪽 상단 사과 → 이 Mac에 관하여에서 확인하실 수 있어요.

---

## 설치

### macOS

터미널을 열고 아래 명령어를 그대로 붙여넣습니다.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Homebrew가 설치되어 있으면 이 방법도 됩니다.

```bash
brew install --cask claude-code
```

설치가 끝나면 버전을 확인해보세요.

```bash
claude --version
```

숫자가 나오면 설치 완료예요.

### Windows

PowerShell을 관리자 권한으로 열고 실행합니다.

```powershell
irm https://claude.ai/install.ps1 | iex
```

또는 winget으로도 됩니다.

```powershell
winget install Anthropic.ClaudeCode
```

**주의:** 구글에 검색하다 보면 `npm install -g @anthropic-ai/claude-code` 이런 명령어가 나오는 블로그들이 있는데요. 이건 공식적으로 deprecated된 방법이에요. 지금 알려드린 방법으로 설치하세요.

## 로그인

설치 후 처음 `claude`를 실행하면 브라우저가 자동으로 열려요.

```bash
claude
```

claude.ai 계정으로 로그인하면 인증이 완료됩니다. 터미널로 돌아오면 프롬프트가 뜨면서 바로 사용 가능해요.

로그인 확인 겸, 간단한 첫 명령을 해봅니다.

```
현재 폴더 경로를 알려줘.
```

경로가 출력되면 클로드코드가 정상 동작하는 거예요.

---

## 설치가 안 될 때

**"command not found" 오류**

PATH 설정이 안 된 경우예요. 터미널을 닫고 다시 열거나, 아래를 실행해보세요.

```bash
source ~/.zshrc
```

**로그인이 안 되는 경우**

네트워크 문제일 수 있어요. claude doctor 명령으로 진단해보세요.

```bash
claude doctor
```
