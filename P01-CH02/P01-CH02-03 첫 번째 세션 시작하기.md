# P01-CH02-03 첫 번째 세션 시작하기

## 📌 클립 정보
- **예상시간:** 10분
- **유형:** 화면 녹화 (Antigravity 에디터)
- **준비물:** Claude Code + Antigravity 세팅 완료 (P01-CH02-02 선행)

---

## [슬라이드 s16 — 첫 번째 세션 시작하기]

이제 실제로 첫 번째 세션을 시작해보겠습니다.

클로드코드 채팅 패널에서 세션을 시작할 때, 프롬프트에 어디서 작업할지를 먼저 알려주는 게 좋아요. 폴더가 없으면 만들어달라고 하면 됩니다.

```
~/Desktop/data-viz-project 폴더 만들고, 지금부터 거기서 작업할게.
```

이렇게 하면 Claude가 폴더를 만들고, 이후 작업은 그 안에서 진행됩니다.

이제 테스트 두 가지를 해볼게요.

**테스트 1 — 데이터 파일 생성**

```
채널별 월매출 가짜 데이터 CSV 만들어줘.
컬럼: 월, 채널, 매출. 채널은 검색·소셜·이메일. 6개월치.
```

에디터 왼쪽 파일 탐색기에 CSV 파일이 생기면 1단계 완료입니다.

**테스트 2 — 차트 생성**

```
방금 만든 CSV 읽고 채널별 매출 바 차트 HTML 만들어줘.
```

HTML 파일을 열어서 차트가 나오면 세팅이 제대로 된 거예요.

---

## [슬라이드 s17 — 터미널 명령어 X / 자연어 O]

핵심 원칙 하나만 말씀드리겠습니다.

터미널 명령어를 외울 필요가 없어요. 채팅 패널에서 말로 하면 Claude가 알아서 실행합니다.

"data.csv 파일 읽고 채널별 합계 만들어줘"라고 말하면, 파이썬 코드를 직접 쓰고 실행까지 해요. 여러분이 파이썬을 몰라도 됩니다.

저희가 이 강의에서 주로 쓸 건 세 가지예요.
- 클로드코드 채팅 패널 — 작업 지시
- 에디터 — 파일 내용 확인
- 터미널 — 꼭 필요할 때만

터미널은 정말 가끔만 씁니다.

---

## 핵심 정리

폴더 생성부터 CSV → 차트까지, 첫 번째 세션을 완성했습니다.

앞으로 이 환경으로 데이터 시각화를 본격적으로 만들어보겠습니다.
