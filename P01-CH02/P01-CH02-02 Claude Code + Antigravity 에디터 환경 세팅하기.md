## [슬라이드 s19 — Google Antigravity 소개]

안티그래비티는 Google에서 만든 코드 에디터입니다.

저희가 이걸 쓰는 이유는 단순해요. 코드 에디터로 쓰면서 Claude Code 익스텐션을 연결하는 거예요. 에디터 안에서 클로드코드랑 채팅하고, 파일도 보고, 결과도 바로 확인하는 게 가능해서 데이터 시각화 작업에 딱 맞습니다.

무료로 제공되고, macOS랑 Windows 둘 다 됩니다.

---

## [슬라이드 s11 — AI 네이티브 코드 에디터]

안티그래비티는 AI 협업을 기본으로 설계된 에디터예요. VS Code랑 비슷하게 생겼는데 AI 기능이 기본으로 들어가 있어요.

저희가 안티그래비티를 쓰는 이유는 세 가지입니다.

**첫 번째, 에디터 안에서 클로드코드와 채팅합니다.**

오른쪽 패널에서 자연어로 요청하면 Claude가 파일을 읽고 수정하고 실행해요. 에디터 탭 여러 개 띄워놓고 파일도 바로바로 보고, 채팅도 하고, 결과를 바로 확인할 수 있습니다.

**두 번째, 파일 변경을 실시간 diff로 봅니다.**

Claude가 파일을 수정하면 에디터에서 diff 형태로 바로 보여요. 수정 내용을 눈으로 확인하면서 승인하거나 되돌릴 수 있습니다.

**세 번째, Pro/Max 구독으로 API 추가 비용 없이 씁니다.**

별도 API 키 없이 구독 내에서 사용할 수 있어요.

지원 환경은요:
- macOS: Apple Silicon (M1~M4), macOS 12 이상
- Windows: 10 64비트 이상
- Intel Mac은 지원하지 않습니다

---

## [슬라이드 s13 — Claude Code 익스텐션]

**[화면: Antigravity 에디터]**

안티그래비티가 실행됐으면, 클로드코드 익스텐션을 설치합니다.

**Step 1: 익스텐션 설치**

왼쪽 사이드바에서 퍼즐 조각 모양 익스텐션 아이콘을 클릭합니다. 검색창에 "Claude Code"를 입력하고, Install 버튼 클릭 후 Enable을 클릭하세요.

**Step 2: 계정 연결**

설치 후 익스텐션 패널 상단에 주황색 꽃 모양 아이콘이 생겨요. 클릭하면 "Connect Account" 버튼이 나타납니다.

클릭하면 브라우저가 열리면서 claude.ai 인증 화면이 나와요. 로그인 후 인증 코드를 복사해서 에디터로 돌아와 붙여넣으면 됩니다.

**Step 3: 연결 확인**

연결 완료 메시지가 뜨면 끝이에요.
