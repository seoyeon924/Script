# P01-CH02-02 Claude Code + Antigravity 에디터 환경 세팅하기

## 📌 클립 정보
- **예상시간:** 10분
- **유형:** 화면 녹화 (Antigravity 에디터)
- **준비물:** Claude Code 설치 완료 (P01-CH02-01 선행), claude.ai Pro 이상 구독

---

## 오프닝

이번 클립이 이 강의에서 가장 중요한 세팅입니다.

안티그래비티 에디터를 설치하고, 안에 클로드코드 익스텐션을 연결합니다. 이 환경이 갖춰지면 이후 모든 실습은 이 에디터 안에서 진행돼요.

잠깐, 안티그래비티가 뭔지부터 짚겠습니다.

---

## Antigravity란

안티그래비티는 AI 네이티브 코드 에디터예요. VS Code랑 비슷하게 생겼는데, AI와 협업을 기본으로 설계되어 있어요.

저희가 안티그래비티를 쓰는 이유는 세 가지입니다.

**첫 번째, 에디터 안에서 클로드코드와 채팅합니다.**

오른쪽 패널에서 자연어로 요청하면, Claude가 파일을 읽고 수정하고 실행해요. 에디터 탭 여러 개 띄워놓고 파일도 바로바로 보고, 채팅도 하고, 결과를 바로 확인할 수 있습니다.

**두 번째, 파일 변경을 실시간으로 봅니다.**

Claude가 파일을 수정하면 에디터에서 diff 형태로 바로 보여요. 수정 내용을 눈으로 확인하면서 승인하거나 되돌릴 수 있습니다.

**세 번째, Claude Pro/Max 구독으로 API 추가 비용 없이 씁니다.**

별도 API 키 없이 구독 내에서 사용할 수 있어요.

지원 환경은요:
- macOS: Apple Silicon (M1/M2/M3/M4), macOS 12 이상
- Windows: Windows 10 64비트 이상
- Intel Mac은 지원하지 않습니다

---

## Antigravity 설치

**[화면: 브라우저]**

`antigravity.google`에 접속합니다.

macOS 또는 Windows 버전을 내려받아 설치하세요.

macOS는 .dmg 파일 열고 Applications에 드래그하면 되고요. Windows는 .exe를 실행하면 됩니다.

---

## Claude Code 익스텐션 설치 및 연결

**[화면: Antigravity 에디터]**

안티그래비티가 실행됐으면, 클로드코드 익스텐션을 설치합니다.

**Step 1: 익스텐션 설치**

왼쪽 사이드바에서 퍼즐 조각 모양 익스텐션 아이콘을 클릭합니다. 검색창에 "Claude Code"를 입력하고, Install 버튼 클릭 후 Enable을 클릭하세요.

**Step 2: 계정 연결**

설치 후 익스텐션 패널 상단에 주황색 꽃 모양 아이콘이 생겨요. 클릭하면 "Connect Account" 버튼이 나타납니다.

클릭하면 브라우저가 열리면서 claude.ai 인증 화면이 나와요. 로그인 후 인증 코드를 복사해서 에디터로 돌아와 붙여넣으면 됩니다.

연결 완료 메시지가 뜨면 끝이에요.

---

## 작업 환경 구성

이제 실제로 쓸 레이아웃을 잡겠습니다.

**[화면: Antigravity 레이아웃]**

**Step 1: 프로젝트 폴더 열기**

File → Open Folder → 작업할 폴더를 선택합니다. 이 강의에서는 바탕화면에 `data-viz-project` 폴더를 만들어서 씁니다.

**Step 2: Claude Code 패널 열기**

오른쪽에 클로드코드 채팅 패널이 나타납니다. 이 패널이 우리의 주 작업 공간이에요.

**Step 3: 내장 터미널 열기 (필요할 때만)**

Ctrl + ` (백틱)으로 하단에 터미널이 열려요. Claude가 작업하는 모습을 볼 때, 또는 직접 명령어를 실행해야 할 때 씁니다.

저희가 쓸 기본 레이아웃은 이렇습니다.
- 왼쪽: 파일 탐색기 + 에디터
- 오른쪽: 클로드코드 채팅 패널
- 하단: 터미널 (필요 시)

---

## 첫 번째 대화 테스트

환경이 제대로 세팅됐는지 확인해볼게요.

오른쪽 클로드코드 패널에 이걸 입력해보세요.

```
안녕. 현재 열려 있는 폴더 이름을 알려줘.
```

폴더 이름이 나오면 정상이에요.

이번에는 파일을 만들어봅니다.

```
hello.txt 파일을 만들어줘. 내용은 "Claude Code + Antigravity 세팅 완료"라고 써줘.
```

에디터 왼쪽 파일 탐색기에 hello.txt가 생기면 환경 세팅이 완료된 거예요.

## 핵심 정리

앞으로 이 강의에서 쓸 환경입니다.

- **클로드코드 채팅 패널**: 자연어로 작업 지시
- **에디터**: 파일 내용 확인 및 검토
- **터미널**: 꼭 필요할 때만 사용

터미널 명령어를 외울 필요 없습니다. 채팅 패널에서 말하면 Claude가 알아서 실행해요.

다음 파트에서는 이 환경으로 첫 번째 데이터 시각화를 만들어보겠습니다.
