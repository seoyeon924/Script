# P01-CH02-02 Claude Code + Antigravity 에디터 환경 세팅하기

## 📌 클립 정보
- **예상시간:** 10분
- **유형:** 화면 녹화 (브라우저 + 에디터)
- **준비물:** 맥 애플 실리콘 (M1 이상), 클로드 프로 이상 구독

---

## 오프닝 (30초)

Antigravity는 구글이 만든 AI 코드 에디터입니다.
Claude Code와 함께 쓰면 API 토큰을 아끼면서 에디터와 터미널을 동시에 사용할 수 있습니다.

---

## Antigravity란 무엇인가 (2분)

에디터와 에이전트 매니저가 하나의 앱에 통합되어 있습니다.

**두 가지 장점:**

**API 토큰 절약입니다.**
Claude Pro 구독이 있으면 API 키 없이 연결됩니다.
토큰 사용량이 구독 내에 포함되어 별도 과금이 없습니다.

**에디터와 터미널 동시 사용입니다.**
왼쪽 터미널에서 Claude Code를 실행하고, 오른쪽 에디터에서 결과 파일을 바로 확인합니다.

**지원 환경:**
- 맥: 애플 실리콘(M1/M2/M3/M4), macOS 12 이상
- 윈도우: 윈도우 10 64비트 이상
- 인텔 맥: 지원하지 않습니다

---

## 설치 방법 (3분)

**[화면: 브라우저]**

`https://antigravity.google/download` 에 접속합니다.
맥 또는 윈도우 버전을 내려받아 설치합니다.

**Claude Code 익스텐션 설치:**

1. 왼쪽 사이드바 익스텐션 탭 클릭
2. "Claude" 검색 → 설치 → Enable
3. 주황 꽃 모양 아이콘 클릭 → Connect Account
4. 브라우저에서 claude.ai 인증 코드 복사 → 패널에 붙여넣기

---

## 터미널 + 에디터 분할 레이아웃 설정 (3분)

**[화면: Antigravity 분할 레이아웃]**

1. `File` → `Open Folder` → 프로젝트 폴더 선택
2. `Ctrl + \`` 로 내장 터미널 열기
3. 터미널 패널을 왼쪽으로 드래그 → 에디터 오른쪽 배치

**왼쪽**: 터미널 (Claude Code 실행)
**오른쪽**: 파일 편집기

터미널에서 `claude`를 실행하면 오른쪽 에디터에서 파일 변경이 실시간으로 표시됩니다.

---

## 핵심 정리 (30초)

Antigravity 설치 → 익스텐션에서 Claude 검색·설치·Enable → 주황 꽃 아이콘 → 계정 연결 순서입니다.
연결 후 내장 터미널에서 `claude` 실행하면 에디터와 동시에 사용할 수 있습니다.
이것으로 Part 01 바이브코딩 환경 세팅을 마칩니다.
