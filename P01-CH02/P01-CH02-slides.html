Claude Code 설치하기 9
사용 전 필독
보안 기초
규칙
Claude Code는 파일 시스템에 직접 접근 — 기본 수칙 숙지 필수
01 · 민감 정보 채팅창 입력 금지
API 키 · 비밀번호 · 개인 인증서 → 채팅창 직접 입력 금지
환경변수 또는 .env 파일 사용
# 이렇게 하지 말 것
내 AWS 키는 AKIA... DB 비밀번호는 pass123...
02 · sudo 권한 요청 — 이유 먼저 확인
시스템 파일 수정·관리자 권한 요청 시 → 이유 파악 후 허용 여부 판단
03 · --dangerously-skip-permissions 사용 주의
모든 권한 확인을 생략하는 옵션 — 컨테이너 등 격리 환경 외 사용 금지
04 · 대규모 작업 전 백업 선행
리팩토링 · DB 마이그레이션 전 → git commit 또는 별도 백업 필수
