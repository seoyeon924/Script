## 핵심 원칙

강의 스크립트는 번역체, 공문서체 금지. 실제 강의 현장에서 자연스럽게 말하는 한국어 구어체.

**Why:** 기존 스크립트가 "이번 파트에서는 Claude Code를 설치하고, 우리가 강의 내내 쓸 작업 환경을 세팅합니다" 처럼 딱딱하고 번역체가 강해 자연스럽지 않았음.

**How to apply:** 아래 규칙을 모든 스크립트 작성 시 적용.

---

## 발음·표기 규칙

- Claude Code → 클로드코드 (or 그대로 Claude Code도 OK, 혼용 가능)
- Antigravity → 안티그래비티
- Claude.ai → claude.ai (영문 그대로)
- Pro/Max 구독 → 그대로 영문 사용
- CLAUDE.md → 클로드 MD, 또는 CLAUDE.md 그대로

## 말투 스타일

### 1. 자연스러운 구어 어미
- "~다고 보시면 됩니다" — 설명할 때
- "~거든요" — 이유 설명할 때
- "~이거든요" / "~이에요" — 부드러운 강조
- "~구요" — 나열할 때
- "~잖아요" — 전제 공유할 때
- "~거예요" — 사실 설명
- "~하기도 하구요" — 예외/추가 설명
- "~다고 봐주시면 됩니다" — 권고/설명

### 2. 솔직하고 실용적인 말투
- 예외/제한 사항을 솔직하게 먼저 말하기: "간혹 ~경우도 있는데요"
- 선택지가 있을 때 이유도 함께: "꼭 ~일 필요는 없구요. 다만 ~기 때문에 ~를 씁니다"
- 추천의 이유를 명확히: "~분들한테 훨씬 편리하기 때문에"

### 3. 에너지 표현
- "드디어", "한번", "같이" — 시작할 때 에너지 추가
- "바로", "지금" — 행동 유도
- "그러면 바로 ~부터 시작하도록 하겠습니다" — 섹션 전환

### 4. 호칭
- "여러분" — 일반 호칭
- "저희" — our/we (not "우리" in formal context)
- "분들" — 수강자 지칭

### 5. 피해야 할 표현
- "이번 파트에서는 ~을 다룹니다" → "이번 파트에서는 ~해보겠습니다"
- "살펴보겠습니다" → "보겠습니다 / 알아보겠습니다 / 확인해보겠습니다"
- "진행합니다" → "해봅니다 / 시작합니다"
- "중요한 이야기를 먼저 하겠습니다" → 그냥 바로 말하기
- 딱딱한 나열 구조 → 이유와 맥락을 자연스럽게 섞기

## 슬라이드별 스크립트 구조

각 스크립트 파일은 슬라이드 ID로 섹션을 나눠야 함:

```
## [슬라이드 s1]
(타이틀 슬라이드 등장 - 나레이션)

---

## [슬라이드 s2 — 강사 소개]
...
```

슬라이드에 없는 내용은 스크립트에 추가하지 않음.
슬라이드 순서대로 작성 (ORDER 배열 기준).

## 예시 비교

**이전 (번역체):**
> 이번 파트에서는 Claude Code를 설치하고, 우리가 강의 내내 쓸 작업 환경을 세팅합니다. 여기서 중요한 이야기를 먼저 하겠습니다. 많은 분들이 Claude Code를 "터미널에서 쓰는 도구"로 알고 계세요. 맞습니다. 하지만 이 강의에서는 다르게 접근합니다.

**개선 (자연스러운 구어체):**
> 이번 파트에서는 드디어 클로드코드를 설치해보겠습니다. 저희가 강의 내내 쓸 환경을 지금 세팅해둔다고 보시면 됩니다. 저희는 안티그래비티 에디터 안에서 클로드코드를 쓸 예정인데요. 간혹 터미널에서 하는 게 편한 경우도 있고, 특정 작업은 터미널에서 해야 하기도 하구요. 다만 저희는 데이터 시각화 작업 특성상 안티그래비티 에디터에서 쓰는 게 편하고, 입문자분들한테도 훨씬 편리하기 때문에 안티그래비티를 씁니다.
