## A/B 테스트란 (4분)

**[화면: A/B 테스트 개념도]**

A/B 테스트는 두 가지 버전을 비교하는 실험입니다.

**예시:**
- 버튼 색상: 파란색(A) vs 초록색(B)
- 랜딩 페이지: 기존 디자인(A) vs 새 디자인(B)
- 이메일 제목: 짧은 버전(A) vs 긴 버전(B)

**목표:** 어떤 버전이 더 좋은 결과를 내는지 "증명"하는 것

**왜 필요한가:**
- 직감이 아닌 데이터로 의사결정
- "이게 더 나아 보여요"가 아닌 "이게 15% 더 좋습니다"
- 실제로 효과가 있는지 검증

---

## 통계적 유의성 (5분)

**[화면: 유의성 설명 다이어그램]**

"B가 A보다 전환율이 5% 높아요"

이게 정말 B가 더 좋은 걸까요, 아니면 우연일까요?

**통계적 유의성이 답을 줍니다.**

| p-value | 의미 | 판단 |
|---------|------|------|
| p < 0.05 | 우연일 확률 5% 미만 | ✅ 유의함 (B가 진짜 더 좋음) |
| p < 0.01 | 우연일 확률 1% 미만 | ✅✅ 매우 유의함 |
| p > 0.05 | 우연일 확률 5% 이상 | ❌ 유의하지 않음 (확신 못함) |

**비유하자면:**
동전을 10번 던져서 앞면이 7번 나왔다면, 이 동전이 조작된 걸까요?
통계적 유의성은 "이게 우연인지 아닌지"를 수치로 판단하게 해줍니다.

---

## 샘플 사이즈의 중요성 (3분)

**[화면: 샘플 사이즈 비교]**

같은 5% 차이라도 샘플 사이즈에 따라 결론이 달라집니다:

| 샘플 수 | A 전환율 | B 전환율 | 차이 | 유의한가? |
|---------|----------|----------|------|-----------|
| 100명 | 10% | 15% | +5% | ❌ 불확실 |
| 1,000명 | 10% | 15% | +5% | ⚠️ 아마도 |
| 10,000명 | 10% | 15% | +5% | ✅ 유의함 |

**결론:** 샘플이 많을수록 작은 차이도 감지할 수 있습니다.

## Claude Code로 유의성 계산 (4분)

**[화면: Claude Code 실행]**

복잡한 통계 공식을 외울 필요 없습니다. Claude Code가 계산해줍니다:

**클로드에게 이렇게 말합니다:**
```
A/B 테스트 결과 분석해줘:
- A 그룹: 5,000명 방문, 150명 전환 (3.0%)
- B 그룹: 5,000명 방문, 195명 전환 (3.9%)

통계적으로 유의한지 검정하고,
95% 신뢰구간도 계산해줘.
```

Claude Code의 답변:
```
📊 A/B 테스트 결과

전환율 차이: +0.9%p (B가 30% 더 높음)
p-value: 0.018 (< 0.05)
결론: ✅ 통계적으로 유의합니다.

95% 신뢰구간: B가 A보다 0.2%p ~ 1.6%p 높음
권장: B 버전을 적용하세요.
```

## 직접 해보기

**목표**: A/B 테스트 결과를 Claude Code로 분석합니다.

**터미널에서 실행**
```bash
claude
```

**클로드에게 이렇게 말합니다**
```
내 A/B 테스트 결과야:
- 기존 페이지(A): 방문 8,000명, 구매 240명
- 새 페이지(B): 방문 8,000명, 구매 296명

1. 각각 전환율 계산해줘
2. 통계적으로 유의한지 검정해줘
3. B를 적용해도 될지 추천해줘
```

→ 통계 분석 결과와 함께 의사결정 추천을 받습니다.

## 핵심 정리 (1분)

A/B 테스트는 두 버전을 비교해서 더 나은 것을 찾는 실험입니다.
통계적 유의성(p < 0.05)은 차이가 우연이 아님을 보장합니다.
Claude Code로 복잡한 통계 계산을 자동화할 수 있습니다.
