# P06-CH01-01 Stitch로 포트폴리오 블로그 디자인 기획하기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 + 화면녹화

---

## 오프닝 (30초)

(이 강의에서 만든 대시보드와 시각화 결과물을 포트폴리오 블로그로 엮는 방법 시연)

## 본문

### 포트폴리오 블로그 구조 기획

```
내 데이터 시각화 포트폴리오 블로그를 기획해줘.

포함할 섹션:
1. 히어로 — 이름, 한 줄 소개, 주요 기술 스택
2. 프로젝트 갤러리 — 대시보드 썸네일 + 설명 카드
3. 기술 소개 — Claude Code, D3.js, Python 등
4. 연락처

디자인 방향:
- 다크 테마, 데이터 시각화 분야 전문가 느낌
- 반응형 (모바일 대응)
- 대시보드 iframe 임베드 지원

Stitch 프롬프트로 변환해줘.
```

### Stitch 디자인 프롬프트

```
Design a dark-themed data visualization portfolio website.

Sections:
- Hero: name, tagline "Data Visualization Engineer", tech stack badges
- Project gallery: 3-column grid with dashboard preview cards, hover effect
- Skills: Claude Code, D3.js, Python, Tableau icon badges
- Contact: email + GitHub link

Style: dark navy background (#0a0e1a), accent color electric blue (#3b82f6),
card borders with subtle glow effect, monospace font for code elements.
Responsive layout, mobile-first.
```

---

## 핵심 정리 (30초)

포트폴리오 블로그는 히어로 → 프로젝트 갤러리 → 기술 소개 → 연락처 구조로 기획합니다.
Stitch로 디자인 시안을 빠르게 생성하고, 다음 클립에서 Antigravity + Claude Code로 실제 빌드합니다.
