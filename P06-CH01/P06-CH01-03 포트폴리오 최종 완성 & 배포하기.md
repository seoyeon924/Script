## 오프닝 (30초)

(완성된 포트폴리오를 GitHub Pages로 배포하고 공개 URL을 만드는 과정 시연)

## 본문

### 최종 점검 체크리스트

```
포트폴리오 index.html을 최종 점검해줘.

체크리스트:
- 모든 대시보드 iframe이 정상 로드되는가
- 모바일 레이아웃이 깨지지 않는가
- 이름, 연락처 정보가 올바른가
- 페이지 로딩 속도 최적화 (이미지 압축, CSS 인라인)
- 오타 및 문법 오류 없는가

문제 발견 시 즉시 수정해줘.
```

### GitHub Pages 배포

```bash
# GitHub 저장소 초기화
git init
git add .
git commit -m "feat: 데이터 시각화 포트폴리오 초기 배포"

# GitHub에 저장소 생성 후
git remote add origin https://github.com/{username}/data-viz-portfolio.git
git branch -M main
git push -u origin main

# GitHub Pages 활성화 (Settings → Pages → main branch / root)
```

### SEO & 메타 태그 추가

```
index.html에 SEO 최적화 메타 태그를 추가해줘.

포함:
- title: "{이름} | 데이터 시각화 포트폴리오"
- description: "Claude Code와 D3.js로 만든 인터랙티브 대시보드 포트폴리오"
- og:image: 포트폴리오 스크린샷
- og:url, og:title, og:description
- Twitter Card 메타 태그
```

---

## 핵심 정리 (30초)

최종 점검 → GitHub Pages 배포 → SEO 최적화 순서로 포트폴리오를 완성합니다.
이것으로 전체 강의를 마칩니다. 여러분의 포트폴리오가 취업과 이직에 도움이 되길 바랍니다.
