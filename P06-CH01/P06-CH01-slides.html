Notion API + @notionhq/client 패키지로 연동

속성 이름
타입

CategorySelect
DescriptionText
Cover ImageFiles & media
Reading TimeNumber
FeaturedCheckbox

Draft는 숨김 상태로 유지
Clip 02 · Notion API 연동
연동 3단계
Notion API 키를 받아
Claude Code에게 연결 요청
01
Notion Integration 생성
notion.so/my-integrations → 새 통합 → API 토큰 복사
02
데이터베이스에 통합 연결
데이터베이스 페이지 → … → 연결 → 통합 선택
03
Claude Code에 연동 요청
"이 사이트를 내 Notion DB에 연결해줘" + DB 링크 전달
Claude Code 프롬프트
이 사이트를 Notion 데이터베이스에 연결해줘. DB 링크: notion.so/…/데이터베이스ID Notion에 있는 블로그 포스트를 가져와서 카드 형태로 표시해줘. 각 카드에: - 커버 이미지 - 제목 - 카테고리 뱃지 - 설명 (2줄) Status = Published인 글만 노출. 내용이 바뀌면 자동으로 반영돼야 해.

Clip 03 · Netlify 배포
배포 3단계
GitHub 연결 → 환경변수 → 배포 완료
01
GitHub 레포 연결
netlify.com → Add new site → Import from Git
02
빌드 명령어 설정
Build: npm run build / Publish: dist
03
환경변수 추가
Site settings → Environment →
NOTION_API_KEY, NOTION_DATABASE_ID
🚀
배포 완료 — 공개 URL 생성
netlify.toml 캐싱 전략
# netlify.toml [[headers]] for = "/" [headers.values] Cache-Control = "no-cache" ← HTML 항상 최신 [[headers]] for = "/assets/*" [headers.values] Cache-Control = "max-age=31536000" ← JS/CSS 1년 [[headers]] for = "/images/*" [headers.values] Cache-Control = "max-age=604800" ← 이미지 1주 [[headers]] for = "/*.json" [headers.values] Cache-Control = "no-cache" ← 데이터 항상 최신
Claude Code에게 "netlify.toml에 캐싱 전략 추가해줘"라고 하면 자동 생성
