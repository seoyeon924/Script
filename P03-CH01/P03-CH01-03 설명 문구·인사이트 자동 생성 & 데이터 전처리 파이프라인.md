## 본문

### 인사이트 자동 생성 원칙

좋은 인사이트는 수치를 넘어 비즈니스 의미를 전달합니다.

나쁜 인사이트: "SNS ROI는 143%입니다."
좋은 인사이트: "SNS 채널 ROI가 검색 대비 2배 높습니다. 예산의 30%를 SNS로 재배분하면 연간 ROI가 15% 향상될 것으로 예상됩니다."

### 인사이트 자동 생성 지시

```
data/processed/kpi_results.csv를 분석해서
다음 형식으로 인사이트 3~5개를 생성해줘:

형식:
1. 핵심 발견 (수치 포함, 1문장)
2. 비즈니스 의미 (왜 중요한가, 1~2문장)
3. 권고 액션 (무엇을 해야 하는가, 1문장)

output/insights.md로 저장해줘.
```

### 차트 제목 자동 생성

```
각 차트에 인사이트 기반 제목을 자동으로 붙여줘.
예:
- 나쁜 제목: "채널별 ROI"
- 좋은 제목: "SNS ROI 143% — 검색(72%) 대비 2배 효율"
```

### 데이터 전처리 파이프라인

표준 전처리 파이프라인을 CLAUDE.md에 정의합니다:

```markdown
## 데이터 전처리 파이프라인

새 CSV가 들어오면 반드시 이 순서로 처리합니다:

1. 데이터 구조 파악
   - 컬럼 수, 행 수, 데이터 타입
   - 결측값 비율 확인

2. 결측값 처리
   - 수치형: 평균 또는 중앙값 대체
   - 범주형: 'Unknown' 대체
   - 결측 비율 30% 초과 컬럼: 삭제 검토

3. 이상치 처리
   - IQR 1.5배 이상: 플래그 처리
   - 분석자 판단 후 제거 또는 유지

4. 형식 통일
   - 날짜: YYYY-MM-DD
   - 금액: 정수 (소수점 제거)
   - 퍼센트: 0~100 범위로 통일

5. 저장: data/processed/에 _cleaned.csv로 저장
```

## 핵심 정리 (30초)

인사이트는 수치가 아니라 비즈니스 의미와 권고 액션을 담아야 합니다.
전처리 파이프라인을 CLAUDE.md에 정의하면 새 데이터마다 자동으로 적용됩니다.
다음 클립에서는 분석·시각화·리포트 자동 완성 워크플로우 실전을 진행합니다.
