# P03-CH01-01 데이터 구조 분석 → 시각화 전략 자동 도출

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 4장
- **준비물:** 없음 (개념 강의)

---

## 오프닝 (30초)

"이 데이터 시각화해줘"라고 지시하면 차트가 나오지만 기대와 다를 수 있습니다.
데이터 구조를 먼저 분석하고 시각화 전략을 자동으로 도출하는 방법을 배웁니다.

---

## 데이터 유형과 차트 유형의 관계 (5분)

데이터는 네 가지 질문 유형으로 분류됩니다.

**질문 1: 시간에 따라 어떻게 변했는가? (트렌드)**
- 적합한 차트: 라인 차트, 영역 차트
- 예: 월별 매출 추이, 일별 방문자 수 변화
- 핵심: X축이 반드시 시간 순서여야 합니다

**질문 2: 항목끼리 얼마나 다른가? (비교)**
- 적합한 차트: 막대 차트, 가로 막대 차트
- 예: 채널별 광고비 비교, 지역별 판매량 비교

**질문 3: 전체에서 각 부분의 비율은? (구성)**
- 적합한 차트: 파이 차트, 도넛 차트, 100% 누적 막대
- 핵심: 부분의 합이 100%인 데이터에만 사용합니다

**질문 4: 두 변수 사이에 관계가 있는가? (관계)**
- 적합한 차트: 스캐터 플롯, 버블 차트, 히트맵

---

## Claude Code가 데이터 구조를 분석하는 방법 (5분)

Claude에게 데이터를 주면 자동으로 시각화 전략을 제안받을 수 있습니다.

```
data/raw/campaigns.csv를 읽고
각 컬럼의 데이터 유형과 분포를 파악해줘.
그리고 이 데이터로 답할 수 있는 비즈니스 질문 5개와
각 질문에 적합한 차트 유형을 제안해줘.
```

Claude 응답 예시:
```
데이터 구조 분석 결과:
- date (날짜): 시계열 → 트렌드 분석 적합
- channel (카테고리, 5개): 비교 분석 적합
- spend (수치): 집계·비교 가능
- revenue (수치): ROI 계산 가능

추천 시각화:
1. "채널별 월간 ROI 추이" → 라인 차트 (시간 × 채널)
2. "채널별 총 광고비 비교" → 막대 차트
3. "채널별 매출 비중" → 파이 차트
```

---

## CLAUDE.md에 시각화 전략 규칙 정의 (4분)

```markdown
## 시각화 전략 자동 도출 규칙

새 데이터가 들어오면:
1. 컬럼 타입 파악 (날짜/카테고리/수치)
2. 답할 수 있는 비즈니스 질문 도출
3. 질문 유형에 맞는 차트 선택
   - 시간 데이터 → 라인 차트
   - 카테고리 비교 (7개 이하) → 세로 막대
   - 카테고리 비교 (8개 이상) → 가로 막대
   - 구성 비율 → 파이 (5개 이하만)
   - 두 변수 관계 → 스캐터 플롯
4. 인사이트 기반 제목 자동 생성
```

---

## 핵심 정리 (30초)

차트 선택은 데이터가 답하는 질문 유형에 따라 결정됩니다.
이 규칙을 CLAUDE.md에 정의하면 에이전트가 자동으로 데이터 구조를 분석하고 적합한 시각화를 제안합니다.
