# P03-CH01-04 분석·시각화·리포트 자동 완성 워크플로우 실전

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 2장 + 화면 녹화 (실전 실습)
- **준비물:** Python, Plotly

---

## 오프닝 (30초)

"이 데이터 분석해줘"라고만 해도 분석부터 리포트까지 자동으로 완성되는 시스템을 만듭니다.
8단계 파이프라인을 CLAUDE.md에 한 번 정의하면 이후 모든 분석에 자동 적용됩니다.

---

## 8단계 파이프라인 구조 (4분)

```
① 문제 정의 → ② 데이터 전처리 → ③ 지표 설계
→ ④ 방법론 선택 → ⑤ 인사이트 도출 → ⑥ 데이터 시각화
→ ⑦ 대시보드 생성 → ⑧ 보고서 생성
```

---

## CLAUDE.md — 8단계 파이프라인 템플릿 (4분)

```markdown
## 데이터 분석 파이프라인 (8단계)

새 데이터 분석 요청을 받으면 반드시 아래 순서를 따릅니다.

### ① 문제 정의
- 분석 목적을 한 문장으로 명시
- 핵심 질문 3개 도출

### ② 데이터 전처리
- data/raw/ 파일 읽기 (수정 금지)
- 결측값/날짜 형식/이상치 처리
- 전처리된 데이터 → data/processed/ 저장

### ③ 지표 설계
- 주요 KPI와 계산 공식 명시

### ④ 방법론
- 집계 / 시계열 / 코호트 / 상관관계 / A/B 테스트 중 선택

### ⑤ 인사이트 도출
- 발견한 패턴을 사실 기반으로 서술
- 최소 3개, 최대 7개 도출

### ⑥ 데이터 시각화
- 인사이트별 차트 생성 → charts/ 저장

### ⑦ 대시보드
- Plotly로 인터랙티브 대시보드 생성
- KPI 카드 + 차트 2~3개
- charts/dashboard.html 저장

### ⑧ 보고서
- 배경 → 방법론 → 주요 결과 → 인사이트 → 권고사항
- reports/analysis_report.md 저장
```

---

## 실전 실행 (5분)

CLAUDE.md에 파이프라인이 정의된 상태에서:

```
data/raw/q1_campaigns.csv 파일로 8단계 파이프라인 실행해줘.
문제 정의는 '1분기 채널별 광고 효율성 분석 및 2분기 예산 배분 추천'이야.
```

결과물:
- `data/processed/q1_cleaned.csv` — 전처리 완료 데이터
- `charts/channel_roi.png` — 채널별 ROI 차트
- `charts/dashboard.html` — 인터랙티브 대시보드
- `reports/analysis_report.md` — 최종 보고서

---

## 핵심 정리 (30초)

8단계 파이프라인을 CLAUDE.md에 정의하면 에이전트가 매번 자동으로 따릅니다.
새 데이터가 들어올 때마다 목적만 알려주면 나머지는 에이전트가 처리합니다.
