## 본문

### KPI 히어라키란

KPI 히어라키는 핵심 지표와 그것을 구성하는 하위 지표의 계층 구조입니다.

예시 — 마케팅 KPI 히어라키:
```
매출 ROI (최상위 KPI)
├── 채널별 ROI
│   ├── SNS ROI = (SNS 매출 - SNS 광고비) / SNS 광고비 × 100
│   ├── 검색 ROI
│   └── 이메일 ROI
├── 전환율 (CVR)
│   ├── 클릭 전환율 = 전환수 / 클릭수 × 100
│   └── 세그먼트별 CVR
└── 고객 획득 비용 (CPA)
    └── CPA = 총 광고비 / 총 전환수
```

### Claude Code로 KPI 히어라키 자동 설계

```
data/raw/campaigns.csv 컬럼 구조를 보고
마케팅 성과 분석을 위한 KPI 히어라키를 설계해줘.

요구사항:
- 최상위 KPI 3개
- 각 KPI별 하위 지표 2~3개
- 각 지표의 계산 공식 포함
- CLAUDE.md의 지표 설계 섹션에 추가해줘
```

### 자동 생성된 계산식 검증

```
방금 설계한 KPI 계산식을 실제 데이터로 검증해줘.
각 지표의 계산 결과와 합리적인 범위인지 확인해줘.
이상한 값이 있으면 계산식 수정을 제안해줘.
```

### KPI 카드 자동 생성

```
핵심 KPI 5개를 대시보드 상단 카드로 표시해줘.
각 카드에: 현재값, 전기 대비 증감, 목표치 대비 달성률
charts/kpi_cards.html로 저장해줘.
```

## 핵심 정리 (30초)

KPI 히어라키는 최상위 지표부터 계산 가능한 하위 지표까지 계층화한 체계입니다.
