- **유형:** 슬라이드 + 화면녹화

## 오프닝 (30초)

(리텐션 대시보드를 통해 이탈 패턴을 발견하고 개선 액션을 도출하는 방법 시연)

## 본문

### 시나리오 1 — 이탈 패턴 발견

```
코호트 리텐션 히트맵을 분석해서
이탈이 가장 많이 발생하는 구간을 찾아줘.

분석 항목:
- 어느 Month에서 가장 큰 이탈이 발생하는가
- 특정 코호트(가입 시기)가 다른 것보다 이탈이 심한가
- 이탈 급증 구간에서 무슨 일이 있었는가 (날짜 확인)
```

### 시나리오 2 — LTV 기반 고객 세그먼트

```
LTV 분석 결과를 기반으로 고객을 세그먼트화해줘.

세그먼트:
- VIP (LTV 상위 20%): 이들의 공통 특성은?
- 일반 (LTV 중위 60%): VIP로 전환 가능한 그룹은?
- 이탈 위험 (LTV 하위 20%): 조기 개입 필요한 그룹은?

각 세그먼트에 맞는 유지 전략 제안해줘.
```

### 시나리오 3 — 리텐션 개선 ROI 계산

```
리텐션을 개선하는 데 투자하면 얼마나 돌아오는지 계산해줘.

가정:
- 현재 Month 1 리텐션: 45%
- 리텐션 개선 목표: +5%p (50%)
- 개선 캠페인 비용: 월 500만원

계산:
- 리텐션 5% 개선 시 추가 LTV = ?
- 투자 회수 기간 = ?
- ROI = ?
```

## 핵심 정리 (30초)

리텐션 대시보드로 이탈 패턴 발견 → LTV 기반 세그먼트 → 개선 ROI 계산의 흐름으로 활용합니다.
Claude Code가 자동으로 이탈 구간을 찾고 개선 방향을 제안합니다.
