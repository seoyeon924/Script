# CH01-01 클로드 코드란 무엇인가 — 에이전트 구조 이해

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 4장 + 화면 녹화 (간단한 실습)
- **준비물:** 설치 완료된 클로드 코드 (CH00-04 선행 필수)

---

## 학습 목표 선언 (30초)

이 클립을 마치면 다음 두 가지를 할 수 있습니다.

첫 번째, 클로드 코드가 챗지피티와 구조적으로 어떻게 다른지 설명할 수 있습니다.
두 번째, 에이전트 루프가 어떤 단계로 동작하는지 설명할 수 있습니다.

---

## 슬라이드 1 — 두 가지 도구의 차이 (3분)

**[화면: 비교 도식]**

클로드 코드와 챗지피티는 같은 에이아이처럼 보이지만 구조가 다릅니다.

챗지피티는 대화 인터페이스입니다.
사용자가 텍스트를 입력하면 텍스트로 답합니다.
파일에 직접 접근하지 않습니다.
세션이 바뀌면 이전 대화 내용을 기억하지 않습니다.

클로드 코드는 에이전트입니다.
터미널에서 실행하고, 파일 시스템에 직접 접근합니다.
파일을 읽고, 코드를 실행하고, 명령어를 수행합니다.
클로드엠디라는 파일을 통해 프로젝트 맥락을 유지합니다.

한 문장으로 정리하면 이렇습니다.
챗지피티는 조언을 주는 도구이고, 클로드 코드는 실제로 작업을 수행하는 도구입니다.

---

## 슬라이드 2 — 에이전트란 무엇인가 (3분)

**[화면: 에이전트 구조 도식]**

에이전트는 목표를 받아서 스스로 계획하고 실행하는 시스템입니다.

사람이 일하는 방식과 비슷합니다.
업무 지시를 받으면 → 어떻게 할지 계획하고 → 하나씩 실행하고 → 결과를 확인하고 → 완료를 보고합니다.

클로드 코드 에이전트도 같은 구조입니다.

```
사용자 지시
   ↓
계획 (어떤 순서로 할까)
   ↓
도구 선택 (파일 읽기? 코드 실행? 검색?)
   ↓
실행
   ↓
결과 확인
   ↓
완료 또는 다음 단계
```

이 과정이 반복되는 것을 에이전트 루프라고 합니다.

---

## 슬라이드 3 — 클로드 코드가 가진 도구들 (3분)

**[화면: 도구 목록]**

에이전트는 도구를 사용해서 작업을 수행합니다.
클로드 코드가 기본으로 가진 도구는 다음과 같습니다.

**파일 관련**
- 파일 읽기: 텍스트, 씨에스브이, 코드 파일 읽기
- 파일 쓰기: 새 파일 생성 또는 기존 파일 수정
- 파일 검색: 특정 내용이 담긴 파일 찾기

**실행 관련**
- 터미널 명령어 실행: 쉘 커맨드, 파이썬 스크립트 실행
- 코드 평가: 파이썬, 자바스크립트 즉석 실행

**검색 관련**
- 웹 검색 (설정 시)
- 코드베이스 내 검색

이 도구들을 조합해서 데이터 파일을 읽고, 집계 코드를 실행하고, 결과를 저장하는 전 과정을 자동으로 처리합니다.

---

## 슬라이드 4 — 실제 동작 확인 (4분)

**[화면: 터미널]**

직접 확인해봅니다.

데이터 파일 하나를 만들고, 클로드 코드에게 처리를 요청합니다.

```bash
mkdir data-demo
cd data-demo
```

샘플 씨에스브이 파일을 만듭니다.

```bash
cat > sales.csv << 'EOF'
월,채널,매출
1월,검색,1200000
1월,SNS,800000
1월,이메일,450000
2월,검색,1350000
2월,SNS,920000
2월,이메일,510000
EOF
```

클로드 코드를 실행합니다.

```bash
claude
```

다음 요청을 입력합니다.

```
sales.csv 파일에서 채널별 총 매출을 계산해줘. 결과를 result.txt에 저장해.
```

클로드 코드가 무엇을 하는지 터미널에 단계별로 표시됩니다.
파일을 읽고, 계산 코드를 작성하고, 실행하고, 결과를 파일에 저장합니다.

## 마무리 (1분)

클로드 코드의 핵심 구조를 이해했습니다.

에이전트는 목표를 받아 계획하고 실행하는 구조입니다.
파일 읽기, 코드 실행, 파일 저장 도구를 조합해서 작업을 수행합니다.
챗지피티와 달리 실제 파일 시스템에서 작업합니다.

다음 클립에서는 클로드엠디를 다룹니다.
세션이 바뀌어도 프로젝트 맥락을 유지하는 파일인데요, 이게 있으면 매 세션마다 반복 설명을 하지 않아도 됩니다.

## 직접 해보기

**목표**: 클로드 코드가 실제로 내 파일을 읽는 것을 눈으로 확인합니다.

**준비 (터미널에 복붙)**
```bash
mkdir ~/my-first-claude && cd ~/my-first-claude
printf "날짜,채널,매출\n2024-01,소셜,1200000\n2024-02,이메일,980000\n2024-03,소셜,1450000" > data.csv
claude
```

**클로드에게 이렇게 말합니다**
```
data.csv 파일을 읽어서 내용을 보여줘
```

→ 클로드가 파일을 직접 열어서 내용을 출력합니다.
→ 챗지피티에게 같은 요청을 하면 "파일에 접근할 수 없습니다"라고 나옵니다.
→ 이 차이가 에이전트 구조의 핵심입니다.
