산출물 리뷰
& 재호출
각 .md 파일을 직접 열어 확인하고
처음 실행에서 흔한 실수를 짚어봅니다.
부족한 단계는 에이전트만 단독 재실행합니다.

처음 실행 시 자주 생기는 실수—
처음 실행에서 흔한 상황 3가지
실수 01 — 파일 경로
input/ 이 아닌 다른 위치에 파일을 넣음
에러: "No CSV found in runs/latest/input/"
해결
runs/latest/input/ 폴더에 정확히 넣기.
프로젝트 루트가 ai-pipeline-kit 인지 먼저 확인.
실수 02 — 이전 결과 잔류
새 데이터인데 outputs/에 이전 파일이 남아있음
증상: 파이프라인이 수 초 만에 완료 (전 단계 skip)
해결
rm runs/latest/outputs/*
로 초기화 후 /run-pipeline 재실행.
실수 03 — 분석 방향 불일치
파일은 생겼지만 내용이 데이터와 맞지 않음
증상: 산출물에 관련 없는 컬럼·문제 정의 등장
해결
CLAUDE.md에 분석 목적·타겟 컬럼 추가 후
해당 에이전트만 재호출.
에이전트 재호출9
특정 단계만 다시 실행
상황 — 문제 정의가 너무 광범위할 때
"@problem 다시 실행해줘. 마케팅 채널 ROI에 집중해서."
상황 — KPI 계산식이 틀렸을 때
"@metrics 다시 실행해줘. CVR 계산식 수정해줘."
상황 — 분석이 피상적일 때
"@analysis만 다시 해줘. 채널별 세분화 더 깊게."
