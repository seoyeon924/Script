## 오프닝 (30초)

---

## 대시보드 자동 생성 팀 구조 (5분)

```
오케스트레이터 (팀장)
│  → 전체 작업 계획 수립
│  → 각 워커에게 작업 분배
│  → 결과 취합 및 최종 판단
│
├── 데이터 분석가 (워커 1)
│      담당: CSV 로딩, EDA, KPI 계산, 인사이트 도출
│      결과 저장: output/analysis/
│
├── BI 개발자 (워커 2)
│      담당: 차트 생성, 인터랙티브 대시보드 빌드
│      결과 저장: charts/dashboard.html
│
└── 리포트 작성가 (워커 3)
       담당: 경영진용 마크다운 리포트 작성
       결과 저장: reports/final_report.md
```

---

## CLAUDE.md 에이전트 팀 정의 (4분)

```markdown
# 대시보드 자동 생성 에이전트 팀

## 팀 구성

### 팀장 (오케스트레이터)
**역할**: 전체 파이프라인 지휘
**책임**: 데이터 수신 → 작업 분배 → 결과 취합 → 품질 검토

### 데이터 분석가
**역할**: 수치 분석 전담
- CSV EDA (탐색적 데이터 분석)
- KPI 계산 (ROI, CTR, CVR 등)
- 인사이트 3~5개 도출
- 저장: output/analysis/eda_result.json

### BI 개발자
**역할**: 시각화 전담
- 인사이트별 차트 생성 (Plotly)
- 인터랙티브 대시보드 빌드
- KPI 카드 + 필터 기능 포함
- 저장: charts/dashboard.html

### 리포트 작성가
**역할**: 문서화 전담
- 경영진용 요약 리포트
- 인사이트 + 권고 액션 포함
- 저장: reports/final_report.md
```

---

## 핵심 정리 (30초)

팀장/분석가/BI/리포트 작성가의 4개 역할로 대시보드 자동 생성 팀을 구성합니다.
각 에이전트가 전문 역할에만 집중하므로 결과 품질이 높아집니다.
다음 클립에서는 CSV → EDA → 인사이트 → 대시보드 파이프라인을 실전 실행합니다.
