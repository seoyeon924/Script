## s4 — 데이터 투입

**[화면: 슬라이드]**

파일을 넣기 전에 형식별로 주의할 점을 먼저 확인해요.

CSV는 인코딩을 UTF-8로 저장해야 해요. EUC-KR이면 한글 컬럼명이 깨질 수 있어요. Excel은 `.xlsx`만 인식하고, 병합 셀은 `@data-ingestion`이 자동으로 해제해줘요. JSON은 배열 구조여야 인식하고, 중첩 객체는 자동으로 flatten해요. PDF는 텍스트와 표 기반만 가능하고, 스캔된 이미지는 추출이 안 돼요. 그리고 한글 컬럼명은 에이전트가 참조할 때 인코딩 오류가 날 수 있어서 영문 컬럼명을 권장해요.

파일을 넣었으면 실행은 `/run-pipeline` 한 줄로 끝이에요. 슬래시 커맨드로 직접 입력하거나, "파이프라인 실행해줘"라고 자연어로 말해도 돼요.

어느 단계에서 문제가 생기는지는 실행해봐야 알 수 있어요!

## s20 — 내 데이터로 교체하기

**[화면: 슬라이드]**

강의 자료 `ai-pipeline-kit.zip`을 받아서 압축을 해제해요. 그다음 `runs/latest/input/` 폴더에 분석할 CSV 파일을 넣으면 돼요.

실행 방법은 두 가지예요. 터미널에서는 `ai-pipeline-kit` 폴더로 이동한 뒤 `claude .`으로 Claude Code를 실행하고 "파이프라인 실행해줘"라고 입력해요. VS Code나 Cursor에서는 폴더를 열고 Claude Code 사이드바에서 같은 방식으로 실행하면 돼요.

다음 클립에서는 이 산출물을 하나씩 열어보고 내용이 맞지 않는 단계만 다시 실행하는 과정을 해봐요.
