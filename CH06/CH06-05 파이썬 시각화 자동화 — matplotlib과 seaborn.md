## matplotlib과 seaborn — 언제 어떤 것을 쓰는가 (3분)

파이썬 시각화 라이브러리 두 가지를 많이 씁니다.

**맷플롯립 (matplotlib):**
파이썬 시각화의 기초 라이브러리입니다.
세밀하게 커스터마이징할 수 있습니다.
코드가 조금 길지만 자유도가 높습니다.
선 굵기, 색상, 눈금 간격 하나하나 조정 가능합니다.

**씨본 (seaborn):**
맷플롯립 위에서 동작하는 고수준 라이브러리입니다.
코드 몇 줄로 세련된 차트를 만들 수 있습니다.
통계 기반 차트(히트맵, 페어플롯, 바이올린 플롯 등)에 강점이 있습니다.
기본 스타일이 맷플롯립보다 세련됩니다.

**선택 기준:**
빠르게 깔끔한 차트가 필요할 때 → 씨본
세밀한 커스터마이징이 필요할 때 → 맷플롯립

클로드 코드에게는 두 라이브러리 중 어떤 것을 쓸지 명시하는 것이 좋습니다.

---

## 맷플롯립 자동화 지시 방법 (4분)

맷플롯립으로 차트를 생성할 때 지시 방법입니다.

> "data/campaigns.csv를 읽어서 맷플롯립으로 채널별 알오아이 수평 막대 차트를 만들어줘. 조건은 다음과 같아. 차트 크기 10×6 인치. 알오아이 가장 높은 채널만 진한 파랑 (#2563EB), 나머지 연한 회색 (#9CA3AF). 각 막대 오른쪽에 수치 레이블 표시. 글꼴 크기 12. 배경 흰색, 격자선 없음. 차트 저장: charts/roi_bar.png, 해상도 150 dpi."

세부 디자인까지 지시에 포함하면 에이전트가 완성도 높은 차트를 생성합니다.

---

## 씨본 자동화 지시 방법 (4분)

씨본으로 차트를 생성할 때 지시 방법입니다.

> "data/campaigns.csv를 읽어서 씨본으로 채널별 매출 분포를 바이올린 플롯으로 그려줘. 씨본 스타일은 'whitegrid' 사용해줘. 팔레트는 'muted'. 차트 저장: charts/violin.png."

씨본은 스타일 지정이 간단합니다.
`sns.set_style()` 로 전체 스타일을 한 번에 적용합니다.

---

## 반복 시각화 자동화 — 여러 파일을 한 번에 (2분)

여러 씨에스브이 파일에 동일한 차트를 반복 생성할 때 서브에이전트와 조합합니다.

> "data/ 폴더에 있는 씨에스브이 파일 전체를 각각 서브에이전트로 처리해줘. 각 파일에서 채널별 매출 막대 차트를 생성하고, charts/파일명_chart.png 로 저장해줘. 모든 차트의 스타일을 동일하게 유지해줘."

스타일 일관성을 위해 클로드엠디에 차트 스타일 기준을 미리 작성해두는 것을 권장합니다.

## 직접 해보기

**목표**: 맷플롯립과 씨본으로 각각 차트를 자동 생성합니다.

**준비 (터미널에 복붙)**
```bash
# 라이브러리 설치 확인
pip install matplotlib seaborn pandas -q

cd ~/chart-test
claude
```

**클로드에게 이렇게 말합니다**
```
data/analysis.csv를 읽어서 두 개 차트를 만들어줘.

첫 번째 (맷플롯립):
spend와 conversions 스캐터 플롯.
추세선 추가. 차트 크기 8×6. 저장: charts/mpl_scatter.png

두 번째 (씨본):
order_amount 컬럼 히스토그램.
스타일: whitegrid, 팔레트: muted.
저장: charts/sns_hist.png
```

→ 두 라이브러리의 스타일 차이를 직접 비교합니다.

## 핵심 정리 (30초)

반복 작업은 서브에이전트와 조합해서 자동화합니다.
