두 번째, 여러 차트에 동일한 디자인 기준이 자동 적용되는 워크플로를 구성할 수 있습니다.

## 색상 일관성이 왜 중요한가 (3분)

여러 차트를 만들다 보면 문제가 생깁니다.
차트마다 색이 제각각입니다.
어떤 차트는 파랑, 어떤 차트는 초록, 어떤 차트는 주황을 씁니다.
이런 보고서를 받는 사람은 어떤 색이 무슨 의미인지 매번 다시 파악해야 합니다.

브랜드 일관성이 있으면 다릅니다.

**비유하자면 이렇습니다.**

같은 회사의 발표 자료들이 모두 같은 글꼴, 같은 색상 체계를 씁니다.
보는 사람이 바로 "아, 이 회사 자료다"라고 인식합니다.
데이터 시각화도 마찬가지입니다.
색상 체계가 일관되면 신뢰도가 올라갑니다.

---

## CLAUDE.md에 색상 기준 정의하기 (5분)

클로드엠디에 시각화 디자인 기준 섹션을 추가합니다.

```markdown
## 시각화 색상 기준

### 주요 색상 팔레트
- 강조색 (핵심 지표): #2563EB (진한 파랑)
- 보조색 (일반 항목): #9CA3AF (연한 회색)
- 긍정 (목표 달성, 상승): #059669 (초록)
- 경고 (목표 미달, 하락): #DC2626 (빨강)
- 배경: #FFFFFF (흰색)
- 격자선: #F3F4F6 (매우 연한 회색, 또는 없음)

### 차트 기본 설정
- 폰트: 맑은 고딕 또는 나눔 고딕 (한국어), 크기 12
- 차트 크기: 10×6 인치 (기본)
- 저장 해상도: 150 dpi
- 제목: 기술적 설명 금지, 인사이트 한 줄로 작성

### 색상 사용 원칙
- 강조는 1개 항목만 진한 색, 나머지는 모두 회색
- 긍정/부정 판단이 필요한 차트는 초록/빨강 사용
- 색맹 친화: 빨강-초록 조합은 패턴이나 형태로 보완
```

이 내용이 클로드엠디에 있으면, 이후 모든 차트 생성 요청에 자동 적용됩니다.

## 색상 기준 자동 적용 확인 (4분)

클로드엠디에 기준을 추가한 후 차트 생성을 요청합니다.

> "data/campaigns.csv에서 채널별 알오아이를 막대 차트로 그려줘. charts/roi.png로 저장해줘."

색상을 따로 지시하지 않아도, 에이전트가 클로드엠디의 기준을 읽고 자동 적용합니다.
가장 높은 알오아이 채널만 `#2563EB`, 나머지는 `#9CA3AF`.

---

## 다수 차트의 스타일 일괄 통일 (1분)

이미 여러 차트가 생성되어 있을 때 스타일을 일괄 수정하는 방법입니다.

> "charts/ 폴더에 있는 피엔지 파일들을 확인해줘. 생성에 사용된 파이썬 스크립트가 scripts/ 폴더에 있으면 모두 CLAUDE.md의 색상 기준으로 업데이트하고 차트를 다시 생성해줘."

에이전트가 스크립트를 찾아서 색상 값을 교체하고 재생성합니다.
