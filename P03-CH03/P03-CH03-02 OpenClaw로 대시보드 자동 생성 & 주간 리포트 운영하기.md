# P03-CH03-02 OpenClaw로 대시보드 자동 생성 & 주간 리포트 운영하기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 화면 녹화
- **준비물:** OpenClaw 설치, 텔레그램 연동 완료

---

## 세 가지 자동화 패턴 (4분)

**패턴 1 — 시간 기반 스케줄**
"매주 월요일 오전 8시에 주간 마케팅 리포트 생성"

**패턴 2 — 파일 변경 감지**
"data/raw/ 폴더에 새 파일이 생기면 자동 분석 실행"

**패턴 3 — 메시지 트리거**
"텔레그램에서 '분석 실행' 메시지를 보내면 바로 실행"

---

## 주간 리포트 자동 운영 설정 (6분)

HEARTBEAT.md에 반복 임무를 정의합니다.

```markdown
## 매일 반복 임무

매일 오전 9시:
1. ~/marketing-project/data/raw/ 최신 CSV 확인
2. 새 파일 있으면 8단계 파이프라인 실행
3. 결과 요약을 텔레그램으로 전송

매주 월요일 오전 8시:
1. 지난 주 마케팅 성과 주간 리포트 생성
2. HR 이직 위험군 업데이트
3. PM KPI 주간 현황 취합
4. 통합 요약 텔레그램 발송
```

---

## 알림 메시지 설계 (2분)

```
📊 [마케팅 주간 리포트] 2024-01-08 완료

핵심 지표:
• 총 광고비: 12,300,000원
• 평균 ROI: 143%
• 최고 채널: 검색 (ROI 210%)

⚠️ 주목: 디스플레이 ROI -12% 하락
📁 상세 리포트: reports/weekly_2024_01_08.md
```

이 형식을 CLAUDE.md에 정의하면 에이전트가 자동으로 이 형식으로 전송합니다.

---

## 직접 해보기

**HEARTBEAT.md에 추가:**
```
## 매일 반복 임무
1. ~/marketing-project/data/raw/ 확인
2. 새 파일 있으면 8단계 파이프라인 실행
3. 텔레그램으로 3줄 요약 전송
```

**텔레그램 트리거 테스트:**
```
마케팅 분석 지금 실행해줘. 결과 텔레그램으로 보내줘.
```

## 핵심 정리 (30초)

OpenClaw 자동화 패턴은 시간 기반, 파일 감지, 메시지 트리거 세 가지입니다.
HEARTBEAT.md에 반복 임무를 정의하면 에이전트가 자동으로 수행합니다.
다음 클립에서는 Agent Manager로 태스크 흐름을 관리하는 방법을 배웁니다.
