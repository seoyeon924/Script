크론 자동화
파이프라인 연동
스케줄을 설정하면 에이전트가 자는 동안 일해요.

크론 스케줄 — every vs cron13
jobs.json 예시 — 두 가지 스케줄 방식
# 종류 1 — every (주기 반복)
{
  "name": "data-feed-update",
  "schedule": {
    "kind": "every",
    "everyMs": 7200000  ← 2시간마다
  }
}

# 종류 2 — cron (시간 지정)
{
  "name": "weekly-dashboard-run",
  "schedule": {
    "kind": "cron",
    "expr": "0 9 * * 1"  ← 매주 월요일 오전 9시
    "tz": "Asia/Seoul"
  }
}

3
7단계 파이프라인 자동 실행 → 대시보드 + 보고서 생성
