#### s24 — BotFather 봇 만들기 `[데모 — 텔레그램 앱]`

**열 것:** 텔레그램 앱 → @BotFather 검색

순서:
```
1. @BotFather 채팅 열기
2. /newbot 입력
3. 봇 표시 이름: "Echo Agent" 입력
4. username: sy_echo_agent_bot (반드시 bot으로 끝나야 함)
5. 토큰 발급 → 메모장에 임시 저장 (5개 모아두기)

```

토큰 5개 모은 뒤 터미널에서만 등록:
```bash
# Echo — onboard 마법사에서 입력
openclaw onboard

# Aria/Sam/Min/Evan — macOS · Windows 동일
node add-tokens.js
```

## s24 — Telegram BotFather — 에이전트별 봇 만들기

**[화면: 텔레그램 앱]**

에이전트 하나마다 텔레그램 봇이 하나씩 필요해요. BotFather에서 만들어요.

텔레그램에서 @BotFather를 검색하고 `/newbot`을 입력해요. 봇 표시 이름을 정하고, username을 정해요. username은 반드시 bot으로 끝나야 해요.

토큰이 발급되면 메모장에 임시 저장해두고, 같은 창에서 `/newbot` 반복해서 5개 다 만들어요. 봇 하나 만드는 데 1분도 안 걸려요.

5개 토큰을 다 모은 다음에는 Echo는 `openclaw onboard` 마법사로, 나머지 4개는 `node add-tokens.js`로 등록해요. macOS · Windows 동일해요. 입력값이 화면에 안 보이고 히스토리에도 안 남아요.

## s9 — workspace vs agentDir

workspace는 에이전트 성격이 저장되는 폴더예요. SOUL.md 파일이 여기 있어요.

SOUL.md는 에이전트가 어떤 성격으로 일할지 정의하는 파일이에요. 직접 쓸 수도 있고, 텔레그램으로 대화하면 자동으로 만들어줘요.

agentDir는 에이전트별로 별도 디렉토리가 필요할 때 쓰는 설정이에요. 일반적으로는 workspace만 알면 돼요.

## s22 — 프롬프트 한 마디 → SOUL.md 자동 생성

**[화면: 텔레그램]**

처음 Echo 봇을 열면 어떤 성격으로 일하면 될지 물어봐요.

"분석가 스타일로, 팩트 중심으로 말하고, 칭찬보다 객관적으로 봐줘" 이렇게 한 마디 하면 자동으로 SOUL.md가 만들어져요.

이 파일대로 에이전트가 앞으로 계속 행동해요. 나중에 바꾸고 싶으면 다시 대화하면 돼요.

## s21 — 실제 프롬프트 — 크론이 Echo에게 보내는 메시지

크론이 에이전트에게 자동으로 보내는 메시지 형식이에요.

파일 경로를 절대경로로 명시하고, 뭘 실행할지 적고, 완료 후 어떻게 보고할지 적으면 돼요. 사람이 직접 채팅하는 것과 완전히 같은 형식이에요. 크론이 정해진 시간에 자동으로 전송할 뿐이에요.
