# P04-CH01 Interactive Data Art — 강사용 실습 운영 가이드

> 이 문서는 강사 전용 참고자료입니다. 수강생에게 배포하지 않습니다.

---

## 실습 진행 원칙

1. **완성본을 먼저 보여준다** — 수강생이 "이걸 만드는 거구나"를 먼저 확인한 뒤 실습에 들어간다. complete/ 폴더를 브라우저로 직접 열어 인터랙션을 시연한다.
2. **practice/ 폴더에서 CLAUDE.md 순서대로** — 수강생은 avengers-practice/ 또는 globe-practice/ 폴더를 Claude Code로 열고, CLAUDE.md에 적힌 프롬프트를 순서대로 실행한다.
3. **처음부터 다 만들지 않는다** — 전체 코드를 처음부터 짜는 세션이 아니다. 핵심 Step만 골라서 실행하고, 결과가 빠르게 나오는 흐름을 유지한다.
4. **프롬프트는 미리 준비된 것 그대로 쓴다** — 수강생이 직접 프롬프트를 작성하게 하면 대기 시간이 길어진다. 이 가이드에 있는 프롬프트를 복사해서 붙여넣는다.
5. **Clip당 프롬프트 최대 2~3개** — 프롬프트가 많아지면 Claude Code 실행 대기 시간이 쌓인다. 한 Clip 안에서 Step은 2~3개로 제한한다.

## Clip 02 실습: 어벤져스 네트워크 차트

### 전체 진행 흐름 (25분)

```
완성본 시연 (5분) → Step 1 기본 네트워크 (10분) → Step 2+3 디자인+인터랙션 (10분)
```

---

### Phase 1 — 완성본 시연 (5분)

**진행 방법:**
- `avengers-complete/index.html` 을 브라우저로 직접 열기
- 노드 드래그, 노드 클릭, 호버 인터랙션을 직접 시연
- 수강생이 "이게 오늘 만들 거예요"를 명확히 인식하게 한 뒤 실습으로 넘어감

**강사 멘트 예시:**
> "지금 보시는 게 완성본이에요. 드래그도 되고, 클릭하면 캐릭터 정보가 뜨고, 호버하면 연결선이 강조돼요. 이걸 D3.js Force Simulation으로 만든 거고, 지금부터 같이 만들어볼 거예요."

---

### Phase 2 — Step 1 실습: 기본 네트워크 생성 (10분)

**준비:**
- 수강생: Claude Code에서 `avengers-practice/` 폴더 열기
- 강사: 아래 프롬프트를 화면에 띄워두거나 채팅에 공유

**Step 1 프롬프트 (복사해서 그대로 실행):**

```
D3.js v7으로 어벤져스 캐릭터 네트워크 그래프 만들어줘.
데이터: avengers_network_data.csv (Source→Target, Strength=선 굵기)
D3 Force Simulation으로 노드 배치. index.html 하나로.
```

**진행 포인트:**
- Claude Code 실행 후 결과 파일(`index.html`)을 브라우저로 열어 기본 네트워크 확인
- 노드가 제대로 그려지고 선이 연결되어 있으면 성공
- 이 단계에서 디자인은 기대하지 않음 — 기능 확인이 목적

**강사 팁:**
- Step 1 실행하는 동안 수강생들에게 Step 2 프롬프트를 미리 읽게 하기
- Claude Code가 실행되는 2~3분 동안 D3 Force Simulation 개념 간단히 설명 가능 ("노드들이 물리 법칙처럼 밀고 당기는 힘으로 배치됩니다")
- 결과가 비어 있거나 오류 메시지가 나오면 → 아래 트러블슈팅 섹션 참고

---

### Phase 3 — Step 2+3 실습: 디자인 + 인터랙션 (10분)

**Step 2 프롬프트 — 디자인 (복사해서 그대로 실행):**

```
배경: 우주 느낌 (검정 + GLSL 별 파티클)
노드 색상: Source_Group별로 구분 (Asgardians, Guardians, Avengers, Wakanda, Villains)
노드 크기: Source_Importance에 비례
선 굵기: Strength에 비례
폰트: Google Fonts Cinzel
```

**Step 3 프롬프트 — 인터랙션 (Step 2 완료 직후 이어서 실행):**

```
노드 드래그 가능하게.
호버 시 연결된 캐릭터만 강조, 나머지 흐리게.
클릭 시 캐릭터 이름 + 그룹 + 연결 수 표시.
```

**진행 포인트:**
- Step 2와 Step 3은 이어서 실행하되, Step 2 결과를 브라우저로 확인한 뒤 Step 3으로 넘어감
- 시간이 빠듯하면 Step 2와 Step 3을 하나의 프롬프트로 합쳐서 한 번에 실행해도 됨

**강사 팁:**
- D3 Force Simulation은 실행할 때마다 노드 배치가 달라짐 (랜덤성). 결과가 조금 다르게 나와도 정상임을 미리 안내
- "아까랑 배치가 다르네요?" 질문이 나오면: "Force Simulation이 물리 계산을 하는데, 시작 위치가 랜덤이라 매번 조금씩 달라요. 기능은 동일해요"
- Tableau Extension(Step 4)은 **Clip 03에서 별도로 다룸** — 이 실습 세션에서는 다루지 않음

## Clip 04 실습: 3D Globe 시각화

### 전체 진행 흐름 (30분)

```
완성본 시연 (5분) → Step 1 기본 지구본 (8분) → Step 2+3 데이터+디자인 (12분)
```

---

### Phase 1 — 완성본 시연 (5분)

**진행 방법:**
- `globe-complete/index.html` 을 브라우저로 직접 열기
- 마우스 드래그로 지구본 회전, 국가 클릭 후 필터 동작 시연
- "이게 Three.js로 만든 3D 지구본이에요"로 시작

**강사 멘트 예시:**
> "드래그하면 지구가 돌아요. 아크(Arc)들이 난민 이동 경로를 나타내고 있고, 국가를 클릭하면 해당 국가 관련 경로만 필터링됩니다. 이게 Three.js 하나로 만들어진 거예요."

---

### Phase 2 — Step 1 실습: 기본 지구본 생성 (8분)

**준비:**
- 수강생: Claude Code에서 `globe-practice/` 폴더 열기
- 강사: 아래 프롬프트를 화면에 띄워두거나 채팅에 공유

**Step 1 프롬프트 (복사해서 그대로 실행):**

```
Three.js r128 + GSAP 3로 3D 지구본 만들어줘.
텍스처: https://cdn.jsdelivr.net/gh/mrdoob/three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
배경: 별이 있는 우주 (GLSL 파티클)
드래그로 회전 가능하게.
index.html 하나로.
```

**진행 포인트:**
- 브라우저로 `index.html` 열어 지구본 회전 확인
- 텍스처가 제대로 로드되는지 확인 (Network 탭에서 확인 가능)
- 이 단계에서 데이터 없이 지구본 회전만 되면 성공

**강사 팁:**
- 텍스처 URL을 직접 Network 탭에서 찾는 과정을 시연하고 싶으면 5분 추가 가능 ("Three.js 공식 GitHub의 텍스처 경로를 어떻게 찾는지" 설명)
- Three.js 코드가 길게 나와서 수강생이 당황할 수 있음 → 미리 안심: "코드가 길어도 괜찮아요. 이해 안 해도 됩니다. 프롬프트로 수정하면 되니까요."

---

### Phase 3 — Step 2+3 실습: 데이터 추가 + 디자인 토큰 (12분)

**Step 2 프롬프트 — 데이터 추가 (복사해서 그대로 실행):**

```
unhcr_data.csv 데이터 로드해서 아크 시각화.
Country of Origin ISO → Country of Asylum ISO 방향으로 아크.
Refugees 수 = 아크 굵기.
상위 500개 행만 사용해서 성능 확보.
```

**Step 3 프롬프트 — 디자인 토큰 적용 (Step 2 완료 직후 이어서 실행):**

```
디자인 토큰 적용해줘:
배경: radial-gradient(#0d1a2d 0%, #0a0a12 60%, #000 100%)
강조색: #00CCFF
폰트: Michroma (Google Fonts)
아크: 출발지 rgba(0,204,255,0.7), 도착지 rgba(255,100,100,0.7)
glow: rgba(0,204,255,0.15)
```

**진행 포인트:**
- Step 2 완료 후 아크가 지구 위에 그려지는지 확인
- Step 3 완료 후 색상 테마가 바뀌었는지 확인 (파란 계열 + 붉은 계열 아크)

**강사 팁:**
- `unhcr_data.csv`는 약 35,000행 — 전체 사용 시 렌더링이 느려짐. Step 2 프롬프트에서 **상위 500행 제한이 이미 들어가 있음**. 수강생이 임의로 제거하지 않도록 안내
- "500행밖에 안 쓰면 데이터가 부족한 거 아닌가요?" 질문이 나오면: "시각화 품질은 500행으로도 충분하고, 실습 시간 안에 빠르게 결과를 보는 게 목적이에요. 나중에 혼자 할 때 늘려보세요."
- 완성본과 비교해서 "거의 비슷하게 나왔죠?"로 마무리하면 수강생 성취감 높음

## 공통 트러블슈팅

| 상황 | 대응 방법 |
|---|---|
| 결과가 안 나올 때 (빈 화면) | "한 번 더 실행해줘. 동일하게 다시" → 프롬프트 재실행 |
| 오류 메시지가 나올 때 | 오류 메시지 전체를 복사해서 Claude Code에 그대로 붙여넣기 |
| 렌더링이 너무 느릴 때 | "데이터 1000행으로 줄여서 빠르게 테스트해줘" |
| 스타일이 마음에 안 들 때 | 브라우저 Elements 탭 → 요소 클릭 → 속성값 확인 → "이 값을 XXX로 바꿔줘" |
| Force Simulation 배치가 이상할 때 | 브라우저 새로고침 → 배치가 달라짐 (정상 동작) |
| 텍스처 이미지 로드 실패 | Network 탭에서 URL 오류 확인 → CDN URL을 다시 복사해서 프롬프트에 붙여넣기 |
| Claude Code가 너무 오래 걸릴 때 | 30초 이상 진행 없으면 중단 후 프롬프트를 더 짧게 쪼개서 재실행 |
