## 오프닝 (30초)

(지리 데이터를 3D 지구본 위에 시각화하는 D3.js Globe 제작 실전)

## 본문

### 3D Globe가 필요한 상황

글로벌 데이터를 표현할 때 2D 지도보다 3D Globe가 더 직관적입니다.

**활용 사례:**
- 국가별 매출 분포
- 글로벌 채널 트래픽 흐름
- 지역별 사용자 분포

### D3.js + Three.js Globe 구현

```
국가별 매출 데이터(data/global_revenue.csv)로
3D Globe 시각화를 만들어줘.

요구사항:
- WebGL 기반 3D 지구본
- 국가별 매출 크기에 비례한 버블 표시
- 마우스 드래그로 지구본 회전
- 마우스 오버 시 국가명과 매출 툴팁
- 색상: 매출 높을수록 진한 파랑
- charts/globe.html로 저장
```

### 데이터 구조

```csv
country_code,country,revenue,lat,lon
KR,한국,15000000,37.5665,126.9780
US,미국,32000000,37.0902,-95.7129
JP,일본,22000000,36.2048,138.2529
```

### 글로벌 데이터 수집 + 시각화

```
Firecrawl MCP로 주요 국가별 데이터를 수집하고
3D Globe로 시각화해줘.

Globe 특징:
- 자동 회전 (정지 가능)
- 클릭 시 해당 국가 드릴다운
- 모바일 터치 지원
```

### 구조 재사용

```
이 Globe 시각화 구조를 유지하면서
채널 트래픽 흐름 데이터(flow_data.json)에 적용해줘.
국가 간 연결선을 아크(arc)로 표현해줘.
```

## 핵심 정리 (30초)

3D Globe는 글로벌 지리 데이터를 직관적으로 표현하는 강력한 시각화 도구입니다.
D3.js + WebGL로 구현하며, Claude Code에게 데이터 구조와 인터랙션을 명시하면 자동 생성됩니다.
이것으로 Part 04 고급 인터랙티브 시각화를 마칩니다.
