## s19 — 3D Globe — 제작 접근법

**[화면: 슬라이드]**

3D Globe를 처음 만들 때 가장 막막한 게 뭔지 아세요?

지구 표면 텍스처를 어디서 구하냐예요.

근데 사실 직접 구할 필요가 없습니다.

**느낌은 레퍼런스로, 텍스처는 URL 복붙으로 시작**하면 돼요.

방법은 세 단계입니다.

**첫 번째**, 마음에 드는 3D Globe 화면을 찾아요. 데이터 시각화 어워드나 SNS에서 스크린샷을 모아요. "이런 느낌이면 좋겠다" 하는 레퍼런스예요.

**두 번째**, 개발자도구 **Network 탭**을 활용합니다. 이게 포인트예요.

F12 눌러서 개발자도구 열고, Network 탭으로 가요. 그리고 페이지를 새로고침해요. `.jpg` 파일이 로드되는 게 보이면 클릭하고, 주소창 URL을 그대로 복사합니다.

그러면 그 사이트가 쓰는 텍스처 URL을 바로 얻을 수 있어요.

예를 들어 이런 URL이에요.

```
https://cdn.jsdelivr.net/gh/mrdoob/three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
```

**세 번째**, 이 URL이랑 레퍼런스 이미지를 함께 **Claude Code**에 넘깁니다. URL로 어떤 텍스처인지 지정하고, 이미지로 분위기를 잡아요.

프롬프트는 이렇게 써요.

```
Three.js r128 + GSAP으로 3D 지구본 만들어줘.
텍스처 URL: https://cdn.jsdelivr.net/gh/mrdoob/
three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
데이터: unhcr_data.csv
(Origin ISO → Asylum ISO, Refugees = 아크 굵기)
```

실습은 `globe-practice/` 폴더를 Claude Code로 열고, `CLAUDE.md` 순서대로 따라하면 됩니다.

## s24 — 디자인 토큰 정의

**[화면: 슬라이드]**

이제 아주 중요한 개념 하나를 짚고 넘어갈게요.

**반복 전에 먼저, 디자인 토큰을 정의**합니다.

토큰 없이 반복 수정하면 어떻게 되냐면요.

레퍼런스 이미지를 매번 첨부해야 해요. 그러면 **API 토큰 소모**가 늘어납니다. 그리고 결과물이 매번 조금씩 달라져요. 일관성이 없어지는 거예요.

해결책은 간단합니다.

**색상, 폰트, 효과를 텍스트로 한 번 정의**해요. 그러면 이후에는 이미지 첨부 없이도, 일관된 스타일로 계속 수정할 수 있습니다.

이게 **디자인 토큰**이에요.

MIGRATION ATLAS 결과물에 적용한 토큰이 슬라이드에 나와 있습니다.

```css
/* 배경 */
bg: radial-gradient(
  #0d1a2d 0%, #0a0a12 60%, #000 100%)

/* 강조색 */
accent: #00CCFF

/* 폰트 */
font-family: 'Michroma', sans-serif
text-transform: uppercase
letter-spacing: 0.2em

/* 발광 효과 */
glow: rgba(0, 204, 255, 0.15)

/* 아크 색상 */
arc-origin: rgba(0, 204, 255, 0.7)
arc-dest:   rgba(255, 100, 100, 0.7)
```

배경 그라디언트, 강조색, 폰트, 발광 효과, 아크 색상이에요.

이 토큰을 **첫 번째 프롬프트에 붙여넣으면** 이후에는 텍스트만으로 수정이 가능합니다.

"glow 더 강하게", "accent 색 바꿔" — 이런 식으로요. 이미지 없이도 스타일이 유지됩니다.

## s20 — 3D Globe — 실제 제작 흐름

**[화면: 슬라이드]**

실제로 어떻게 만들어나가는지 흐름을 살펴볼게요.

**한 번에 나오지 않아요.**

**토큰 기반으로 단계별 반복**하는 거예요.

**Phase 1 — 기초 구현**부터 시작합니다.

```
unhcr_data.csv로 3D Globe 아크 시각화.
Origin ISO → Asylum ISO 방향 아크,
Refugees 수 = 아크 굵기.
Three.js r128 + GSAP 사용.
```

일단 동작하는 걸 먼저 만들어요.

**Phase 2**는 시각적 고도화예요. 여러 번 반복합니다.

```
glow 효과 더 강하게, 별 3배 크게
→ arcs를 흐르는 대시 애니메이션으로
→ 배경 더 어둡게, 우주 느낌으로
```

한 번에 하나씩만 수정해요. 디자인 토큰이 있으니까 매번 이미지 안 올려도 됩니다.

**Phase 3**은 기능 추가예요.

```
국가 검색 필터 추가해줘
→ 클릭 시 인트로 오버레이 만들어줘
→ 모바일 터치도 지원하게
```

기초가 잡혀 있으니까 기능을 하나씩 얹을 수 있습니다.

수정할 때 팁이 하나 있어요. **개발자도구 Elements 탭**을 활용합니다.

바꾸고 싶은 요소를 클릭하면, 색상이나 크기, opacity 같은 속성 값이 바로 보여요. 그 값을 Claude Code에 "이 요소의 [속성]을 [값]으로" 라고 정확히 전달하면 됩니다.

데이터 구조도 간단히 확인할게요.

`Country of Origin ISO`는 **아크 출발지**예요. 난민이 떠나는 국가입니다.

`Country of Asylum ISO`는 **아크 도착지**예요. 난민이 향하는 국가예요.

`Refugees`는 **아크 굵기**입니다. 난민 수에 비례해요.

> 한 가지 주의할 게 있어요. 이 컬럼 이름들은 공백이 포함되어 있습니다. 그래서 코드에서 접근할 때 `data["Country of Origin ISO"]` 처럼 대괄호와 따옴표를 써야 해요. Claude Code가 자동으로 처리해주지만, 직접 수정할 때 기억해두면 좋습니다.

## ▶ 화면 전환 — Claude Code 실습

**[화면: Claude Code → globe-practice/ 폴더]**

`globe-practice/` 폴더예요.
`CLAUDE.md` 파일에 단계별 프롬프트가 있습니다. Step 1부터 실행할게요.

### Step 1 — 지구본 뼈대

```
Three.js r128 + GSAP 3.12.2로 3D 지구본 만들어줘.
텍스처: https://cdn.jsdelivr.net/gh/mrdoob/three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
SphereGeometry(1, 64, 64), WebGLRenderer, PerspectiveCamera.
마우스 드래그로 회전 가능하게. index.html 하나로.
```

> 결과 확인: `index.html` 브라우저로 열기 → 지구본 드래그 회전 되면 OK
>
> "Three.js 코드가 길게 나와도 괜찮아요. 이해 안 해도 됩니다. 프롬프트로 수정하면 되니까요."

### Step 2 — 아크 데이터 연결

```
unhcr_data.csv 로드해서 아크 추가해줘.
Origin ISO → Asylum ISO 방향으로 CubicBezierCurve3 곡선 아크.
높이: dist * 0.0065 비례 동적 계산. Refugees 컬럼 값에 비례해서 아크 굵기 조정.
출발 빨강(0xff3333) → 도착 시안(0x00E5FF) 그라디언트.
```

> 결과 확인: 지구 위에 아크 그려지는지 확인
>
> 데이터가 35,000행이라 렌더링 느리면: "데이터 상위 500행만 쓰게 바꿔줘"

### Step 3 — 디자인 토큰 적용

```
아래 디자인 토큰으로 스타일 통일해줘.
배경: radial-gradient(#0d1a2d 0%, #0a0a12 60%, #000 100%)
강조색: #00CCFF
아크: rgba(0,204,255,0.7) → rgba(255,100,100,0.7)
glow: rgba(0,204,255,0.15)
GLSL 파티클 셰이더로 별 추가. 지구 대기 glow 레이어 추가.
아크는 흐르는 대시 애니메이션으로.
```

> 결과 확인: 색상 테마 + 별 + 아크 애니메이션 확인
>
> 완성본과 비교 "거의 비슷하게 나왔죠?"
