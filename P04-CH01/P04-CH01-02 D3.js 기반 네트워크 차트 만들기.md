## s9 — 네트워크 그래프 구조

**[화면: 슬라이드]**

네트워크 그래프는 **노드**와 **엣지**로 이루어져 있어요.
노드는 캐릭터, 엣지는 캐릭터 사이의 관계예요.

슬라이드 왼쪽을 볼게요.
아이언맨이 가운데에 있고, 토르·캡틴 아메리카·헐크·블랙 위도우·스파이더맨이 주변에 배치돼 있어요.
선이 연결된 게 **관계(엣지)**예요.

오른쪽 패널이 **비주얼 인코딩**이에요.

첫 번째, **노드 크기**예요.
`Source_Importance` 값으로 결정돼요.
등장 비중이 높은 아이언맨·토르는 원이 크고, Eitri처럼 비중이 낮은 캐릭터는 원이 작아요.

두 번째, **선 굵기**예요.
`Strength` 값으로 결정돼요.
두 캐릭터가 함께 등장한 장면 수, 즉 관계 강도예요.
수치가 높을수록 선이 굵어요.

세 번째, **선 색상**예요.
`Type` 컬럼으로 결정돼요.
ally·enemy·romantic — 관계 유형마다 색이 달라요.

네 번째, **그룹**이에요.
`Source_Group` 컬럼이에요.
Avengers·Asgardians·Guardians·Mystic Arts 단위로 묶여 있어요.
파벌별로 필터도 가능해요.

## s11 — 구현 방법론

**[화면: 슬라이드]**

이런 차트를 어떻게 만드냐, 방법이 두 가지예요.

**방법 A — 코드 레퍼런스**예요.
오픈소스 코드가 있을 때 빠른 방법이에요.

Step 1은 **레퍼런스 탐색**이에요.
Observable HQ, D3 Gallery, Codepen에서 비슷한 차트를 찾아요.

Step 2는 **개발자도구 코드 복붙**이에요.
Chrome DevTools의 Sources 탭에서 전체 코드를 복사해요.

Step 3은 **Claude Code 요청**이에요.
"이 코드 기반으로 우리 데이터에 맞게 만들어줘"라고 넘기면 돼요.

**방법 B — Gemini 해석**이에요.
스크린샷이나 영상만 있을 때 쓰는 방법이에요.

Step 1은 **영상·이미지 수집**이에요.
원하는 시각화 화면을 캡처해 두면 돼요.

Step 2는 **Gemini로 구조 파악**이에요.
"이 시각화 어떻게 구현됐어? 기술 스택은?" 하고 물어요.
Gemini가 D3.js인지, force simulation인지 분석해서 알려줘요.

Step 3은 **Claude Code 프롬프트**예요.
Gemini 답변을 그대로 붙여넣어서 구현을 시작해요.

어벤져스 차트는 **방법 B**로 만들었어요.
레퍼런스 이미지를 Gemini에 넘겼더니 D3.js + force simulation 조합을 잡아줬어요.
그 결과를 Claude Code에 그대로 전달했어요.

## s12 — 어벤져스 네트워크 — 기획에서 완성까지

**[화면: 슬라이드]**

실제 제작 흐름 네 단계예요.

**01 레퍼런스 탐색 + 주제 선정**이에요.
레퍼런스 사진을 첨부하고 "이런 네트워크 시각화 만들고 싶어. 어떤 데이터가 잘 어울릴까?" 라고 물었어요.
Claude가 어벤져스를 추천했어요.
등장인물이 많고 관계가 복잡한 데이터에 딱 맞는 구조라서예요.

**02 Firecrawl로 데이터 수집**이에요.
"Firecrawl로 어벤져스 캐릭터 공동 출연·관계 유형 데이터 CSV로 수집해줘" 라고 요청했어요.
`Source`, `Target`, `Strength`, `Type` 컬럼이 있는 CSV가 완성됐어요.

**03 차트 제작 + 디자인 고도화**예요.
"D3.js 원형 네트워크 만들어줘"로 시작해서 레퍼런스 사진을 추가하며 "이 느낌으로 텍스처·배경·애니메이션 넣어줘"라고 요청을 더해 나갔어요.
기본 차트에서 시작해서 텍스처, WebGL 갤럭시 배경, 클릭 스핀 애니메이션 순서로 발전했어요.

**04 Tableau Extension 전환**이에요.
"이걸 Tableau Extension으로 만들려면 어떻게 해?" 한 줄로 요청했어요.
`.trex` 파일, Tableau API 연동, Netlify 배포까지 만들었어요.
스타워즈 데이터로도 재사용이 되는지 검증까지 했어요.

실습 파일은 `avengers-practice/` 폴더에 있어요.
Claude Code로 폴더를 열고 `CLAUDE.md` 순서대로 따라하면 돼요.

## s13 — 구조 재사용 — 스타워즈 데이터로 Tableau 실행

**[화면: 슬라이드]**

이번 클립의 핵심 포인트예요.
어벤져스용으로 만든 구조가 **다른 데이터에 그대로 써져요**.

왼쪽 프롬프트를 볼게요.

Step 1은 Extension 전환 요청이에요.
```
이 네트워크 차트를
Tableau Extension으로 만들고 싶어.
.trex 파일 만들어줘.
```

Step 2는 다른 데이터 재사용이에요.
```
전혀 다른 데이터로도 쓸 수 있게
Source, Target, Strength
3개 컬럼만 있으면 동작하게 해줘.
```

`Source`, `Target`, `Strength` — 컬럼 세 개만 있으면 어떤 데이터든 돼요.
`.trex` 파일 하나로 어벤져스, 스타워즈, 채널 데이터 모두 재사용할 수 있어요.

오른쪽 영상을 보면, 스타워즈 CSV를 Tableau에 연결하고 Marks 카드에 필드를 매핑하면 같은 차트가 그대로 나와요.

다음 클립에서는 이 **Tableau Extension 연결 메커니즘**을 자세히 살펴볼게요.
`.trex` 파일이 어떻게 동작하고 Tableau와 어떻게 연동되는지예요.
