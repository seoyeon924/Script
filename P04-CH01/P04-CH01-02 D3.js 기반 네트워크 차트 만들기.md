---

## 오프닝 (30초)

네트워크 그래프는 노드와 엣지로 관계를 표현합니다.
고객 구매 전환 경로, 채널 간 연결, 제품 연관 구매를 시각화할 때 강력합니다.

---

## 세 가지 고급 차트 소개 (3분)

**히트맵 (Heatmap)**
행렬 구조 데이터를 색상 강도로 표현합니다.
사용 시나리오: 요일 × 시간대별 트래픽, 코호트 리텐션.

**트리맵 (Treemap)**
계층 구조 데이터를 면적으로 표현합니다.
사용 시나리오: 카테고리별 매출 비중.

**네트워크 그래프 (Network Graph)**
노드와 엣지로 관계를 표현합니다.
사용 시나리오: 고객 구매 패턴, 채널 간 전환 경로.

---

## 네트워크 그래프 생성 지시 (8분)

```
data/flow.json을 읽어서 D3.js로 포스-다이렉티드 네트워크 그래프를 만들어줘.
- 노드: 채널명, 크기는 방문자 수에 비례
- 엣지: 전환 경로, 두께는 전환 수에 비례
- 노드 드래그 가능
- 마우스 오버 시 방문자 수와 전환율 툴팁
- charts/network.html로 저장해줘.
```

flow.json 구조:
```json
{
  "nodes": [{"id": "SNS", "visitors": 1200}, {"id": "상품페이지", "visitors": 800}],
  "links": [{"source": "SNS", "target": "상품페이지", "value": 650}]
}
```

## 실전 활용 — 어벤져스 캐릭터 네트워크 (5분)

Firecrawl MCP로 어벤져스 캐릭터 공동 출연 데이터를 수집해서 네트워크로 시각화합니다.

```
Firecrawl MCP로 어벤져스 캐릭터 공동 출연 데이터를 수집해줘.
그리고 D3.js 네트워크 그래프를 만들어줘:
- 노드 크기: 총 등장 시간에 비례
- 엣지 두께: 공동 등장 시간에 비례
- 노드 드래그 가능, 마우스 오버 툴팁
- charts/avengers_network.html
```

**구조 재사용 — 다른 데이터에 적용:**
```
이 네트워크 그래프 구조를 스타워즈 데이터에 적용해줘.
필드명만 매핑하고 나머지 로직은 동일하게 사용해.
```

## 히트맵 생성 실습 (4분)

```
data/cohort.csv로 코호트 리텐션 히트맵을 만들어줘.
- 행: 가입 월, 열: Month 0~6
- 색상: 낮으면 흰색, 높으면 #2563EB 파랑
- 각 셀에 % 숫자 표시
- 마우스 오버 툴팁
- charts/heatmap.html
```

## 핵심 정리 (30초)

히트맵은 행렬 구조 데이터에, 네트워크 그래프는 관계 데이터에 씁니다.
Claude Code에게 데이터 구조, 색상 기준, 인터랙션을 명시하면 자동 생성됩니다.
한 번 만든 구조는 다른 데이터셋에 재사용할 수 있습니다.
