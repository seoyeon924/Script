## s9 — 네트워크 그래프 구조

**[화면: 슬라이드]**

네트워크 그래프는 **노드**와 **엣지**로 이루어져 있습니다.
노드는 캐릭터, 엣지는 캐릭터 사이의 관계예요.

선이 연결된 게 **관계(엣지)**예요.

오른쪽 패널이 **비주얼 인코딩**입니다.

첫 번째, **노드 크기**예요.
`Source_Importance` 값으로 결정됩니다.
등장 비중이 높은 아이언맨·토르는 원이 크고, Eitri처럼 비중이 낮은 캐릭터는 원이 작아요.

세 번째, **선 색상**이에요.
`Type` 컬럼으로 결정됩니다.
ally·enemy·romantic — 관계 유형마다 색이 달라요.

네 번째, **그룹**입니다.
`Source_Group` 컬럼이에요.

## ▶ 화면 전환 — Claude Code 실습

**[화면: Claude Code → avengers-practice/ 폴더]**

`avengers-practice/` 폴더입니다.
`CLAUDE.md` 파일에 단계별 프롬프트가 있어요. Step 1부터 순서대로 실행해보도록 하겠습니다.

### Step 1 — 원형 배치 기초

```
D3.js v7으로 어벤져스 캐릭터 네트워크 만들어줘.
데이터: avengers_network_data.csv

레이아웃: Force Simulation 사용하지 말 것.
모든 노드를 원 위에 고정 배치 (fixed circular layout).
그룹 정렬 순서: Avengers → Guardians → Asgardians → Wakanda → Mystic Arts → Black Order → Villain → Supporting
같은 그룹 안에서는 Source_Importance 내림차순.
초기 선택 노드: thanos (항상 왼쪽 9시 방향 = Math.PI 각도에 위치).

calculateLayout(selId) 함수:
- padding = Math.min(W,H)*0.16
- R = (H/2) - padding
- cx = Math.max(W*0.2 + R, padding+R), cy = H/2
- angle = Math.PI + relIdx * slotAngle (slotAngle = 2π/N)

노드: 모든 노드 동일 크기 원(r = min(W,H)*0.013), 그룹별 구분색.
엣지: 두 노드 중심 간 cubic bezier 곡선.
index.html 하나로. W=window.innerWidth, H=window.innerHeight.
```

> Claude Code 실행 중 (2~3분): "Force Simulation과 달리 원형 고정 배치는 위치가 항상 일정해요. 클릭하면 선택한 노드가 9시 방향으로 이동합니다."
>
> 결과 확인: `python3 -m http.server 8080` → http://localhost:8080 → 원형으로 노드 배치되면 OK

### Step 2 — 디자인

```
1. OGL WebGL 갤럭시 배경 추가.
   CDN: https://esm.sh/ogl@1.0.8 (type="module"로 로드)
   별 4레이어, 성운, 마우스 반응, 트윙클, 자동 회전. 배경 canvas: position:fixed, z-index:-1.

2. 엣지 색상 (Type 컬럼 기준):
   ally: #00c8ff | enemy: #ff2020 | romantic: #c040ff | family: #c0c8d0
   SVG defs에 makeLineGlow 함수로 glow 필터 생성.

3. 폰트: Google Fonts Cinzel (400/500/600/700) + Inter (300/400/500/600).
   캐릭터 이름 레이블: Cinzel, uppercase, letter-spacing 0.1em.

4. 전체 배경: #0a0a0f. 화면 가장자리 vignette.
```

> 결과 확인: WebGL 갤럭시 배경 + 관계 유형별 엣지 색상 확인

### Step 3 — 얼굴 이미지 + 클릭 스핀

```
얼굴 이미지 및 클릭 스핀 인터랙션 추가.

얼굴 이미지: avengers_network_data.csv의 Source_Image 컬럼에서 로드.
노드에 SVG foreignObject + xhtml:img로 적용. border-radius:50%, object-fit:cover.

클릭 스핀 (spinTo):
- 회전 방향: 최단 경로
- 소요 시간: Math.min(1200, 300 + steps * 40) ms
- 이징: easeOutQuint = t => 1 - Math.pow(1-t, 5)
- 스핀 중 9시 방향에 가장 가까운 노드를 스포트라이트로 표시
- 완료 후 연결 엣지 dashoffset 애니메이션(650ms)
- 엣지 opacity: 선택 연결 `0.6 + pow(s/10,2)*0.4`, 비연결 `0.02 + pow(s/10,3)*0.12`
```

> 결과 확인: 노드 클릭 → 스핀 → 얼굴 이미지 스포트라이트 → 연결선 강조 확인

### Step 4 — 필터 패널 + 정보 카드

```
우측 고정 필터 패널 추가 (position:fixed, right:16px, top:50%).
RELATIONS: All / Alliance / Conflict / Romance / Family
GROUPS: All / Avengers / Guardians / Asgardians / Wakanda / Mystic Arts / Black Order / Villain / Supporting

필터 클릭 시 해당 타입·그룹 노드만 원에 표시, 나머지는 center로 collapse.
캐릭터 정보 카드: 선택 노드 이름(Cinzel) + 그룹명 + 연결 수.
```

> 결과 확인: 필터 클릭 → 노드 collapse/expand → 정보 카드 표시 확인

## s25 — 디자인 토큰

## s13 — 구조 재사용 — 스타워즈 데이터로 Tableau 실행

**[화면: 슬라이드]**

이번 클립의 포인트예요.
어벤져스용으로 만든 구조가 **다른 데이터에 그대로 써집니다**.

왼쪽 프롬프트를 볼게요.

Step 1은 Extension 전환 요청이에요.
```
Tableau Extensions API 추가해줘.
API 스크립트: https://extensionsdk.azureedge.net/1.10/tableau.extensions.1.latest.js
Tableau 워크시트에서 Source/Target 필드 받아서 해당 캐릭터 관계만 필터링.
manifest 파일(.trex)도 만들어줘. source-location URL은 http://localhost:8080으로.
```

Step 2는 다른 데이터 재사용이에요.
```
전혀 다른 데이터로도 쓸 수 있게
Source, Target, Strength
3개 컬럼만 있으면 동작하게 해줘.
```

`Source`, `Target`, `Strength` — 컬럼 세 개만 있으면 어떤 데이터든 됩니다.
`.trex` 파일 하나로 어벤져스, 스타워즈, 채널 데이터 모두 재사용할 수 있어요.

오른쪽 영상을 보면, 스타워즈 CSV를 Tableau에 연결하고 Marks 카드에 필드를 매핑하면 같은 차트가 그대로 나옵니다.

다음 클립에서는 이 **Tableau Extension 연결 메커니즘**을 자세히 살펴보도록 하겠습니다.
`.trex` 파일이 어떻게 동작하고 Tableau와 어떻게 연동되는지예요.
