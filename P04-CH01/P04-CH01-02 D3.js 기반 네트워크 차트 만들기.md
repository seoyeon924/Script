## s9 — 네트워크 그래프 구조

**[화면: 슬라이드]**

네트워크 그래프는 **노드**와 **엣지**로 이루어져 있습니다.
노드는 캐릭터, 엣지는 캐릭터 사이의 관계예요.

슬라이드 왼쪽을 볼게요.
아이언맨이 가운데에 있고, 토르·캡틴 아메리카·헐크·블랙 위도우·스파이더맨이 주변에 배치돼 있습니다.
선이 연결된 게 **관계(엣지)**예요.

오른쪽 패널이 **비주얼 인코딩**입니다.

첫 번째, **노드 크기**예요.
`Source_Importance` 값으로 결정됩니다.
등장 비중이 높은 아이언맨·토르는 원이 크고, Eitri처럼 비중이 낮은 캐릭터는 원이 작아요.

두 번째, **선 굵기**입니다.
`Strength` 값으로 결정되는 건데요.
두 캐릭터가 함께 등장한 장면 수, 즉 관계 강도예요.
수치가 높을수록 선이 굵어집니다.

세 번째, **선 색상**이에요.
`Type` 컬럼으로 결정됩니다.
ally·enemy·romantic — 관계 유형마다 색이 달라요.

네 번째, **그룹**입니다.
`Source_Group` 컬럼이에요.
Avengers·Asgardians·Guardians·Mystic Arts 단위로 묶여 있습니다.
파벌별로 필터도 가능해요.

## s27 — 데이터 수집 방법

**[화면: 슬라이드]**

이 차트에 들어가는 데이터가 어떻게 만들어졌는지 잠깐 보여드릴게요.

왼쪽은 **방법 A — 직접 수집하는 법**이에요. 실제로 제가 쓴 프롬프트 두 개입니다.

첫 번째, **관계성 데이터**예요.
Firecrawl에 "어벤져스 인피니티워 캐릭터 관계 데이터를 Firecrawl로 수집해줘. Source, Target, Strength(1~10), Type(ally/enemy/romantic/family), Source_Group, Source_Importance 컬럼 CSV로."라고 했습니다.

두 번째, **얼굴 이미지 URL**이에요.
"위키피디아에서 각 캐릭터 공식 프로필 이미지 URL을 수집해줘. Source_Image 컬럼에 추가."라고 했습니다.

오른쪽은 **방법 B — 실습 키트 파일 사용**이에요.
`avengers_network_data.csv`예요. 80개 관계 데이터와 캐릭터 **얼굴 이미지 URL 39개**가 이미 들어 있습니다.
실습에서는 이 수집 과정이 이미 끝난 CSV를 그대로 쓰면 됩니다.

## s12 — 어벤져스 네트워크 — 기획에서 완성까지

**[화면: 슬라이드]**

실제 제작 흐름, 네 단계로 이루어져 있습니다.

**01 레퍼런스 탐색 + 주제 선정**이에요.
레퍼런스 사진을 첨부하고 "이런 네트워크 시각화 만들고 싶어. 어떤 데이터가 잘 어울릴까?" 라고 물었습니다.
Claude가 어벤져스를 추천했어요.
등장인물이 많고 관계가 복잡한 데이터에 딱 맞는 구조라서입니다.

**02 Firecrawl로 데이터 수집**이에요.
"Firecrawl로 어벤져스 캐릭터 공동 출연·관계 유형 데이터 CSV로 수집해줘" 라고 요청했습니다.
`Source`, `Target`, `Strength`, `Type` 컬럼이 있는 CSV가 완성됐어요.

**03 차트 제작 + 디자인 고도화**예요.
"D3.js 원형 네트워크 만들어줘"로 시작해서 레퍼런스 사진을 추가하며 "이 느낌으로 텍스처·배경·애니메이션 넣어줘"라고 요청을 더해 나갔습니다.
기본 차트에서 시작해서 텍스처, WebGL 갤럭시 배경, 클릭 스핀 애니메이션 순서로 발전했어요.

**04 Tableau Extension 전환**이에요.
"이걸 Tableau Extension으로 만들려면 어떻게 해?" 한 줄로 요청했습니다.
`.trex` 파일, Tableau API 연동, Netlify 배포까지 만들었어요.
스타워즈 데이터로도 재사용이 되는지 검증까지 했습니다.

실습 파일은 `avengers-practice/` 폴더에 있어요.
Claude Code로 폴더를 열고 `CLAUDE.md` 순서대로 따라하면 됩니다.

## s13 — 구조 재사용 — 스타워즈 데이터로 Tableau 실행

**[화면: 슬라이드]**

이번 클립의 포인트예요.
어벤져스용으로 만든 구조가 **다른 데이터에 그대로 써집니다**.

왼쪽 프롬프트를 볼게요.

Step 1은 Extension 전환 요청이에요.
```
Tableau Extensions API 추가해줘.
API 스크립트: https://extensionsdk.azureedge.net/1.10/tableau.extensions.1.latest.js
Tableau 워크시트에서 Source/Target 필드 받아서 해당 캐릭터 관계만 필터링.
manifest 파일(.trex)도 만들어줘. source-location URL은 http://localhost:8080으로.
```

Step 2는 다른 데이터 재사용이에요.
```
전혀 다른 데이터로도 쓸 수 있게
Source, Target, Strength
3개 컬럼만 있으면 동작하게 해줘.
```

`Source`, `Target`, `Strength` — 컬럼 세 개만 있으면 어떤 데이터든 됩니다.
`.trex` 파일 하나로 어벤져스, 스타워즈, 채널 데이터 모두 재사용할 수 있어요.

오른쪽 영상을 보면, 스타워즈 CSV를 Tableau에 연결하고 Marks 카드에 필드를 매핑하면 같은 차트가 그대로 나옵니다.

다음 클립에서는 이 **Tableau Extension 연결 메커니즘**을 자세히 살펴보도록 하겠습니다.
`.trex` 파일이 어떻게 동작하고 Tableau와 어떻게 연동되는지예요.
