### A-1 기초 구조 — 원형 레이아웃

```
D3.js v7으로 어벤져스 캐릭터 네트워크 그래프 만들어줘.
데이터: avengers_network_data.csv

레이아웃:
- Force Simulation 사용 금지. 원형(circular) 고정 레이아웃.
- 모든 노드를 동일 반지름 원 위에 등각도(2π/N) 간격으로 배치.
- 초기 선택 노드: "thanos"
- 선택된 노드는 원의 왼쪽(9시 방향, angle = Math.PI)에 고정.
- 나머지 노드는 선택 노드 기준으로 등각도로 배치.

클릭 동작:
- 클릭한 노드가 9시 방향으로 스핀. 반드시 최단 경로(최소 각도) 방향으로 회전.
- 연결된 엣지만 표시, 비연결 엣지는 투명하게.

엣지:
- Type별 색상: ally=#00c8ff, enemy=#ff2020, romantic=#c040ff, family=#c0c8d0
- Strength 비례 선 굵기
- 연결선에 발광(glow) 효과

index.html 하나로.
```

✅ 확인: 원형 배치 → thanos 선택 상태 → 클릭 시 최단경로 스핀

### A-2 디자인 — 우주 배경 + 노드 스타일

```

- body 배경: #000000

### A-4 Tableau Extension 변환 (선택)

```

─── avengers-network.html 구조 ───

스크립트 로드 순서:
1. https://d3js.org/d3.v7.min.js
2. https://extensionsdk.azureedge.net/1.10/tableau.extensions.1.latest.js

초기화 패턴:
tableau.extensions.initializeAsync().then(() => {
  const worksheet = tableau.extensions.dashboardContent.dashboard.worksheets[0];
  loadData(worksheet);
  worksheet.addEventListener(tableau.TableauEventType.FilterChanged, () => loadData(worksheet));
  worksheet.addEventListener(tableau.TableauEventType.MarkSelectionChanged, () => loadData(worksheet));
}).catch(err => {
  // Tableau 밖에서 열면 CSV 직접 로드 (개발/테스트 fallback)
  d3.csv('../avengers_network_data.csv').then(renderNetwork);
});

데이터 파싱 (loadData):
worksheet.getSummaryDataAsync().then(dataTable => {
  const columns = dataTable.columns.map(c => c.fieldName);
  const sourceIdx   = columns.findIndex(c => c.toLowerCase().includes('source'));
  const targetIdx   = columns.findIndex(c => c.toLowerCase().includes('target'));
  const strengthIdx = columns.findIndex(c => c.toLowerCase().includes('strength'));
  const typeIdx     = columns.findIndex(c => c.toLowerCase().includes('type'));
  const rows = dataTable.data.map(row => ({
    Source:   row[sourceIdx]?.formattedValue ?? '',
    Target:   row[targetIdx]?.formattedValue ?? '',
    Strength: parseFloat(row[strengthIdx]?.value ?? 1),
    Type:     row[typeIdx]?.formattedValue ?? 'ally',
  })).filter(r => r.Source && r.Target);
  renderNetwork(rows);
});

렌더링 (renderNetwork):
- D3.js Force Simulation으로 노드 배치
- 엣지 색상: ally=#4fc3f7, enemy=#ef5350, romantic=#f06292, 그 외=#aaa
- 노드: r=8, fill=#e8603c, stroke=#fff
- 라벨: font-size=11, fill=#ccc, text-anchor=middle, dy=20
- 드래그 가능하게 (d3.drag)

스타일: body { background:#000; color:#ddd; overflow:hidden; }

function latLngToVec3(lat, lng, r, h) {
  var phi = (90 - lat) * toRAD;
  var theta = (lng + 180) * toRAD;
  var rad = r + (h || 0);
  return new THREE.Vector3(
    -rad * Math.sin(phi) * Math.cos(theta),
    rad * Math.cos(phi),
    rad * Math.sin(phi) * Math.sin(theta)
  );
}
