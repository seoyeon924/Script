### A-1 기초 구조 — 원형 레이아웃

```
D3.js v7으로 어벤져스 캐릭터 네트워크 그래프 만들어줘.
데이터: avengers_network_data.csv

레이아웃 방식:
- Force Simulation 아님. 원형(circular) 고정 레이아웃.
- 모든 노드를 동일 반지름 원 위에 등각도 간격으로 배치.
- 처음엔 첫 번째 캐릭터가 선택된 상태로 시작.
- 선택된 노드는 원의 왼쪽(9시 방향, angle = Math.PI)에 고정.
- 나머지 노드는 선택 노드 기준으로 등각도로 배치.

노드 클릭 시:
- 클릭한 노드가 9시 방향으로 회전하는 스핀 애니메이션 (GSAP 또는 D3 transition).
- 연결된 엣지만 표시, 나머지는 흐리게.

엣지: Strength 값에 비례해 선 굵기, Type 값으로 색상 구분 (ally/enemy/romantic).
index.html 하나로.
```

✅ 확인: 원형 배치 → 노드 클릭 시 스핀 회전 → 엣지 강조

### A-2 디자인 — 우주 배경 + 노드 스타일

```
아래 디자인 토큰으로 스타일 통일해줘.

배경:
- body 배경색: #000000
- background.jpg 파일이 없으니 대신 CSS로 deep space 느낌 (짙은 검정)
- 반투명 fog 레이어 3개 (position:fixed, CSS blur + radial-gradient 조합)
- vignette 레이어 (가장자리 어둡게)
- GLSL WebGL 별 파티클: 멀티레이어(4층), 트윙클 효과, 성운(nebula) 컬러 포함

노드:
- 원형, Source_Group별 색상 구분 (Avengers/Asgardians/Guardians/Wakanda/Mystic Arts/Black Order/Villain/Supporting)
- 노드 크기: Source_Importance 비례
- 노드 안에 캐릭터 이름 텍스트 (Google Fonts Cinzel)
- 호버 시 툴팁 (이름 + 그룹)

엣지:
- Type별 색상: ally=#4fc3f7, enemy=#ef5350, romantic=#f06292
- Strength 비례 선 굵기

헤더:
- 상단 중앙에 "AVENGERS — Character Network" 제목 텍스트
- 하단에 "Click any character to explore connections" 힌트 텍스트
```

✅ 확인: 우주 배경 + 그룹별 색상 + fog/vignette

### A-3 인터랙션 — 검색 · 필터 · 패널

```
아래 인터랙션 요소를 추가해줘.

검색:
- 우측 상단에 Search 입력창
- 입력 시 이름 자동완성 드롭다운
- 선택 시 해당 캐릭터로 스핀 이동

필터 패널:
- Relations 필터: All / Alliance(ally) / Conflict(enemy) / Romance(romantic) / Family
- Groups 필터: All / Avengers / Guardians / Asgardians / Wakanda / Mystic Arts / Black Order / Villain / Supporting
- 필터 적용 시 해당 노드/엣지만 표시, 나머지는 원 중앙으로 숨김

연결 패널 (우측 하단):
- 선택 캐릭터의 연결된 캐릭터 목록 표시 (이름 + Strength)
- 글래스카드 스타일 (backdrop-filter: blur)

하단 정보:
- 선택된 캐릭터 이름 + 그룹 텍스트 표시
- 연결 수(connections) 숫자 표시
```

✅ 확인: 검색 → Relations 필터 → Groups 필터 → 연결 패널

## PART B — 3D Globe 시각화

> 폴더: `globe-practice/`
> 데이터: `unhcr_data.csv` (35,472행)
> ⚠️ 컬럼명 공백 포함 — `data["Country of Origin ISO"]` 형태로 접근

---

### B-1 지구본 뼈대

```
Three.js r128 + GSAP 3.12.2로 3D 지구본 만들어줘.

텍스처: https://cdn.jsdelivr.net/gh/mrdoob/three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
SphereGeometry(1, 48, 48), WebGLRenderer, PerspectiveCamera.
마우스 드래그로 회전 가능하게.

인트로 오버레이:
- 첫 화면에 반투명 오버레이 표시 ("MIGRATION ATLAS" 제목 + 설명 텍스트 + "ENTER" 버튼)
- 버튼 클릭 시 오버레이 페이드아웃, 지구본 인터랙션 시작

index.html 하나로.
```

✅ 확인: 인트로 오버레이 → ENTER 클릭 → 지구본 드래그 회전

### B-2 아크 데이터 연결

```
unhcr_data.csv 로드해서 아크 추가해줘.

컬럼명 (정확히):
- 출발: "Country of Origin ISO"
- 도착: "Country of Asylum ISO"
- 굵기: "Refugees"

위경도 변환: ISO 코드 → 위경도 매핑 테이블 포함 (주요 국가 30개 이상).
아크: CatmullRomCurve3 곡선, 지구 표면에서 위로 호를 그리는 방향.
Refugees 값 비례 아크 굵기. Refugees < 100 필터링.
데이터 상위 500행만 사용 (렌더링 속도).
```

✅ 확인: 지구 위에 아크 그려지는지 확인

### B-3 디자인 토큰 적용

```
아래 디자인 토큰으로 스타일 통일해줘.

배경: radial-gradient(ellipse at 30% 20%, #0d1a2d 0%, #0a0a12 35%, #050508 70%, #000000 100%)
강조색: #00CCFF
폰트: 'Michroma', sans-serif / text-transform: uppercase / letter-spacing: 0.2em
아크 출발: rgba(0,204,255,0.7)  →  아크 도착: rgba(255,19,19,0.7)
glow: rgba(0,204,255,0.15)

지구본:
- 대기권 glow 레이어 3겹 SphereGeometry (반지름 1.06, 1.15, 1.25배)
- 각 레이어 투명도 다르게 (0.08, 0.04, 0.02)

별 파티클: GLSL fragmentShader로 구현
- 멀티레이어 4층, 트윙클 효과
- 성운(nebula) 컬러 레이어 (blue/purple/gold)

아크 애니메이션: 흐르는 대시 패턴 (GLSL mod + uTime)

UI 요소:
- 좌측 상단: "MIGRATION ATLAS" 타이틀
- glow-layer: radial-gradient(circle at 50% 50%, rgba(255,19,19,0.15), transparent 50%)
```

✅ 확인: 색상 테마 + 대기권 glow + 별 + 아크 애니메이션

## 트러블슈팅

| 증상 | 해결 프롬프트 |
|---|---|
| 노드가 원 밖으로 튀어나감 | "calculateLayout에서 padding 값 키우고, 노드가 화면 안에 고정되게 수정해줘" |
| 스핀 애니메이션이 반대 방향으로 돎 | "클릭 시 최단 경로로 회전하도록 각도 계산 수정해줘" |
| 아크가 지구 표면 아래로 꺼짐 | "CatmullRomCurve3 중간 포인트 높이(altitude) 올려줘" |
| 지구 텍스처 안 보임 | "Three.js 텍스처 로드 실패 처리 추가하고 콘솔 에러 확인해줘" |
| 렌더링 느림 | "데이터 상위 300행만 쓰게 바꿔줘" |
| GLSL 별 안 보임 | "GLSL 컴파일 에러 console.error로 출력하게 추가해줘" |
