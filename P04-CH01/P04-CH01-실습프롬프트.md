### A-1 기초 구조 — 원형 레이아웃

```
D3.js v7으로 어벤져스 캐릭터 네트워크 그래프 만들어줘.
데이터: avengers_network_data.csv

레이아웃:
- Force Simulation 사용 금지. 원형(circular) 고정 레이아웃.
- 모든 노드를 동일 반지름 원 위에 등각도(2π/N) 간격으로 배치.
- 초기 선택 노드: "thanos"
- 선택된 노드는 원의 왼쪽(9시 방향, angle = Math.PI)에 고정.
- 나머지 노드는 선택 노드 기준으로 등각도로 배치.

클릭 동작:
- 클릭한 노드가 9시 방향으로 스핀. 반드시 최단 경로(최소 각도) 방향으로 회전.
- 연결된 엣지만 표시, 비연결 엣지는 투명하게.

엣지:
- Type별 색상: ally=#00c8ff, enemy=#ff2020, romantic=#c040ff, family=#c0c8d0
- Strength 비례 선 굵기
- 연결선에 발광(glow) 효과

index.html 하나로.
```

✅ 확인: 원형 배치 → thanos 선택 상태 → 클릭 시 최단경로 스핀

### A-2 디자인 — 우주 배경 + 노드 스타일

```
아래 디자인 토큰으로 스타일 통일해줘.

배경:
- body 배경: #000000
- fog 레이어 3개 (position:fixed, CSS linear-gradient + blur 조합으로 우주 안개 느낌)
- vignette 레이어 (가장자리 어둡게)
- GLSL WebGL 별 파티클 (OGL 기반 custom WebGL renderer):
  Triangle geometry (전체 화면 quad), GLSL fragment shader로 별 절차적 생성, white/cyan 컬러 혼합, 반짝임 효과

노드:
- 모든 노드 동일한 회색 (fill: #4a4e58, stroke: #a0a8b8) — 그룹별 색상 구분 없음
- 노드 크기: Source_Importance 비례
- 캐릭터 이름은 노드 바깥, 방사형 방향으로 배치 (노드 안에 넣지 말 것)
- 폰트: Google Fonts Cinzel

헤더:
- 좌측 상단에 "AVENGERS — Character Network" 텍스트 로고
- 하단에 "Click any character to explore connections" 힌트 텍스트
```

✅ 확인: 우주 배경 + 모노크롬 노드 + 방사형 레이블

### A-3 인터랙션 — 검색 · 필터 · 패널

```
아래 인터랙션 요소를 추가해줘.

검색 (우측 상단):
- Search 텍스트 입력창
- 입력 시 이름 자동완성 드롭다운 (#search-results)
- 선택 시 해당 캐릭터로 스핀 이동

필터 패널:

- Groups 필터: All / Avengers / Guardians / Asgardians / Wakanda / Mystic Arts / Black Order / Villain / Supporting
- 필터 적용 시 해당 노드/엣지만 표시, 나머지는 원 중앙으로 숨김

연결 패널 (#connection-panel, 우측 하단):
- 선택 캐릭터의 연결된 캐릭터 목록 (이름 + Strength 막대바)
- 글래스카드 스타일

하단 정보:
- 선택 캐릭터 이름 + 그룹 표시

```

## PART B — 3D Globe 시각화

> 폴더: `globe-practice/`
> 데이터: `unhcr_data.csv` (35,472행)
> ⚠️ 컬럼 순서: [0]Year [1]Country of Asylum [2]Country of Origin [3]Country of Asylum ISO [4]Country of Origin ISO [5]Refugees [6]Asylum-seekers

---

### B-1 지구본 뼈대

```
Three.js r128 + GSAP 3.12.2로 3D 지구본 만들어줘.

텍스처: https://cdn.jsdelivr.net/gh/mrdoob/three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
SphereGeometry(65, 48, 48), WebGLRenderer, PerspectiveCamera.
마우스 드래그로 회전 가능하게.

인트로 오버레이 (#intro-overlay):
- 첫 화면에 반투명 어두운 오버레이 표시
- 중앙에 "MIGRATION ATLAS" 제목 + 설명 텍스트 + "Click to start" 버튼
- 버튼 클릭 시: body에서 "intro-active" 클래스 제거, 오버레이 페이드아웃
- intro-active 상태일 때 다른 UI 요소 전부 숨김 (opacity:0, pointer-events:none)

index.html 하나로.
```

✅ 확인: 인트로 "Click to start" → 클릭 후 지구본 드래그 회전

### B-2 아크 데이터 연결

```
unhcr_data.csv 로드해서 아크 추가해줘.

CSV 파싱: 헤더 행 스킵 후 인덱스 기반 파싱
- fields[3] = Country of Asylum ISO (도착)
- fields[4] = Country of Origin ISO (출발)
- fields[5] = Refugees
- fields[6] = Asylum-seekers

필터링: Refugees + Asylum-seekers 합산 < 100인 행 제외.
현재 연도(또는 최신 연도) 데이터만 사용.

ISO → 위경도 변환: 인라인 COUNTRY_COORDS 객체로 주요 80개국 이상 매핑.
아크: CubicBezierCurve3 곡선, 지구 표면에서 위로 호를 그리는 방향 (midpoint altitude: globeRadius * 1.5).
Refugees 값 비례 아크 굵기.
```

✅ 확인: 지구 위에 아크 그려지는지 확인
> 렌더링 느리면: "최신 연도 데이터 중 상위 300개 플로우만 쓰게 바꿔줘"

### B-3 디자인 토큰 적용

```
아래 디자인 토큰으로 스타일 통일해줘.

배경: radial-gradient(ellipse at 30% 20%, #0d1a2d 0%, #0a0a12 35%, #050508 70%, #000000 100%)
강조색: #00CCFF
아크 출발: rgba(0, 204, 255, 0.7)  →  아크 도착: rgba(255, 19, 19, 0.7)
폰트: 'Michroma', sans-serif / text-transform: uppercase / letter-spacing: 0.2em

glow-layer (#glow-layer):
- position:fixed, mix-blend-mode:screen
- background: radial-gradient(circle at 50% 50%, rgba(255,19,19,0.15), transparent 50%)
- (cyan 아님, red)

지구본 대기권 glow (SphereGeometry 3겹):
- 1겹: globeRadius * 1.25배, opacity: 0.12
- 2겹: globeRadius * 1.15배, opacity: 0.18
- 3겹: globeRadius * 1.06배, opacity: 0.25
- 색상: #00CCFF, MeshBasicMaterial + AdditiveBlending

별 파티클 (Three.js BufferGeometry + ShaderMaterial):
- 단일 레이어, Points 약 2000개
- vertexShader: 포인트 크기 랜덤, fragmentShader: 원형 파티클 + white/cyan 혼합
- 트윙클: uTime uniform으로 opacity 변동

아크 애니메이션: GLSL line shader에서 mod(vProgress - uTime * 0.11, dashSize) 패턴
```

✅ 확인: red glow + cyan 대기권 + 별 파티클 + 아크 대시 애니메이션

### B-4 HUD 패널 + 데이터 패널

```
아래 UI 패널을 추가해줘.

좌측 HUD 패널 (#hud-left):
- border: 1px solid rgba(0,204,255,0.3), clip-path 폴리곤으로 모서리 클리핑 (backdrop-filter 사용 안 함)
- scanline 애니메이션 (::before pseudo + keyframes)

  DISPLACED: 117.3M / REFUGEES: 43.4M / ASYLUM SEEKERS: 6.9M

우측 데이터 패널 (#data-panel):
- 선택 국가의 Outflow(출발) / Inflow(도착) CSV 집계 수치
- Outflow 상위 5개국 수평 바 차트 (onclick="filterCountry(isoCode)")
- Inflow 상위 5개국 수평 바 차트
- 국가 행 클릭 시 해당 국가 관련 아크만 필터링

상단 검색 (#countrySearch):
- 국가명 입력 → 드롭다운 자동완성 (#searchDropdown)
- 선택 시 해당 국가 filterCountry() 호출
```

✅ 확인: HUD KPI → 검색 → 데이터 패널 바 차트 클릭 필터링
