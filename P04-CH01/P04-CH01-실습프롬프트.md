# P04-CH01 실습 프롬프트

각 프롬프트를 Claude Code에 순서대로 붙여넣기.
단계별로 브라우저에서 확인 후 다음으로 넘어갈 것.

---

## PART A — 어벤져스 네트워크 차트

> 폴더: `avengers-practice/`
> 데이터: `avengers_network_data.csv`

---

### A-1 기초 네트워크

```
D3.js v7으로 어벤져스 캐릭터 네트워크 그래프 만들어줘.
데이터: avengers_network_data.csv (Source→Target, Strength=선 굵기)
D3 Force Simulation으로 노드 배치. index.html 하나로.
```

✅ 확인: 브라우저에서 index.html 열기 → 노드+엣지 그려지면 OK

---

### A-2 디자인

```
배경: 우주 느낌 (검정 + GLSL 별 파티클)
노드 색상: Source_Group별로 구분 (Asgardians, Guardians, Avengers, Wakanda, Villains)
노드 크기: Source_Importance에 비례
선 굵기: Strength에 비례
폰트: Google Fonts Cinzel
```

✅ 확인: 우주 배경 + 그룹별 노드 색상

---

### A-3 인터랙션

```
노드 드래그 가능하게.
호버 시 연결된 캐릭터만 강조, 나머지 흐리게.
클릭 시 캐릭터 이름 + 그룹 + 연결 수 표시.
```

✅ 확인: 드래그 → 호버 강조 → 클릭 패널 순서로 확인

---

### A-4 Tableau Extension 변환 (선택)

```
이 네트워크 차트를 Tableau Viz Extension으로 만들고 싶어.
API 스크립트: https://extensionsdk.azureedge.net/1.10/tableau.extensions.1.latest.js
Tableau 워크시트에서 Source / Target / Strength / Type 필드를 받아서 네트워크 렌더링.
manifest 파일(.trex)도 만들어줘. source-location URL은 http://localhost:8080으로.
```

✅ 확인: tableau-extension/ 폴더에 .trex 파일 생성 여부

---

## PART B — 3D Globe 시각화

> 폴더: `globe-practice/`
> 데이터: `unhcr_data.csv` (35,472행)
> ⚠️ 컬럼명 공백 포함 — `data["Country of Origin ISO"]` 형태로 접근

---

### B-1 지구본 뼈대

```
Three.js r128 + GSAP 3.12.2로 3D 지구본 만들어줘.
텍스처: https://cdn.jsdelivr.net/gh/mrdoob/three.js@r128/examples/textures/planets/earth_atmos_2048.jpg
SphereGeometry(1, 64, 64), WebGLRenderer, PerspectiveCamera.
마우스 드래그로 회전 가능하게. index.html 하나로.
```

✅ 확인: 지구본 드래그 회전 되면 OK

---

### B-2 아크 데이터 연결

```
unhcr_data.csv 로드해서 아크 추가해줘.
컬럼명: "Country of Origin ISO" → "Country of Asylum ISO" 방향 아크.
"Refugees" 컬럼 값에 비례해서 아크 굵기 조정.
```

✅ 확인: 지구 위에 아크 그려지는지 확인
> 렌더링 느리면: "데이터 상위 500행만 쓰게 바꿔줘"

---

### B-3 디자인 토큰 적용

```
아래 디자인 토큰으로 스타일 통일해줘.

배경: radial-gradient(#0d1a2d 0%, #0a0a12 60%, #000 100%)
강조색: #00CCFF
아크: rgba(0,204,255,0.7) → rgba(255,100,100,0.7)
glow: rgba(0,204,255,0.15)
폰트: 'Michroma', sans-serif / uppercase / letter-spacing: 0.2em

GLSL 파티클 셰이더로 별 추가.
지구 대기 glow 레이어 추가.
아크는 흐르는 대시 애니메이션으로.
```

✅ 확인: 색상 테마 + 별 + 아크 애니메이션

---

### B-4 인터랙션

```
상단에 국가명 검색 필터 UI 추가.
입력하면 해당 국가 관련 아크만 표시.
국가 클릭 시 해당 국가 아크만 필터링.
```

✅ 확인: 검색 → 필터링 → 클릭 인터랙션

---

### B-5 모바일 (선택)

```
터치 드래그 회전 지원 추가. canvas 반응형으로.
```
