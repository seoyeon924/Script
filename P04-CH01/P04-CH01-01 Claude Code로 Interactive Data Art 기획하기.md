## 본문

### Interactive Data Art란

인터랙티브 데이터 아트는 데이터를 시각적으로 아름답고 탐색 가능하게 표현하는 시각화입니다.

**일반 차트와의 차이:**
- 일반 차트: 정보 전달
- 인터랙티브 데이터 아트: 정보 + 경험 + 탐색

**대표 사례:**
- D3.js 기반 네트워크 그래프 (관계 탐색)
- 3D Globe 시각화 (지리 데이터 탐색)
- Tableau Extension (기존 대시보드에 커스텀 레이어 추가)

### 기획 프레임워크

Claude Code에게 데이터 아트를 기획해달라고 요청합니다:

```
data/campaigns.csv를 보고
이 데이터로 만들 수 있는 인터랙티브 데이터 아트 아이디어 3개를 제안해줘.

각 아이디어에 포함:
1. 시각화 타입 (D3.js / 3D Globe / 네트워크 등)
2. 탐색 방법 (클릭, 드래그, 필터, 줌)
3. 전달할 인사이트
4. 제작 난이도 (하/중/상)
```

### D3.js 선택 이유

D3.js는 인터랙티브 데이터 시각화의 표준 라이브러리입니다.

- 제한 없는 커스터마이징
- SVG 기반 → 확대해도 선명
- 데이터 바인딩이 자연스러움
- 네트워크, 히트맵, 3D 등 모든 타입 구현 가능
