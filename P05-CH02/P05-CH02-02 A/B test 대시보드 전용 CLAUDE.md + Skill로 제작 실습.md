## 본문

### A/B 테스트 전용 CLAUDE.md

```markdown
# A/B 테스트 분석 대시보드

## 분석 방법론
- 통계 검정: t-test (전환율 비교)
- 유의수준: α = 0.05 (p-value < 0.05이면 유의미)
- 신뢰구간: 95% CI 표시

## 필수 계산 지표
- 각 그룹 전환율 및 95% 신뢰구간
- 상대적 개선율 (lift): (B - A) / A × 100
- p-value (통계적 유의성)
- 필요 샘플 크기 (power analysis)

## 대시보드 구성
1. KPI 카드: 그룹별 전환율, 상대 개선율, p-value
2. 전환율 비교 차트 (신뢰구간 포함)
3. 세그먼트별 결과 히트맵
4. 의사결정 권고 (통과/대기/추가실험)

## 결과 해석 규칙
- p < 0.05: "통계적으로 유의미한 차이"
- p ≥ 0.05: "통계적으로 유의미하지 않음"
- lift > 0: "B버전 전환율 더 높음"
```

### A/B Analyst Skill

```markdown
# A/B Test Analyst Skill

## 분석 순서
1. 그룹별 기본 통계 (전환율, 표본 크기)
2. 통계 검정 (t-test / chi-square)
3. 신뢰구간 계산
4. 세그먼트별 분석
5. 매출 임팩트 계산
6. 의사결정 권고 생성
```
