## 오프닝 (30초)

(A/B 테스트 결과를 어떻게 해석하고 의사결정에 활용하는지 실전 시연)

## 본문

### A/B 테스트 결과 해석 가이드

**경우 1: p < 0.05, lift > 0 (B버전이 유의미하게 더 좋음)**
```
결론: B버전으로 전환 권고
근거: B그룹 전환율 4.1%로 A그룹(3.2%) 대비 28% 향상 (p=0.023)
임팩트: 월간 전환수 +180건, 추가 매출 약 900만원 예상
```

**경우 2: p ≥ 0.05 (차이가 통계적으로 유의미하지 않음)**
```
결론: 현재 A버전 유지 또는 표본 수 증가 후 재실험
근거: 현재 표본 10,000명으로는 차이를 확인하기 어려움
권고: 15,000명으로 실험 확장 (검정력 80% 달성)
```

### 세그먼트별 인사이트 활용

```
A/B 테스트 결과에서 세그먼트별로 분석해줘.

분석 항목:
- 연령대별 (20대, 30대, 40대+)
- 기기별 (모바일, 데스크톱)
- 신규 vs 재방문 사용자

특정 세그먼트에서만 B버전이 효과적이라면
해당 세그먼트에만 우선 적용하는 방안 제안해줘.
```

### 반복 실험 파이프라인

```
이번 A/B 테스트 결과를 바탕으로
다음 실험 설계를 제안해줘.

현재 B버전이 28% 향상:
1. 다음으로 테스트할 가설 3개
2. 각 실험에 필요한 샘플 크기
3. 실험 기간 권고 (7일 vs 14일)
```
