# CH02-03 서브에이전트 실전 — 데이터 분석 파이프라인 자동화

## 📌 클립 정보
- **예상시간:** 20분
- **유형:** 화면 녹화 위주 (실습 중심)
- **준비물:** 샘플 캠페인 씨에스브이 파일 5개 (강의 자료 포함)

---

## 학습 목표 선언 (30초)

이 클립을 마치면 두 가지를 할 수 있습니다.

첫 번째, 실제 씨에스브이 데이터를 서브에이전트로 병렬 분석하는 전체 파이프라인을 실행할 수 있습니다.
두 번째, 이 구조를 본인 업무 데이터에 바로 적용할 수 있습니다.

---

## 실습 시나리오 소개 (2분)

**[화면: 파일 구조]**

오늘 실습할 시나리오입니다.

마케팅팀에서 5개 캠페인 데이터를 받았습니다.
각 파일에는 날짜, 채널, 클릭수, 전환수, 비용 컬럼이 있습니다.

```
data/
  campaign_a.csv
  campaign_b.csv
  campaign_c.csv
  campaign_d.csv
  campaign_e.csv
output/
  results/      (서브에이전트 결과 저장)
  final/        (최종 리포트)
```

목표는 다음과 같습니다.

1. 5개 캠페인을 서브에이전트로 병렬 분석
2. 각 캠페인의 전환율과 알오아이 계산
3. 전체 캠페인 비교 분석 리포트 생성

---

## 클로드엠디 설정 (3분)

**[화면: 텍스트 에디터에서 클로드엠디 작성]**

프로젝트 폴더 루트에 클로드엠디를 작성합니다.

```markdown
# 마케팅 캠페인 분석 프로젝트

## 개요
5개 캠페인 성과 데이터를 분석하여 캠페인별 알오아이와 채널별 전환율을 파악합니다.

## 데이터 스펙
- 파일 위치: data/
- 컬럼: date, channel, clicks, conversions, cost
- 인코딩: UTF-8

## 서브에이전트 운영 규칙
- 각 서브에이전트: 캠페인 파일 1개 담당
- 분석 항목:
  1. 총 클릭수 / 총 전환수 / 총 비용
  2. 전환율 = 전환수 / 클릭수 × 100
  3. 알오아이 = (전환수 × 평균 주문금액 - 비용) / 비용 × 100
     (평균 주문금액: 50,000원 기준)
  4. 채널별 전환율 상위 3개
- 결과 저장: output/results/{캠페인명}_result.json
- 원본 파일 수정 금지

## 최종 리포트 형식
- 파일: output/final/campaign_comparison.md
- 내용: 캠페인별 전환율·알오아이 비교표 + 인사이트 3줄
```

---

## 실행 — 병렬 분석 시작 (8분)

**[화면: 터미널]**

프로젝트 폴더로 이동합니다.

```bash
cd ~/projects/campaign-analysis
claude
```

클로드 코드가 시작되면 지시합니다.

> "data 폴더에 있는 캠페인 씨에스브이 5개를 각각 서브에이전트로 병렬 분석해줘. 클로드엠디 규칙에 따라 각 결과를 output/results/에 저장하고, 모두 완료되면 최종 비교 리포트를 output/final/에 만들어줘."

클로드 코드의 처리 과정을 확인합니다.

먼저 파일 목록을 확인합니다.
```
> 5개 파일 확인: campaign_a.csv, campaign_b.csv ...
> 5개 Task 도구 생성 중...
> [Task 1] campaign_a 분석 시작
> [Task 2] campaign_b 분석 시작
> [Task 3] campaign_c 분석 시작
> [Task 4] campaign_d 분석 시작
> [Task 5] campaign_e 분석 시작
```

서브에이전트들이 병렬로 실행됩니다.
각 서브에이전트가 완료되면 결과를 저장합니다.

```
> [Task 1] 완료 → output/results/campaign_a_result.json
> [Task 3] 완료 → output/results/campaign_c_result.json
> [Task 2] 완료 → output/results/campaign_b_result.json
> [Task 5] 완료 → output/results/campaign_e_result.json
> [Task 4] 완료 → output/results/campaign_d_result.json
> 5개 결과 취합 중...
> 최종 리포트 생성 완료 → output/final/campaign_comparison.md
```

완료 후 결과물을 확인합니다.

**[화면: 생성된 리포트 내용]**

```markdown
# 캠페인 성과 비교 분석

| 캠페인 | 클릭수 | 전환수 | 전환율 | 알오아이 |
|--------|--------|--------|--------|--------|
| A      | 12,450 | 234    | 1.88%  | 142%   |
| B      | 8,320  | 198    | 2.38%  | 178%   |
| C      | 15,670 | 187    | 1.19%  | 89%    |
| D      | 6,120  | 156    | 2.55%  | 193%   |
| E      | 9,840  | 143    | 1.45%  | 108%   |

## 인사이트
1. 캠페인 D가 전환율과 알오아이 모두 최고 성과 — 예산 집중 권장
2. 캠페인 C는 클릭수 최다이나 전환율 최저 — 타겟팅 개선 필요
3. 캠페인 B, D는 소규모 예산으로 고효율 달성 — 스케일업 검토
```

## 결과 검토 및 보완 (4분)

**[화면: 추가 지시 시연]**

서브에이전트 실행 후 추가 분석을 요청할 수 있습니다.

> "캠페인 D와 B의 채널별 세부 전환율을 비교해줘. 어떤 채널에서 차이가 나는지 알고 싶어."

> "캠페인 C의 전환율이 낮은 이유를 데이터에서 찾을 수 있는지 분석해줘."

> "이 결과를 태블로에서 쓸 수 있도록 정리된 씨에스브이로 다시 만들어줘."

서브에이전트로 처리한 결과를 기반으로 추가 인사이트를 빠르게 얻을 수 있습니다.

## 본인 업무에 적용하는 방법 (2분)

이 패턴을 본인 업무에 적용하는 방법입니다.

**단계 1.** 반복되는 파일 처리 작업을 찾습니다.
월별 보고서, 팀별 데이터, 지역별 파일 등이 해당됩니다.

**단계 2.** 클로드엠디에 분석 규칙을 정의합니다.
무엇을 계산하고, 어디에 저장하는지 명확히 적습니다.

**단계 3.** 서브에이전트로 병렬 실행을 요청합니다.
"각 파일을 서브에이전트로 병렬 처리해줘"라는 한 줄이면 됩니다.

## 직접 해보기

**목표**: 5개 캠페인 파일을 한 번의 지시로 병렬 분석합니다.

**준비 (터미널에 복붙)**
```bash
mkdir ~/pipeline-test && cd ~/pipeline-test
mkdir -p data output/results output/final
for c in A B C D E; do
  printf "날짜,채널,클릭,전환,비용\n" > data/campaign_${c}.csv
  for d in 01 02 03 04 05; do
    printf "2024-01-${d},소셜,$(shuf -i 500-2000 -n 1),$(shuf -i 10-100 -n 1),$(shuf -i 50000-300000 -n 1)\n" >> data/campaign_${c}.csv
  done
done
claude
```

**클로드에게 이렇게 말합니다**
```
data/ 폴더의 캠페인 씨에스브이 5개를 서브에이전트로 병렬 분석해줘.
각 파일에서 총 클릭수, 총 전환수, 전환율을 계산하고
output/results/에 저장해줘.
모두 완료되면 5개를 비교한 요약표를 output/final/summary.md로 만들어줘.
```

## 핵심 정리 (1분)

서브에이전트 파이프라인의 핵심은 세 가지입니다.
클로드엠디에 규칙 정의 → 한 문장으로 병렬 실행 지시 → 메인 에이전트가 결과 취합.
이 패턴만 익히면 대부분의 반복 데이터 작업을 자동화할 수 있습니다.
