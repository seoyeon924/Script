How it works
규칙 · 절차 · 기준
이걸 가능하게 하는 세 개의 파일
파일 1 — 규칙CLAUDE.md
CLAUDE.md = 디자인 헌법
색·KPI 계산식·구성 순서를 고정. 매번 같은 기준으로 판단하게 만드는 규칙집.
# 핵심 KPI 정의 (계산식 고정) ROAS = revenue / spend # 6.15x CTR = clicks / impressions × 100 CVR = conversions / clicks × 100 # KPI 수치 색 = 검정 고정 · 빨강/초록 금지 # 채널 순위 = ROAS 내림차순, 1위 진한 파랑
파일 2 — 절차build-dashboard
Skill = 작업 매뉴얼
"한 줄"의 정체. CSV에서 대시보드까지 가는 5단계를 고정해 둔 절차.
1
데이터 읽기 — 컬럼·채널·기간 파악
EDA
2
KPI 계산 — 채널별 ROAS·CVR·CPA 실제 산출
compute
3
레퍼런스 흡수 — reference.html 구조 그대로
reuse
4
데이터 주입 렌더 — output/ 에 HTML 생성
render
5
전달 — 예산 배분 권고까지
deliver
파일 3 — 기준reference.html
reference.html = 품질 기준선
강사의 완성 대시보드 자체. 처음부터 새로 그리지 않고, 이 구조·디자인을 그대로 재사용.
구조·레이아웃·차트 종류 → 그대로
숫자·인사이트 → 새 데이터로 교체
복붙 아님. 구조 재사용 + 실제 분석값 주입.
