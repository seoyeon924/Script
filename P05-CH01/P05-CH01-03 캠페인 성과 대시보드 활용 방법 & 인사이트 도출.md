# P05-CH01-03 캠페인 성과 대시보드 활용 방법 & 인사이트 도출

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 + 화면녹화

---

## 오프닝 (30초)

(완성된 마케팅 대시보드를 실제 업무에서 어떻게 활용하는지, 어떤 인사이트를 도출하는지 시연)

## 본문

### 대시보드 활용 시나리오

**시나리오 1 — 주간 리뷰**
```
이번 주 마케팅 성과를 대시보드로 확인하고
전주 대비 주요 변화 3가지를 요약해줘.
```

**시나리오 2 — 예산 배분 의사결정**
```
현재 채널별 ROI를 분석하고
월간 예산 1,200만원을 어떻게 배분하면
전체 ROI를 최대화할 수 있는지 권고안을 만들어줘.
```

**시나리오 3 — 이상 탐지**
```
지난 주 대비 성과가 20% 이상 하락한 채널을 찾고
가능한 원인과 대응 방안을 제안해줘.
```

### 인사이트 도출 템플릿

좋은 마케팅 인사이트 형식:

```
[발견] SNS 채널 ROI가 143%로 검색(72%) 대비 2배 높습니다.
[의미] SNS 캠페인의 전환 효율이 압도적으로 높은 상황입니다.
[액션] SNS 예산을 현재 20%에서 35%로 증가를 권고합니다.
       예상 추가 매출: 월 3,200만원 (보수 추정)
```

### OpenClaw 자동화 연동

```
매주 월요일 오전 9시에:
1. 마케팅 대시보드 자동 갱신
2. 전주 대비 성과 변화 분석
3. 주요 인사이트 3개 텔레그램 발송
```

---

## 핵심 정리 (30초)

마케팅 대시보드는 주간 리뷰, 예산 배분, 이상 탐지 세 가지 시나리오에서 특히 유용합니다.
인사이트는 발견→의미→액션의 3단계 형식으로 작성합니다.
이것으로 Part 05 CH01 마케팅 대시보드를 마칩니다.
