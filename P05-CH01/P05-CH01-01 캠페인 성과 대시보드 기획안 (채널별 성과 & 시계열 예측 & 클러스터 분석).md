## 마케팅 데이터의 기본 구조 (3분)

| 컬럼명 | 의미 | 예시 |
|-------|------|-----|
| date | 집계 날짜 | 2024-01-15 |
| channel | 광고 채널 | SNS, 검색, 이메일, 디스플레이 |
| spend | 광고 지출 | 500,000원 |

| clicks | 클릭수 | 3,200 |
| conversions | 전환수 | 180 |
| revenue | 발생 매출 | 5,400,000원 |

---

## 대시보드 기획 — 3개 레이어 (6분)

**레이어 1 — 채널별 성과 (현황 파악)**
- KPI 카드: 총 ROI, 총 광고비, 총 전환수
- 채널별 ROI, CTR, CVR, CPA 비교 막대 차트
- 채널별 매출 비중 파이 차트

**레이어 2 — 시계열 예측 (트렌드 분석)**
- 월별 ROI 추이 라인 차트 (채널별)
- 다음 달 ROI 예측선 (Prophet 또는 선형 회귀)
- 이상치 포인트 강조 표시

**레이어 3 — 클러스터 분석 (세그먼트 발견)**
- 채널 × 성과 지표 스캐터 플롯
- K-Means 클러스터링으로 유사 채널 그룹화
- 각 클러스터별 예산 배분 권고

## 샘플 데이터 생성 (3분)

```bash
mkdir ~/marketing-project && cd ~/marketing-project
mkdir -p data/raw data/output scripts charts reports
python3 -c "
import pandas as pd, numpy as np, random
random.seed(42)
dates = pd.date_range('2024-01-01', '2024-03-31', freq='D')
channels = ['SNS','검색','이메일','디스플레이','유튜브']
rows = []
for d in dates:
    for ch in channels:
        impr = random.randint(50000,200000)
        clicks = int(impr * random.uniform(0.01,0.05))
        conv = int(clicks * random.uniform(0.03,0.12))
        spend = random.randint(100000,600000)
        rev = conv * random.randint(20000,50000)
        rows.append({'date':str(d.date()),'channel':ch,'impressions':impr,'clicks':clicks,'conversions':conv,'spend':spend,'revenue':rev})
pd.DataFrame(rows).to_csv('data/raw/campaigns.csv',index=False)
print('샘플 데이터 생성 완료')
"
```
