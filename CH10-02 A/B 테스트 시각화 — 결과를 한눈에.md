# CH10-02 A/B 테스트 시각화 — 결과를 한눈에

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 화면 녹화 중심
- **준비물:** CH10-01 선행 필수

---

## 학습 목표 선언 (30초)

이 클립을 마치면 두 가지를 할 수 있습니다.

첫 번째, A/B 테스트 결과를 효과적으로 시각화할 수 있습니다.
두 번째, 신뢰구간을 포함한 차트를 만들 수 있습니다.

---

## 전환율 비교 차트 (4분)

**[화면: Claude Code 실행]**

A와 B의 전환율을 막대 차트로 비교합니다:

**클로드에게 이렇게 말합니다:**
```
A/B 테스트 결과를 시각화해줘:
- A: 전환율 3.0%
- B: 전환율 3.9%

막대 차트로 만들고:
- 각 막대 위에 정확한 수치 표시
- 차이(+30%)를 화살표로 표시
- 통계적 유의성 배지 추가 (p=0.018)
output/ab-comparison.html로 저장해.
```

이 차트 하나로 경영진에게 결과를 설명할 수 있습니다.

---

## 신뢰구간 차트 (4분)

**[화면: 에러바 차트]**

신뢰구간은 "실제 값이 이 범위 안에 있을 확률이 95%"를 의미합니다:

**클로드에게 이렇게 말합니다:**
```
같은 데이터로 신뢰구간 차트를 만들어줘:
- A: 3.0% (95% CI: 2.5% ~ 3.5%)
- B: 3.9% (95% CI: 3.4% ~ 4.4%)

에러바(오차막대)로 신뢰구간 표시하고,
두 구간이 겹치지 않으면 "유의함" 표시해줘.
output/ab-confidence.html로 저장해.
```

신뢰구간이 겹치지 않으면 통계적으로 유의합니다.

---

## 시간에 따른 누적 차트 (4분)

**[화면: 누적 전환율 차트]**

테스트 기간 동안 전환율이 어떻게 변했는지 보여줍니다:

**클로드에게 이렇게 말합니다:**
```
일별 A/B 테스트 데이터가 data/ab-daily.csv에 있어.
시간에 따른 누적 전환율 추이를 라인 차트로 만들어줘:
- X축: 테스트 날짜 (1일차~14일차)
- Y축: 누적 전환율
- 두 개의 선: A(파란색), B(초록색)
- 유의성 도달 시점에 세로선 표시
output/ab-timeline.html로 저장해.
```

언제부터 B가 확실히 이기기 시작했는지 볼 수 있습니다.

---

## 대시보드 통합 (3분)

**[화면: A/B 대시보드]**

세 가지 차트를 하나의 대시보드로 통합합니다:

**클로드에게 이렇게 말합니다:**
```
A/B 테스트 대시보드를 만들어줘:
- 상단: 요약 카드 (A 전환율, B 전환율, 차이, p-value)
- 중단 왼쪽: 전환율 비교 막대 차트
- 중단 오른쪽: 신뢰구간 차트
- 하단: 시간별 누적 전환율 추이

제목: "랜딩 페이지 A/B 테스트 결과"
output/ab-dashboard.html로 저장해.
```

## 직접 해보기

**목표**: A/B 테스트 대시보드를 한 번에 생성합니다.

**준비**
```bash
mkdir ~/ab-test-viz && cd ~/ab-test-viz
mkdir output
claude
```

**클로드에게 이렇게 말합니다**
```
A/B 테스트 대시보드를 만들어줘.
데이터:
- A: 방문 10,000명, 전환 320명 (3.2%)
- B: 방문 10,000명, 전환 410명 (4.1%)
- 테스트 기간: 14일

포함할 차트:
1. 전환율 비교 막대
2. 95% 신뢰구간 에러바
3. 일별 누적 전환율 추이 (가상 데이터 생성)
4. 요약 카드 (결론 포함)

output/ab-dashboard.html로 저장해.
```

**확인**
```bash
open output/ab-dashboard.html
```

## 핵심 정리 (1분)

A/B 테스트 결과는 막대 차트, 신뢰구간 차트, 시계열 차트로 시각화합니다.
신뢰구간이 겹치지 않으면 통계적으로 유의합니다.
대시보드로 통합하면 의사결정자가 한눈에 결과를 파악합니다.
