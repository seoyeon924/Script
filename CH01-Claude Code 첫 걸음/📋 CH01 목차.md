# CH01 — 클로드 코드 기본 활용

## 이 챕터를 마치면

1. 클로드 코드의 에이전트 구조를 설명할 수 있습니다.
2. 클로드엠디를 직접 작성해서 프로젝트 맥락을 관리할 수 있습니다.
3. 파일 읽기, 코드 실행, 결과 저장을 포함한 기본 워크플로우를 운영할 수 있습니다.
4. 플랜 모드를 활용해서 큰 작업을 안전하게 처리할 수 있습니다.
5. 비용을 모니터링하고 절약 전략을 적용할 수 있습니다.

## 이전 챕터 연결

CH00에서 환경 셋업을 완료했습니다.
이 챕터에서는 실제 도구 사용법을 익힙니다.

## 챕터 구성 의도

**CH01-01**: 에이전트 구조 개념 이해. 챗지피티와 무엇이 다른지 설명. 실제 파일로 동작 확인.

**CH01-02**: 클로드엠디 작성법. 프로젝트 맥락을 파일로 유지하는 방법. 이것이 있어야 이후 클립들이 효율적으로 진행됨.

**CH01-03**: 실제 파일 기반 워크플로우. 씨에스브이 읽기, 처리, 저장까지 전 과정.

**CH01-04**: 플랜 모드로 큰 작업 안전하게 처리. 체크포인트 개념. 되돌리기 전략.

**CH01-05**: 비용 모니터링과 절약 전략. Fast Mode 활용. 실무 예산 기준 제시.
