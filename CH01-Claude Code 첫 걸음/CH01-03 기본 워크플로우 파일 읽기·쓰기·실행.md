## 내부 동작 구조 (3분)

Claude Code는 세 가지 도구를 사용합니다.

| 도구 | 역할 |
|------|------|
| Read | 파일 내용을 읽어 Claude에 전달 |
| Write / Edit | 파일 생성 또는 수정 |
| Bash | 터미널 명령어 실행 |

"이 CSV 분석해줘"라고 하면 → 파일 읽기 → 코드 작성 → 실행 → 결과 출력이 자동으로 연결됩니다.

## 직접 해보기

**목표**: 엑셀 파일을 읽고, 집계하고, 결과를 저장하는 전체 흐름을 한 번에 실행합니다.

**준비**
1. 강의 자료실에서 `패캠-실습자료.zip` 다운로드 후 압축 해제
2. `CH01-기본활용` 폴더에 준비된 파일 확인:
   - `sales_2024.xlsx` — 2024년 월별 매출 데이터
   - `customers.csv` — 고객 정보

```bash
cd ~/Downloads/패캠-실습자료/CH01-기본활용
mkdir -p output
claude
```

**클로드에게 이렇게 말합니다**
```
sales_2024.xlsx를 읽어서 월별 총 매출과 제품별 판매량 상위 5개를 집계하고
output/monthly_summary.csv로 저장해줘
```

→ 클로드가 엑셀 파일 읽기 → 집계 → 저장을 자동으로 실행합니다.
→ `cat output/monthly_summary.csv`로 결과를 확인합니다.
