# 클로드코드 데이터분석 강의 — 교육 설계 개선안

> 작성: 민 (콘텐츠 에이전트) | 2026-03-07
> 관점: 교육 커리큘럼 설계 + AI 바이브코딩 + 데이터 분석 시각화

---

## 1. 현황 진단

### 현재 문제점

| 영역 | 문제 | 영향 |
|------|------|------|
| OT | 80초, 결과물 나열 중심 | 수강생이 "나한테 맞는 강의인가" 판단 불가 |
| 강의 목표 | 명시 없음 | 학습 후 성취감 측정 불가 |
| 수강생 경로 | 없음 | 직무별 무엇을 먼저 볼지 모름 |
| 챕터 연결 | 없음 | 각 챕터가 왜 이 순서인지 이해 불가 |
| 클립 목표 | 없음 | 클립 시작 시 "뭘 배우는지" 불명확 |
| 사전 조건 | 불명확 | 코딩 경험 없는 수강생의 기대 오류 발생 |

### 수강생 관점 시뮬레이션

> "클로드 코드 강의 신청했는데 — 내가 파이썬 몰라도 되나? 어디서부터 시작하지? 챕터 1 다 봤는데 내 업무에 어떻게 쓰지?"

지금 OT로는 이 질문 중 하나도 답이 안 됩니다.

## 2. 교육 설계 원칙 (적용 프레임)

### Backward Design (역방향 설계)
최종 결과물 → 필요 역량 → 교육 내용 순으로 설계

### Bloom's Taxonomy 6단계
```
창조 ← 챕터 9~14 (프로젝트)
평가 ← 챕터 6~8 (시각화 전략)
분석 ← 챕터 3~5 (에이전트 시스템)
적용 ← 챕터 1~2 (기본 활용)
이해 ← 챕터 0 (개념 정립)
기억 ← OT (도구 인식)
```

### 수강생 여정 지도 (4단계)

```
[인식] CH00 — 나한테 맞나? 뭘 배우나?
  ↓
[기초] CH01~02 — 도구 다루기 + 에이전트 구조 이해
  ↓
[확장] CH03~08 — 시스템 설계 + 시각화 자동화
  ↓
[실전] CH09~14 — 직무별 프로젝트 완성
```

## 3. 전체 커리큘럼 재구조화

### CH00 — 강의 소개 & 준비 (4클립 → 55분)

| # | 클립명 | 시간 | 핵심 |
|---|--------|------|------|
| CH00-01 | 강의 OT — Why, What, Who, How | 15분 | 강의 목표 + 결과물 시연 |
| CH00-02 | 이 강의로 무엇을 만드나 — 결과물 프리뷰 | 10분 | 실제 대시보드/리포트 시연 |
| CH00-03 | 수강생 유형별 학습 경로 | 10분 | 직무별 경로 가이드 |
| CH00-04 | 개발 환경 셋업 — 첫 실행까지 | 20분 | Node.js + API키 + 설치 |

> CH01에 있던 "설치" 클립을 CH00-04로 이동. CH01은 순수 활용 클립으로 구성.

## 4. 강의 목표 체계 (Learning Outcomes)

### 전체 강의 목표 3가지

```
LO-1 (이해)
클로드 코드의 에이전트 구조를 설명할 수 있습니다.

LO-2 (적용)
씨에스브이 데이터를 입력받아 태블로/디쓰리제이에스 시각화를 자동으로 생성할 수 있습니다.

LO-3 (창조)
자신의 직무 데이터를 분석하고 갱신되는 대시보드와 리포트 파이프라인을 구축할 수 있습니다.
```

### 수료 기준 (Competency Check)

각 프로젝트 챕터(CH09~14) 완주 = 수료 인정
본인 직무 데이터로 하나의 대시보드 완성 = 심화 수료

## 5. 각 클립 구성 표준 템플릿

모든 클립은 다음 구조를 따릅니다:

```
① 학습 목표 선언 (30초)
   "이 클립을 마치면 X를 할 수 있습니다."

② 개념 설명 (비유 + 도식)

③ 실습 (화면 녹화)
   - 실습 전: "지금 하실 것은 Y입니다."
   - 실습 후: "방금 Y를 했고, 결과는 Z입니다."

④ 요약 (30초)
   "오늘 배운 것: X"

⑤ 다음 클립 연결 (15초)
   "다음 클립에서는 W를 다룹니다."
```

> 데이터 읽기는 되나 분석 자동화 필요.
```
CH00 → CH01 → CH02 → CH11 → CH10
```

### 경로 D — 개발자/AI 엔지니어
> 코딩 능숙. 에이전트 시스템 구축 목적.
```
CH00 → CH01 → CH02 → CH03 → CH04 → CH05 → CH08 → CH14
```

## 7. 각 챕터 시작 슬라이드 필수 포함 요소

모든 챕터 첫 클립에 반드시 들어가야 할 것:

1. **이 챕터를 마치면** (학습 목표 3줄)
2. **지난 챕터에서** (이전 챕터 연결)
3. **이 챕터 클립 목록** (미니 목차)
4. **사전 조건** (어떤 클립을 먼저 봐야 하나)

## 8. CH01 클립 재구성 제안

현재 CH01-01이 "설치"를 다루는데, 설치는 CH00-04로 이동.
CH01은 순수하게 "도구 활용" 챕터로 재편:

| # | 현재 | 개선 |
|---|------|------|
| CH01-01 | 설치 & 첫 세션 | → CH00-04로 이동. 대신 "클로드 코드란 무엇인가 — 에이전트 구조 이해" |
| CH01-02 | CLAUDE.md | 유지 (잘 작성됨) |
| CH01-03 | 기본 워크플로우 | 유지 |
| CH01-04 | 플랜 모드 & 체크포인트 | 유지 |
| CH01-05 | Fast Mode & 비용 | 유지 |
