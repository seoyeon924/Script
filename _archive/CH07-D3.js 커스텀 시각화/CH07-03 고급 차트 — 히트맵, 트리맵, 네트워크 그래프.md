## 세 가지 고급 차트 소개 (3분)

일반 라이브러리로는 만들기 어렵지만, 실무에서 강력하게 쓰이는 차트들입니다.

**히트맵 (Heatmap)**
행렬 구조의 데이터를 색상의 강도로 표현합니다.
사용 시나리오: 요일 × 시간대별 트래픽, 상품 × 지역별 판매량.

**트리맵 (Treemap)**
계층 구조 데이터를 면적으로 표현합니다.
사용 시나리오: 카테고리별 매출 비중, 예산 항목별 구성.

**네트워크 그래프 (Network Graph)**
노드와 엣지로 관계를 표현합니다.
사용 시나리오: 고객 구매 패턴, 채널 간 전환 경로.

---

## 히트맵 생성 지시 방법 (5분)

코호트 분석에서 가장 많이 쓰는 히트맵입니다.

> "data/cohort.csv를 읽어서 디쓰리제이에스로 히트맵을 만들어줘. 행은 가입 월(코호트), 열은 이후 경과 월(Month 0~6). 값은 리텐션율(0~100). 색상은 값이 낮을수록 흰색, 높을수록 파랑 (#2563EB). 각 셀 안에 퍼센트 숫자 표시. 마우스 오버 시 코호트, 경과 월, 리텐션율 툴팁. charts/heatmap.html로 저장해줘."

샘플 씨에스브이 구조입니다.
```
cohort,month0,month1,month2,month3
2024-01,100,72,58,51
2024-02,100,68,54,48
```

## 트리맵 생성 지시 방법 (5분)

카테고리별 매출 비중을 면적으로 보여주는 트리맵입니다.

> "data/category_sales.csv를 읽어서 디쓰리제이에스로 트리맵을 만들어줘. 각 사각형의 크기는 매출에 비례. 사각형 안에 카테고리명과 매출 표시. 색상은 매출 순위에 따라 파랑 계열 그라데이션. 마우스 오버 시 상세 툴팁. 클릭하면 해당 카테고리 상세 데이터를 콘솔 출력. charts/treemap.html로 저장해줘."

---

## 네트워크 그래프 생성 지시 방법 (5분)

고객 구매 전환 경로를 노드와 엣지로 표현합니다.

> "data/flow.json을 읽어서 디쓰리제이에스로 포스-다이렉티드 네트워크 그래프를 만들어줘. 노드: 채널명, 크기는 방문자 수에 비례. 엣지: 전환 경로, 두께는 전환 수에 비례. 노드 드래그 가능. 마우스 오버 시 방문자 수와 전환율 툴팁. charts/network.html로 저장해줘."

flow.json 구조:
```json
{
  "nodes": [{"id": "SNS", "visitors": 1200}, {"id": "상품페이지", "visitors": 800}],
  "links": [{"source": "SNS", "target": "상품페이지", "value": 650}]
}
```

## 실제 활용 사례 — 어벤져스 캐릭터 네트워크 (3분)

**[화면: 네트워크 그래프 시연 영상]**

네트워크 그래프를 실무에서 어떻게 활용하는지 보여드리겠습니다.

클로드 코드와 파이어크롤 엠씨피를 함께 사용한 사례입니다.

---

**데이터 수집 — 파이어크롤 엠씨피 활용**

파이어크롤 엠씨피로 어벤져스 캐릭터 데이터를 수집합니다.
수집 항목은 이름, 이미지, 등장 시간, 공동 출연 관계입니다.

```
클로드 코드에게 이렇게 말합니다:

"파이어크롤 엠씨피로 어벤져스 캐릭터 공동 출연 데이터를 수집해줘.
캐릭터명, 총 등장 시간(분), 다른 캐릭터와의 공동 등장 시간을 구조화된 JSON으로 만들어줘."
```

파이어크롤 엠씨피는 CH05에서 배운 웹 데이터 수집 도구입니다.
외부 데이터를 직접 가져와서 시각화까지 이어지는 완전한 파이프라인입니다.

---

**네트워크 설계 원칙**

이 사례에서 네트워크를 설계한 방식입니다.

- 관계는 공동 등장 시간을 기준으로 계산합니다
- 함께 등장하는 시간이 길수록 연결선이 굵어집니다
- 관계 강도 내림차순으로 정렬합니다

```
"어벤져스 공동 출연 데이터로 디쓰리제이에스 네트워크 그래프를 만들어줘.
노드 크기는 총 등장 시간에 비례.
엣지 두께는 공동 등장 시간에 비례.
노드 드래그 가능, 마우스 오버 시 등장 시간과 주요 공동 출연자 툴팁.
charts/avengers_network.html로 저장해줘."
```

---

**구조 재사용 — 스타워즈 데이터에 적용**

인상적인 점은 시각화 자체보다, 같은 구조가 다른 데이터에 그대로 적용된다는 것입니다.

스타워즈 데이터셋에 필드만 다시 매핑하면 동일한 네트워크 그래프가 생성됩니다.
특정 케이스를 위한 코드가 아니라, 재사용 가능한 구조로 만든 것이 핵심입니다.

```
"이 네트워크 그래프 구조를 스타워즈 공동 출연 데이터에 적용해줘.
캐릭터명과 등장 시간 필드명만 매핑하고, 나머지 로직은 동일하게 사용해."
```

실무에서도 마찬가지입니다.
처음에 고객 구매 경로 네트워크로 만들었다면, 같은 구조를 채널 전환 경로, 부서 간 협업 패턴, 제품 연관 구매에 그대로 쓸 수 있습니다.

---

**태블로 익스텐션(.trex)으로 확장**

같은 디쓰리제이에스 로직을 태블로 익스텐션 파일로 변환할 수 있습니다.
태블로 워크시트 안에서 직접 실행되는 커스텀 시각화입니다.

```
"이 네트워크 그래프를 로컬 태블로 익스텐션으로 만들어줘.
.trex 파일로 패키징하고, 태블로 대시보드에서 바로 실행할 수 있게 해줘."
```

디쓰리제이에스 시각화를 웹 버전과 태블로 버전 두 곳에서 동시에 사용할 수 있게 됩니다.
기존 태블로 환경을 그대로 유지하면서 커스텀 인터랙티브 차트를 추가하는 방식입니다.

태블로 익스텐션은 CH08에서 더 자세히 다룹니다.
