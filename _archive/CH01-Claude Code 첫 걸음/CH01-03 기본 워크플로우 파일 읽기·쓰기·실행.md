## 오프닝 (1분)

파일 읽기, 쓰기, 실행 — 이 세 가지 조합으로 대부분의 작업이 가능합니다.

---

## 내부 동작 구조 (3분)

Claude Code는 세 가지 도구를 사용합니다.

| 도구 | 역할 |
|------|------|
| Read | 파일 내용을 읽어 Claude에 전달 |
| Write / Edit | 파일 생성 또는 수정 |
| Bash | 터미널 명령어 실행 |

"이 CSV 분석해줘"라고 하면 → 파일 읽기 → 코드 작성 → 실행 → 결과 출력이 자동으로 연결됩니다.

## 직접 해보기

**목표**: 엑셀 파일을 읽고, 집계하고, 결과를 저장하는 전체 흐름을 한 번에 실행합니다.

**준비**
1. 강의 자료실에서 `패캠-실습자료.zip` 다운로드 후 압축 해제
2. `CH01-기본활용` 폴더에 준비된 파일 확인:
   - `sales_2024.xlsx` — 2024년 월별 매출 데이터
   - `customers.csv` — 고객 정보

```bash
cd ~/Downloads/패캠-실습자료/CH01-기본활용
mkdir -p output
claude
```

**클로드에게 이렇게 말합니다**
```
sales_2024.xlsx를 읽어서 월별 총 매출과 제품별 판매량 상위 5개를 집계하고
output/monthly_summary.csv로 저장해줘
```

→ 클로드가 엑셀 파일 읽기 → 집계 → 저장을 자동으로 실행합니다.
→ `cat output/monthly_summary.csv`로 결과를 확인합니다.

## 슬라이드 추가 — 프로젝트 폴더 구조 한눈에 보기

**[화면: 아래 다이어그램]**

Claude Code 프로젝트의 표준 폴더 구조입니다.

```
my_project/
│
├── CLAUDE.md                  ← 프로젝트 기억 · 팀 공유
│
├── .claude/
│   ├── settings.json          ← 권한 · Hooks · 환경변수 설정
│   ├── settings.local.json    ← 나만 적용 · .gitignore 처리
│   └── commands/              ← 슬래시 커맨드 (/review, /deploy 등)
│       ├── review.md
│       ├── deploy.md
│       └── bootstrap.md
│
├── skills/                    ← 작업 유형에 따라 자동 활성화
│   ├── code-review/
│   │   ├── SKILL.md
│   │   ├── scripts/
│   │   └── references/
│   └── text-writer/
│       └── SKILL.md
│
├── agents/                    ← 서브에이전트 정의
│   ├── code-reviewer.yml
│   ├── test-writer.yml
│   └── devops-sre.yml
│
├── .mcp.json                  ← MCP 서버 연결 설정
│
├── src/                       ← 실제 소스 코드
├── tests/
└── scripts/
```

**핵심 구성 요소 역할 요약**

| 파일/폴더 | 역할 |
|-----------|------|
| `CLAUDE.md` | 프로젝트 컨벤션, 기술 스택, 보안 규칙 |
| `.claude/settings.json` | 권한 허용/차단, Hooks, 환경변수 |
| `.claude/commands/` | 프로젝트 전용 슬래시 커맨드 |
| `skills/` | 특정 작업 시 자동 활성화되는 지침 묶음 |
| `agents/` | 병렬 처리할 서브에이전트 정의 |
| `.mcp.json` | GitHub, Postgres, Slack 등 외부 도구 연결 |
