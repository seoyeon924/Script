# CH01-04 Plan 모드 & Checkpoint로 안전하게 작업하기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 3장 + 화면 녹화
- **준비물:** 여러 파일이 있는 샘플 프로젝트

---

## 오프닝 (1분)

파일 여러 개가 바뀌는 작업을 할 때, 중간에 문제가 생기면 되돌리기 어렵습니다.
Plan 모드와 Checkpoint는 이 상황을 방지하는 방법입니다.

---

## Plan 모드 (6분)

실행 전에 계획을 먼저 확인하는 방식입니다.

요청에 이렇게 붙이면 됩니다:
> "전체 파이프라인 리팩토링해줘. 실행 전에 계획 먼저 보여줘."

Claude 응답 예시:
```
계획:
1. scripts/preprocess.py — 날짜 처리 함수 분리
2. scripts/analyze.py — 중복 코드 3곳 통합
3. config.py 신규 생성 — 설정값 분리
4. README.md 업데이트

진행할까요?
```

"3번 빼고 나머지만 해줘"처럼 조정한 뒤 실행할 수 있습니다.

---

## Checkpoint (6분)

작업 중간 상태를 저장하는 기능입니다.

> "여기까지 작업 checkpoint로 저장해줘"

**활용 예시:**
```
전처리 완료  →  Checkpoint A 저장
분석 완료    →  Checkpoint B 저장
시각화 작업  →  결과 이상 발생
             →  Checkpoint B로 복구 후 재시도
```

처음부터 다시 하지 않아도 됩니다.

---

## 정리 (2분)

- Plan 모드 — 실행 전 계획 검토
- Checkpoint — 단계별 중간 저장

규모가 큰 작업이나 프로덕션 데이터 다룰 때 기본으로 쓰는 걸 권장합니다.

다음은 Fast Mode와 비용 관리입니다.

## 직접 해보기

**목표**: 실행 전에 계획을 먼저 받아서 위험한 변경을 방지합니다.

**클로드에게 이렇게 말합니다**
```
data/campaign.csv에서 비용이 250000 이상인 행만 남기고
나머지는 삭제해줘. 실행 전에 계획 먼저 보여줘.
```

→ 클로드가 실행하지 않고 계획만 출력합니다.
→ 계획을 확인한 후 "진행해줘" 또는 "취소해줘"를 입력합니다.

**한 줄 팁**: 파일 여러 개를 바꾸는 작업은 항상 끝에 "실행 전에 계획 먼저 보여줘"를 붙이세요.
