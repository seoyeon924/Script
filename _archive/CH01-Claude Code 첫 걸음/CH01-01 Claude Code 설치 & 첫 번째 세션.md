# CH01-01 Claude Code 설치 & 첫 번째 세션

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 2~3장 + 화면 녹화
- **준비물:** 터미널, 클로드 닷에이아이 계정 (프로 또는 맥스 구독)

---

## 오프닝 (1분)

이번 클립에서는 클로드 코드 설치부터 첫 세션 실행까지 진행합니다.
설치는 5분이면 끝나고, 이후 실제로 클로드 코드가 어떻게 동작하는지 직접 확인해볼게요.

---

## 사전 준비 (3분)

> 📎 **참고 링크**
> - [Claude Code 공식 문서](https://docs.anthropic.com/en/docs/claude-code/overview) — 전체 기능 가이드
> - [Claude.ai 요금제](https://claude.com/pricing) — 플랜 비교

**Node.js 별도 설치 불필요합니다.**
클로드 코드는 네이티브 설치 방식을 사용합니다.

**클로드 닷에이아이 계정 준비**
[claude.com](https://claude.com)에서 프로($20/월) 또는 맥스($100/월) 구독이 필요합니다.
계정 로그인은 설치 후 브라우저에서 오이오스(OAuth) 방식으로 진행합니다.

---

## 설치 (4분)

[화면: 터미널 실행]

터미널을 열고 아래 명령어를 입력합니다.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

맥에서 홈브루를 사용한다면 이 방법도 있습니다.

```bash
brew install --cask claude-code
```

설치 후 버전을 확인합니다.

```bash
claude --version
```

버전 번호가 나오면 설치 완료입니다.

---

## 설치가 안 될 때 — npm 대안 방법 (2분)

위 방법으로 설치가 안 되는 경우가 있습니다.
**회사 맥북처럼 보안 정책이 있는 환경**에서 주로 발생합니다.

회사 맥에서 네이티브 설치가 실패하는 이유는 이렇습니다.
회사 보안 정책(엠디엠)이 외부 스크립트 실행을 차단하거나,
`~/.local/bin/` 폴더에 파일을 쓰는 권한이 제한되어 있는 경우입니다.

이럴 때는 npm 방식을 사용합니다.
단, 공식 문서에서 deprecated(구식) 방법으로 분류하고 있습니다.
가능하면 네이티브 방식을 권장하지만, 회사 맥에서는 현실적인 대안입니다.

**npm 설치 방법**

Node.js 18 이상이 먼저 필요합니다.

```bash
node -v
```

버전이 18 미만이거나 없으면 nodejs.org에서 엘티에스 버전을 설치합니다.

그 다음 클로드 코드를 설치합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

> ⚠️ `sudo npm install -g`는 사용하지 마세요. 권한 오류가 날 수 있습니다.

설치 확인:
```bash
claude --version
```

## 로그인 (2분)

처음 실행하면 브라우저가 열리면서 로그인 화면이 나타납니다.

```bash
claude
```

브라우저에서 클로드 닷에이아이 계정으로 로그인하면 자동으로 인증이 완료됩니다.
에이피아이 키를 별도로 발급받을 필요가 없습니다.

## 첫 번째 세션 실행 (5분)

```bash
mkdir my-first-session
cd my-first-session
claude
```

프롬프트가 뜨면 바로 요청할 수 있습니다.

> "이 폴더에 hello.txt 파일 만들어줘. 내용은 'Claude Code 시작!'"

클로드가 어떤 도구를 쓰는지, 어떤 명령어를 실행하는지 전 과정을 터미널에서 볼 수 있어요.
결과만 보여주는 게 아니라 과정이 투명하게 보이는 게 클로드 코드의 특징입니다.

---

## 직접 해보기

**목표**: 설치를 완료하고 클로드 코드가 실제로 동작하는지 확인합니다.

**설치 (터미널에 복붙)**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**설치 확인**
```bash
claude --version
```

**첫 번째 실행**
```bash
# 실습 폴더를 만들고 그 안으로 이동합니다
mkdir ~/hello-claude && cd ~/hello-claude

# 클로드 코드를 시작합니다 (브라우저 로그인 창이 뜸)
claude
```

**클로드에게 이렇게 말합니다**
```
안녕. 현재 폴더 경로를 알려줘. 그리고 hello.txt 파일을 만들어서 "첫 번째 클로드 코드 실습 완료"라고 저장해줘.
```

→ 클로드가 파일을 직접 생성합니다.
→ `cat hello.txt`로 내용을 확인합니다.

## 정리 (2분)

클로드 코드는 터미널에서 실행하는 에이아이 에이전트입니다.
파일을 만들고, 코드를 실행하고, 터미널 명령어를 직접 수행합니다.

다음 클립에서는 클로드엠디를 다룹니다.
프로젝트 컨텍스트를 저장해두는 파일인데, 이게 있으면 매 세션마다 반복 설명을 안 해도 됩니다.
