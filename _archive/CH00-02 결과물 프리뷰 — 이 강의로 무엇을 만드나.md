# CH00-02 결과물 프리뷰 — 이 강의로 무엇을 만드나

## 📌 클립 정보
- **예상시간:** 10분
- **유형:** 화면 녹화 (실제 결과물 시연)
- **준비물:** 완성된 데모 대시보드, 자동화 리포트 샘플

---

## 오프닝 (1분)

이 클립에서는 강의 결과물 세 가지를 미리 확인합니다.

학습 동기를 명확히 하는 단계인데요, 지금 보여드리는 것들이 강의를 완주하면 직접 만들 수 있는 것들입니다.
각 결과물이 어느 챕터에서 완성되는지도 함께 안내합니다.

---

## 결과물 1 — 자동 갱신 대시보드 (3분)

**[화면: 마케팅 대시보드 시연]**

지금 보이는 것은 마케팅 채널별 알오아이 대시보드입니다.

이 대시보드는 씨에스브이 파일을 교체하면 자동으로 갱신됩니다.
데이터가 바뀌어도 차트 업데이트를 수동으로 할 필요가 없습니다.

**어떻게 만드나**
클로드 코드가 씨에스브이를 읽고, 집계 스크립트를 실행하고, 태블로 데이터 원본을 교체합니다.
이 과정 전체가 하나의 명령어로 실행됩니다.

**어느 챕터에서 완성되나**
CH09 마케팅 대시보드 챕터에서 직접 구현합니다.
태블로 기반이며, CH07에서 디쓰리제이에스 버전도 다룹니다.

---

## 결과물 2 — 자동화 주간 리포트 (3분)

**[화면: 리포트 자동 생성 과정 시연]**

매주 월요일 오전에 자동으로 생성되는 주간 리포트입니다.

데이터 집계 → 차트 생성 → 슬라이드 구성 → 이메일 발송까지 사람이 개입하지 않습니다.

**어떻게 작동하나**
스케줄러가 클로드 코드 에이전트를 실행합니다.
에이전트는 지난주 데이터를 분석하고, 정해진 형식에 맞게 리포트를 생성합니다.
완성된 파일을 지정된 이메일로 발송합니다.

**어느 챕터에서 완성되나**
CH13 에이치알 자동화 챕터와 CH14 오픈클로 파이프라인에서 다룹니다.
기반 구조는 CH02 서브에이전트 챕터에서 설계합니다.

---

## 결과물 3 — 데이터 분석 에이전트 (3분)

**[화면: 에이전트 대화 시연]**

이것은 분석 요청을 받아 처리하는 에이전트입니다.

사용 방식은 이렇습니다.
"지난 분기 매출 데이터에서 지역별 성장률 비교해줘"라고 입력합니다.
에이전트가 데이터 파일을 열고, 파이썬으로 집계하고, 결과 차트를 저장합니다.

챗지피티에서 같은 요청을 하면 코드 예시만 나옵니다.
클로드 코드 에이전트는 실제 파일에서 처리하고 결과물을 만듭니다.

**어느 챕터에서 완성되나**
CH02~CH03에서 에이전트 구조를 설계하고, CH10 에이비 테스트와 CH12 리텐션 분석에서 실전에 적용합니다.

## 마무리 (1분)

세 가지 결과물을 확인했습니다.

자동 갱신 대시보드, 자동화 리포트 파이프라인, 데이터 분석 에이전트입니다.
이 모두는 실제 데이터로 만들어진 것이고, 강의 중에 직접 구현합니다.

다음 클립에서는 수강생 유형별 학습 경로를 안내합니다.
본인 직무에 맞는 최적 순서로 강의를 진행할 수 있습니다.
