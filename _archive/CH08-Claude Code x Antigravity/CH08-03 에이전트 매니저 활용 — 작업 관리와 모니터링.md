# CH08-03 에이전트 매니저 활용 — 작업 관리와 모니터링

## 📌 클립 정보
- **예상시간:** 18분
- **유형:** 화면 녹화
- **준비물:** 안티그래비티 + 클로드 코드 연결 완료

---

## 에이전트 매니저란 무엇인가 (3분)

안티그래비티는 에디터와 에이전트 매니저 두 화면으로 구성됩니다.
단축키 `Cmd + E`로 전환합니다.

에이전트 매니저는 에이아이 작업을 관리하는 공간입니다.

**에이전트 매니저에서 할 수 있는 것:**

먼저 여러 작업 세션을 동시에 관리합니다.
세션마다 독립적인 작업이 진행됩니다.

다음으로 각 세션의 진행 상태를 한눈에 봅니다.
어떤 파일을 수정하고 있는지, 어떤 명령어를 실행했는지 확인합니다.

세 번째로 작업을 일시 정지하거나 취소합니다.
에이전트가 잘못된 방향으로 가고 있으면 중간에 개입합니다.

---

## 워크스페이스 생성과 관리 (5분)

**[화면: 에이전트 매니저]**

에이전트 매니저에서 새 워크스페이스를 생성합니다.

워크스페이스는 하나의 프로젝트 단위입니다.
예를 들어 "마케팅 분석", "리텐션 분석" 같은 단위로 분리합니다.

**워크스페이스 생성:**
`+` 버튼 클릭 → 프로젝트 폴더 선택 → 워크스페이스 이름 입력

**워크스페이스 전환:**
에이전트 매니저에서 워크스페이스 목록 클릭
또는 에디터에서 `Cmd + E` 후 워크스페이스 선택

각 워크스페이스는 독립적인 클로드 코드 세션을 가집니다.
프로젝트가 여러 개여도 섞이지 않습니다.

---

## 작업 진행 상태 모니터링 (5분)

**[화면: 에이전트 매니저 — 실행 중]**

클로드 코드가 작업 중일 때 에이전트 매니저에서 진행 상태를 봅니다.

표시되는 정보입니다.
- 현재 실행 중인 명령어
- 생성되거나 수정된 파일 목록
- 사용한 도구 이력 (파일 읽기, 명령어 실행 등)
- 남은 컨텍스트 윈도우 용량

**개입이 필요한 상황:**

에이전트가 원하지 않는 파일을 수정하려 할 때.
예상과 다른 방향으로 진행될 때.
오류가 반복될 때.

이 때 터미널에서 `Ctrl + C`로 현재 작업을 중단하고 새 지시를 입력합니다.

---

## 직접 해보기

**목표**: 에이전트 매니저에서 워크스페이스를 만들고 작업을 모니터링합니다.

**순서**
1. `Cmd + E` 로 에이전트 매니저 열기
2. 새 워크스페이스 생성: `~/ag-test` 폴더 선택
3. `Cmd + E` 로 에디터로 돌아가서 터미널 열기
4. 클로드 코드 실행:

```bash
cd ~/ag-test
claude
```

**클로드에게 이렇게 말합니다**
```
data/ 폴더에 있는 모든 CSV 파일을 읽어서
각 파일의 행수, 컬럼 목록, 결측값 현황을 
reports/data_summary.md 에 정리해줘.
```

→ `Cmd + E`로 에이전트 매니저에서 진행 상태를 확인합니다.
→ 어떤 파일이 생성되는지 실시간으로 모니터링합니다.

---

## 핵심 정리 (30초)

에이전트 매니저는 `Cmd + E`로 에디터와 전환합니다.
워크스페이스 단위로 프로젝트를 분리해서 관리합니다.
작업이 잘못된 방향이면 터미널에서 `Ctrl + C`로 중단하고 재지시합니다.
