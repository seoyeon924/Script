## 서브에이전트란 무엇인가 (4분)

> 📎 **참고 링크**
> - [Claude Code 서브에이전트 문서](https://code.claude.com/docs/en/sub-agents) — 공식 가이드

공식 문서에서 서브에이전트를 이렇게 정의합니다.

"Subagents are specialized AI assistants that handle specific types of tasks. Each subagent runs in its own context window with a custom system prompt, specific tool access, and independent permissions."

서브에이전트는 특정 작업을 전담하는 전문화된 에이아이 어시스턴트입니다.
각 서브에이전트는 독립적인 컨텍스트 창에서 실행됩니다.
커스텀 시스템 프롬프트, 특정 도구 접근, 독립적인 권한을 갖습니다.

클로드가 작업에 맞는 서브에이전트를 자동으로 선택해서 위임(delegate)합니다.

---

## 서브에이전트의 장점 (3분)

**[화면: 장점 목록]**

공식 문서에서 서브에이전트의 장점을 다섯 가지로 설명합니다.

**컨텍스트 보존 (Preserve context)**
탐색과 구현 작업을 메인 대화에서 분리합니다.
메인 컨텍스트가 빠르게 채워지는 것을 방지합니다.

**제약 적용 (Enforce constraints)**
서브에이전트가 사용할 수 있는 도구를 제한할 수 있습니다.
예: 읽기 전용 서브에이전트

**설정 재사용 (Reuse configurations)**
유저 레벨 서브에이전트는 모든 프로젝트에서 사용 가능합니다.

**행동 전문화 (Specialize behavior)**
특정 도메인에 집중된 시스템 프롬프트를 설정합니다.

**다섯 번째, 비용 절감 (Control costs)**
빠르고 저렴한 모델(예: Haiku)로 작업을 처리할 수 있습니다.

## 메인 에이전트 vs 서브에이전트 — 헷갈리지 않기 (4분)

**[화면: 비교표]**

메인 에이전트와 서브에이전트는 생성 방식이 완전히 다릅니다.

**메인 에이전트는 클로드 코드 자체입니다.**

터미널에서 `claude`를 실행하면 그게 메인 에이전트입니다.
별도로 "생성"하는 것이 아닙니다.

```bash
claude   # 이게 메인 에이전트 시작
```

**서브에이전트는 사용자가 정의합니다.**

공식 문서에서 두 가지 방법을 안내합니다.

**방법 1: `/agents` 커맨드 (권장)**

```
/agents
→ Create new agent 선택
→ User-level 또는 Project-level 선택
→ 설명 입력하면 자동 생성
```

**방법 2: 마크다운 파일 직접 작성**

```markdown
# ~/.claude/agents/data-analyst.md

---
name: data-analyst
description: CSV 파일 분석 전문
tools: Read, Glob, Grep, Bash
model: sonnet
---

당신은 데이터 분석 전문가입니다.
CSV 파일을 읽고 통계를 계산하세요.
```

**저장 위치에 따라 범위가 달라집니다.**

| 위치 | 범위 | 우선순위 |
|------|------|----------|
| `.claude/agents/` | 현재 프로젝트 | 높음 |
| `~/.claude/agents/` | 모든 프로젝트 | 낮음 |

**핵심 요약:**

| | 메인 에이전트 | 서브에이전트 |
|---|---|---|
| **생성** | `claude` 실행 (자동) | `/agents` 또는 파일 작성 |
| **개수** | 1개 (고정) | 여러 개 가능 |
| **역할** | 전체 조율, 위임 | 특정 작업 전문 처리 |
| **컨텍스트** | 전체 대화 기억 | 독립적 (격리됨) |

## 내장 서브에이전트 (3분)

**[화면: 내장 서브에이전트 표]**

클로드 코드에는 내장 서브에이전트가 있습니다.
공식 문서에서 소개하는 주요 내장 서브에이전트입니다.

| 이름 | 모델 | 역할 |
|------|------|------|
| **Explore** | Haiku | 코드베이스 탐색, 파일 검색 (읽기 전용) |
| **Plan** | 상속 | 계획 모드에서 리서치 |
| **general-purpose** | 상속 | 복잡한 다단계 작업, 코드 수정 |

클로드가 상황에 맞게 자동으로 이 서브에이전트들을 사용합니다.

예를 들어 "이 프로젝트 구조를 파악해줘"라고 하면 Explore 서브에이전트를 사용합니다.
Explore는 Haiku 모델을 사용해서 빠르고 저렴하게 탐색합니다.

---

## 서브에이전트의 제한사항 (2분)

**[화면: 제한사항]**

공식 문서에서 명시하는 중요한 제한사항입니다.

**서브에이전트는 다른 서브에이전트를 생성할 수 없습니다.**

공식 문서 원문:
"This prevents infinite nesting (subagents cannot spawn other subagents)"

무한 중첩을 방지하기 위해 서브에이전트 안에서 또 서브에이전트를 만들 수 없습니다.

## 직접 해보기

**목표**: `/agents` 명령어로 서브에이전트를 만들고 사용합니다.

**준비 (터미널에 복붙)**
```bash
mkdir ~/subagent-test && cd ~/subagent-test
mkdir -p data
printf "상품,수량,단가\n상품A,10,15000\n상품B,5,25000\n상품C,8,12000" > data/sales.csv
claude
```

**클로드에게 이렇게 말합니다**
```
/agents
```

→ Create new agent 선택
→ User-level 선택
→ 설명: "CSV 파일을 분석하고 통계를 계산하는 에이전트"
→ 도구: Read-only tools 선택
→ 모델: Haiku 선택
→ 저장

**서브에이전트 사용**
```
data/sales.csv를 분석해서 총 매출을 계산해줘
```

→ 클로드가 생성한 서브에이전트에게 위임해서 처리합니다.

## 커스텀 서브에이전트 직접 실행하기

**현재 제약 사항**

대화 안에서 커스텀 에이전트를 서브에이전트로 직접 호출하는 것은 제한될 수 있습니다.
클로드 코드의 Agent 도구는 내장 타입(general-purpose, Explore, Plan 등)만 지원하는 경우가 있습니다.

**확실한 방법 — 터미널에서 직접 실행**

```bash
claude --agent chart-expert "Sample_Superstore 데이터로 매출 바 차트 만들어줘"
```

`--agent` 플래그로 커스텀 에이전트를 지정하면, 해당 에이전트의 시스템 프롬프트와 설정이 적용된 세션이 시작됩니다.

> 📎 **참고 링크**
> - [Claude Code CLI Reference](https://code.claude.com/docs/en/cli-reference) — `--agent` 플래그 설명

## 핵심 정리 (30초)

서브에이전트는 특정 작업을 전담하는 전문화된 에이전트입니다.
`/agents` 명령어 또는 `.claude/agents/` 파일로 생성합니다.
각 서브에이전트는 독립적인 컨텍스트에서 실행됩니다.
서브에이전트는 다른 서브에이전트를 생성할 수 없습니다.
