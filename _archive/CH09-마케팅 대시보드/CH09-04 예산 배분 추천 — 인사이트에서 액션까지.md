## 인사이트에서 행동 추천으로 (4분)

데이터 분석의 최종 목적은 더 나은 결정을 내리는 것입니다.

"SNS의 알오아이가 가장 높다"는 인사이트입니다.
"다음 달 SNS 예산을 20% 늘려라"는 액션입니다.

클로드 코드에게 이 과정도 맡길 수 있습니다.

---

## 예산 배분 추천 지시 (6분)

> "data/output/kpi_by_channel.csv를 분석해서 다음 달 예산 배분 추천안을 만들어줘.
>
> 추천 로직: 알오아이 상위 채널은 예산 증가, 하위 채널은 감소. 전체 예산 총액은 이번 달과 동일하게 유지. 씨피에이가 전체 평균보다 30% 이상 높은 채널은 예산 삭감 대상으로 표시.
>
> 결과 형식: 채널별 이번 달 예산, 추천 예산, 변화율, 변경 이유를 테이블로. 총 3가지 시나리오 제시 (보수적, 중립, 공격적).
>
> reports/budget_recommendation.md 로 저장해줘."

---

## 완성 보고서 생성 지시 (3분)

> "분석 전체를 reports/final_report.md 로 정리해줘. 구성: 분석 배경 → 데이터 개요 → 채널별 성과 요약 → 핵심 인사이트 5가지 → 예산 배분 추천 (보수적 시나리오) → 다음 단계 권고사항. 각 인사이트에 근거 수치 포함."

## 직접 해보기

> **💡 이 클립만 따로 시작한다면** — 먼저 실행해서 데이터 생성
> ```bash
> mkdir -p ~/marketing-project/data/raw ~/marketing-project/data/output ~/marketing-project/charts ~/marketing-project/reports
> cd ~/marketing-project
> python3 -c "
> import pandas as pd, numpy as np, random; random.seed(42)
> dates = pd.date_range('2024-01-01', '2024-03-31', freq='D')
> channels = ['SNS','검색','이메일','디스플레이','유튜브']
> rows = []
> for d in dates:
>     for ch in channels:
>         impr = random.randint(50000,200000); clicks = int(impr * random.uniform(0.01,0.05))
>         conv = int(clicks * random.uniform(0.03,0.12)); spend = random.randint(100000,600000)
>         rev = conv * random.randint(20000,50000)
>         rows.append({'date':str(d.date()),'channel':ch,'impressions':impr,'clicks':clicks,'conversions':conv,'spend':spend,'revenue':rev})
> import pandas as pd; pd.DataFrame(rows).to_csv('data/raw/campaigns.csv',index=False); print('생성 완료')
> "
> ```
