## 주간 PM 리포트 구성 (3분)

피엠이 매주 팀에 공유하는 리포트 구성입니다.

1. **이번 주 핵심 수치** — 디에이유 평균, 주간 활성 사용자 (WAU), Day 7 리텐션
2. **전주 대비 변화** — 각 지표의 증감률과 방향
3. **이상 감지** — 평균 대비 ±20% 이상 변화 항목 자동 표시
4. **피처 현황** — 이번 주 가장 많이 쓴 피처 TOP 3
5. **다음 주 주목 포인트** — 클로드가 데이터 기반으로 제안

## 주간 리포트 자동 생성 지시 (5분)

> "data/raw/user_logs.csv로 지난 7일 기준 주간 피엠 리포트를 작성해줘.
>
> 포함 내용: 이번 주 평균 디에이유, 더블유에이유, Day 7 리텐션율. 전주 대비 증감률. 평균 대비 ±20% 이상 이상 항목 경고 표시. 피처 사용률 TOP 3. 데이터 기반 다음 주 주목 포인트 2가지.
>
> reports/weekly_pm_report.md 로 저장. 제목은 날짜 포함 (예: 2024년 1월 2주차 피엠 주간 리포트)."

## 이상 감지 알림 구조 (4분)

디에이유가 갑자기 떨어지면 자동으로 알 수 있어야 합니다.

> "scripts/pm_monitor.py 를 만들어줘. 이 스크립트는 매일 실행되어 data/raw/user_logs.csv를 읽고 오늘 디에이유가 최근 7일 평균보다 20% 이상 낮으면 'ALERT: 오늘 디에이유가 평균 대비 {차이}% 하락했습니다' 메시지를 출력하게 해줘."

## 직접 해보기

> **💡 이 클립만 따로 시작한다면** — 먼저 실행해서 데이터 생성
> ```bash
> mkdir -p ~/pm-project/data/raw ~/pm-project/data/output ~/pm-project/charts ~/pm-project/reports && cd ~/pm-project
> python3 -c "
> import pandas as pd, random; from datetime import date, timedelta; random.seed(42)
> features = ['검색','추천','즐겨찾기','공유','설정']; start = date(2024,1,1); rows = []
> for uid in range(1000):
>     for day in range(90):
>         rate = 0.6 if day<3 else (max(0.2, 0.6-(day-3)*0.012) if day<30 else 0.2)
>         if random.random() < rate:
>             rows.append({'user_id':f'U{uid:04d}','date':str(start+timedelta(days=day)),'feature_used':random.choice(features)})
> pd.DataFrame(rows).to_csv('data/raw/user_logs.csv',index=False); print('생성 완료:', len(rows), '행')
> "
> ```

## 핵심 정리 (30초)

주간 피엠 리포트 자동화는 수치 계산, 이상 감지, 보고서 작성을 하나의 파이프라인으로 연결합니다.
이상 감지 스크립트를 크론탭으로 매일 실행하면 사람이 직접 확인하지 않아도 됩니다.
