# CH06-06 인터랙티브 차트 — HTML로 살아있는 시각화 만들기

## 📌 클립 정보
- **예상시간:** 14분
- **유형:** 슬라이드 2장 + 화면 녹화
- **준비물:** 파이썬 (플롯리), 클로드 코드, 브라우저

---

## 왜 인터랙티브 차트인가 (3분)

지금까지 만든 차트는 정적 이미지(피엔지 파일)입니다.
보기는 좋지만 한계가 있습니다.
특정 데이터 포인트를 클릭해서 세부 정보를 볼 수 없습니다.
확대 축소가 안 됩니다.
슬라이더로 기간을 바꿀 수 없습니다.

인터랙티브 차트는 이 한계를 넘습니다.

**구체적으로 말하면,**

종이 지도와 구글 지도의 차이입니다.
종이 지도는 보여주는 것이 전부입니다.
구글 지도는 확대, 검색, 길 찾기가 됩니다.
인터랙티브 차트도 마찬가지입니다.

**인터랙티브 차트가 필요한 상황:**
- 보고서를 브라우저에서 공유할 때
- 데이터 포인트가 많아서 세부 확인이 필요할 때
- 기간이나 필터를 실시간으로 조작해야 할 때

---

## Plotly로 인터랙티브 차트 자동화 (5분)

플롯리(Plotly)는 파이썬에서 가장 많이 쓰는 인터랙티브 시각화 라이브러리입니다.
에이치티엠엘 파일로 저장하면 브라우저에서 바로 열립니다.

클로드에게 지시하는 방법입니다.

> "data/campaigns.csv를 읽어서 플롯리로 인터랙티브 차트를 만들어줘. 채널별 알오아이를 막대 차트로 표시하고, 각 막대에 마우스를 올리면 지출, 전환수, 알오아이 세 가지 수치가 툴팁으로 보이게 해줘. 에이치티엠엘 파일로 저장: charts/roi_interactive.html."

에이전트가 플롯리 코드를 작성하고 에이치티엠엘로 내보냅니다.
브라우저에서 열면 클릭, 확대, 범례 토글이 됩니다.

---

## Chart.js 기반 HTML 자동 생성 (4분)

차트 제이에스(Chart.js)는 자바스크립트 라이브러리입니다.
외부 의존성 없이 에이치티엠엘 파일 하나로 완성됩니다.
공유하거나 웹에 올리기에 적합합니다.

클로드에게 지시하는 방법입니다.

> "data/monthly_sales.csv를 읽어서 차트 제이에스로 인터랙티브 라인 차트를 에이치티엠엘로 만들어줘. 조건은: 채널별로 색이 다른 선. 상단에 채널 필터 버튼 추가 (클릭하면 해당 채널 선 토글). 파일 저장: charts/monthly_interactive.html. 에이치티엠엘 파일 하나에 모두 포함해줘 (씨디엔 링크 사용)."

에이전트가 에이치티엠엘과 자바스크립트 코드를 작성합니다.
외부 라이브러리 없이 파일 하나를 공유하면 됩니다.

## 직접 해보기

**목표**: 인터랙티브 에이치티엠엘 차트를 자동 생성하고 브라우저에서 확인합니다.

**준비 (터미널에 복붙)**
```bash
pip install plotly -q

cd ~/chart-test
claude
```

**클로드에게 이렇게 말합니다**
```
data/sales.csv를 읽어서 플롯리로 인터랙티브 차트를 만들어줘.
- 채널별 월별 매출을 그룹 막대 차트로 표시
- 툴팁: 채널명, 월, 매출 표시
- 범례 클릭으로 채널 토글 가능
- charts/interactive.html로 저장
```

**저장 후 브라우저에서 열기 (터미널)**
```bash
open charts/interactive.html
```

→ 브라우저에서 막대를 클릭하고 툴팁을 확인합니다.
