# CH00-04 개발 환경 셋업 — 클로드 코드 설치와 3가지 실행 방법

## 📌 클립 정보
- **예상시간:** 25분
- **유형:** 화면 녹화 (브라우저 + 터미널 + 에디터)
- **준비물:** 맥 또는 윈도우, 인터넷 연결, 클로드 계정 (프로 또는 에이피아이 키)

---

## 오프닝 (1분)

이 클립에서는 클로드 코드를 어디서 내려받는지, 그리고 실제로 어떻게 실행하는지 세 가지 방법을 모두 다룹니다.

세 가지 방법은 이렇습니다.

**터미널에서 직접 실행하는 방법입니다. 가장 기본이고 강력한 방법입니다.**
**안티그래비티 에디터에서 실행하는 방법입니다. 클로드 프로 구독이 있다면 에이피아이 토큰을 아끼면서 쓸 수 있는 방법입니다.**
**클로드 데스크탑 앱에서 실행하는 방법입니다. 마우스 클릭으로 편리하게 사용할 수 있는 방법입니다.**

세 가지 중 하나만 써도 충분합니다. 상황에 따라 골라 쓰면 됩니다.

---

## 클로드 코드를 어디서 내려받는가 (3분)

클로드 코드를 받을 수 있는 공식 경로는 세 가지입니다.

**[화면: 브라우저]**

**① 공식 다운로드 페이지**
`https://claude.ai/code`

클로드 데스크탑 앱 다운로드 링크가 있습니다.
맥, 윈도우 모두 지원합니다.

**② 공식 문서 (설치 가이드)**
`https://code.claude.com/docs`

터미널 설치 명령어, 아이디이 확장 설치 방법, 데스크탑 앱 사용법이 모두 정리되어 있습니다.

**③ 구글 안티그래비티 공식 사이트**
- 다운로드: `https://antigravity.google/download`
- 공식 문서: `https://antigravity.google/docs/`
- 시작 가이드: `https://antigravity.google/docs/get-started`

구글이 만든 에이아이 코드 에디터입니다.
에디터와 에이전트 매니저를 함께 제공합니다.
클로드 코드를 안티그래비티 내장 터미널에서 실행합니다.

---

## 사전 준비 (1분)

**터미널 방법은 노드제이에스 별도 설치가 필요하지 않습니다.**
클로드 코드는 네이티브 설치 방식을 사용합니다.

클로드 닷에이아이 프로 또는 맥스 구독 계정이 있으면 에이피아이 키 없이 오이오스(OAuth) 로그인으로 바로 사용할 수 있습니다.
에이피아이 키는 자동화 파이프라인이나 헤드리스 실행 등 고급 사용 시에 활용합니다.

---

## ① 터미널에서 클로드 코드 실행하기 (8분)

가장 기본적인 방법입니다.
에이피아이 키가 있으면 어디서든 사용할 수 있습니다.

### 설치

**맥 / 리눅스 / WSL:**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**윈도우 파워쉘:**
```powershell
irm https://claude.ai/install.ps1 | iex
```

**윈도우 CMD:**
```batch
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**윈도우 사용자는 Git for Windows를 먼저 설치해야 합니다.**
`https://git-scm.com/downloads/win`

설치 확인:
```bash
claude --version
```

버전 번호가 나오면 설치 완료입니다.

### 에이피아이 키 발급

**[화면: 브라우저 — console.anthropic.com]**

`https://console.anthropic.com` 에 접속합니다.
계정이 없으면 회원가입을 먼저 합니다.

로그인 후 왼쪽 메뉴에서 `API Keys`를 선택합니다.
`Create Key` 버튼을 누릅니다.
키 이름을 입력하고 `Create API Key`를 클릭합니다.

**중요:** 이 화면에서만 전체 키를 볼 수 있습니다.
지금 바로 복사해서 안전한 곳에 저장합니다.

### 에이피아이 키 등록

**맥/리눅스:**
```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-여기에키입력"' >> ~/.zshrc
source ~/.zshrc
```

**윈도우 파워쉘 (현재 세션):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-여기에키입력"
```

### 첫 실행

```bash
mkdir ~/test-project
cd ~/test-project
claude
```

프롬프트가 표시되면 정상 실행입니다.

```
안녕, 이 폴더에 hello.txt 파일 만들어줘. 내용은 "클로드 코드 시작"
```

클로드 코드가 파일을 생성하는 전 과정이 터미널에 표시됩니다.
결과만 보여주는 게 아니라 과정이 투명하게 보이는 것이 클로드 코드의 특징입니다.

세션 종료:
```bash
/exit
```

또는 `Ctrl + D`를 누릅니다.

## ② 안티그래비티 에디터에서 클로드 코드 실행하기 (8분)

클로드 프로 구독이 있으면 에이피아이 키 없이 사용할 수 있습니다.
에이피아이 토큰 비용이 따로 청구되지 않습니다.
코드 편집기와 클로드 코드를 한 화면에서 동시에 쓸 수 있습니다.

### 안티그래비티 설치

**[화면: 브라우저 — antigravity.google/download]**

`https://antigravity.google/download` 에 접속합니다.

지원 환경을 먼저 확인합니다.

| 운영체제 | 지원 여부 | 최소 버전 |
|---------|---------|---------|
| 맥 (애플 실리콘) | ✅ 지원 | 맥오에스 12 몬터레이 |
| 맥 (인텔 X86) | ❌ 미지원 | — |
| 윈도우 | ✅ 지원 | 윈도우 10 64비트 |
| 리눅스 | ✅ 지원 | glibc 2.28 이상 |

**중요:** 맥은 애플 실리콘(M1/M2/M3/M4) 전용입니다. 인텔 맥은 지원하지 않습니다.

운영체제에 맞는 설치 파일을 내려받고 실행합니다.
설치가 완료되면 구글 계정으로 로그인합니다.

### 에디터와 에이전트 매니저

**[화면: 안티그래비티 실행]**

안티그래비티는 두 가지 화면으로 구성됩니다.

- **에디터**: 코드와 파일을 편집하는 공간입니다
- **에이전트 매니저**: 에이아이 에이전트 작업을 관리하는 공간입니다

두 화면 전환 단축키: `Cmd + E`

### 터미널 + 에디터 동시 사용 설정

클로드 코드를 에디터 왼쪽 터미널에서 실행하고, 오른쪽 패널에서 파일을 편집하는 방법입니다.

**[화면: 안티그래비티 — 레이아웃 설정]**

**1단계: 프로젝트 폴더 열기**

안티그래비티 상단 메뉴 → `File` → `Open Folder`
분석할 프로젝트 폴더를 선택합니다.

**2단계: 내장 터미널 열기**

단축키: `Ctrl + \`` (역따옴표, 숫자 1 왼쪽 키)
또는 상단 메뉴 → `View` → `Terminal`

화면 하단 또는 좌측에 터미널 패널이 열립니다.

**3단계: 화면 분할 설정 — 터미널 왼쪽, 에디터 오른쪽**

터미널을 왼쪽 패널로 분리하려면:
- 터미널 패널 상단의 분리(detach) 버튼을 클릭합니다
- 또는 터미널 패널을 드래그해서 왼쪽 사이드에 붙입니다

**[화면: 분할 완성 상태]**

왼쪽: 터미널 (클로드 코드 실행)
오른쪽: 파일 편집기 + 클로드 채팅 패널

**4단계: 터미널에서 클로드 코드 실행**

```bash
cd ~/내프로젝트폴더
claude
```

**[화면: 실제 실행 상태]**

왼쪽 터미널에서 클로드 코드에게 지시합니다.
클로드 코드가 파일을 수정하면 오른쪽 에디터에서 실시간으로 변경 내용이 표시됩니다.
파일을 직접 열거나 수정하고 싶을 때는 오른쪽 에디터를 사용합니다.

### 클로드 프로로 토큰 절약하는 원리

**[화면: 슬라이드 — 비교표]**

에이피아이 방식과 클로드 프로 방식의 차이입니다.

| 항목 | 에이피아이 키 방식 | 클로드 프로 방식 (안티그래비티) |
|------|------------------|-------------------------------|
| 비용 | 토큰당 청구 | 월 구독 고정 |
| 무거운 작업 | 비용 증가 | 구독 내 포함 |
| 사용 한도 | 없음 (청구됨) | 프로 플랜 한도 내 |
| 적합한 상황 | 대량 자동화, 서버 실행 | 일상적인 코딩 작업 |

짧은 작업이 많고 월 사용량이 예측 가능할 때는 클로드 프로가 유리합니다.
장시간 파이프라인이나 대량 파일 처리는 에이피아이 키 방식이 유리합니다.

## ③ 클로드 데스크탑 앱에서 실행하기 (4분)

마우스로 클릭해서 사용하는 그래픽 방식입니다.
터미널이 익숙하지 않아도 시작할 수 있습니다.

### 설치

**[화면: 브라우저]**

`https://claude.ai/code` 에 접속합니다.
`Download for Mac` 또는 `Download for Windows` 버튼을 클릭합니다.
내려받은 설치 파일을 실행합니다.

### 첫 실행

**[화면: 클로드 데스크탑 앱]**

앱을 실행하면 상단에 `Code` 탭이 있습니다.
이 탭을 클릭하면 클로드 코드 인터페이스가 열립니다.

**세션 시작:**

1. `Environment` → `Local` (내 컴퓨터에서 실행)
2. `Project folder` → 작업할 폴더 선택
3. 메시지 입력창에 지시를 입력합니다

### 데스크탑 앱 전용 기능

터미널 방식에는 없는 기능들이 있습니다.

****비주얼 디프 뷰**입니다.**
클로드가 파일을 수정할 때 변경 전후를 나란히 비교해서 보여줍니다.
수락하거나 거부할 수 있습니다.

****병렬 세션**입니다.**
여러 작업을 동시에 실행할 수 있습니다.
각 세션이 독립적인 깃 워크트리로 격리됩니다.

****깃허브 피알 모니터링**입니다.**
풀 리퀘스트 상태를 확인하고 자동으로 수정 제안을 받을 수 있습니다.

****예약 작업**입니다.**
매일 특정 시간에 클로드가 자동으로 작업을 실행합니다.

## 세 가지 방법 비교 요약 (1분)

**[화면: 비교 슬라이드]**

| 방법 | 적합한 상황 | 필요한 것 |
|------|------------|----------|
| ① 터미널 | 자동화, 서버, 대용량 처리 | 에이피아이 키 |
| ② 안티그래비티 | 일상 코딩, 토큰 절약 | 클로드 프로 구독 |
| ③ 데스크탑 앱 | GUI 선호, 비주얼 리뷰 | 클로드 프로 또는 에이피아이 키 |

이 강의에서는 터미널 방법을 기본으로 사용합니다.
실습 환경이 갖춰지면 안티그래비티나 데스크탑 앱으로 전환해도 모든 내용이 동일하게 적용됩니다.
