## HR 데이터의 구성 요소 (4분)

인사 분석에 사용하는 주요 데이터입니다.

| 데이터 유형 | 주요 컬럼 | 분석 목적 |
|-----------|---------|---------|
| 직원 마스터 | employee_id, department, level, hire_date | 인력 구성 파악 |
| 성과 데이터 | employee_id, period, score, rating | 성과 분포 분석 |
| 이직 데이터 | employee_id, leave_date, reason | 이직률 및 원인 분석 |
| 급여 데이터 | employee_id, salary, last_raise_date | 보상 형평성 분석 |

## 샘플 HR 데이터 생성 지시 (5분)

> "인사 분석용 샘플 데이터를 생성해줘. 직원 500명. 데이터: 부서 5개 (개발, 마케팅, 영업, 운영, 인사), 직급 3단계 (주니어, 시니어, 리드), 입사 날짜 2020~2023, 분기별 성과 점수 1~5, 이직 여부 (이직률 약 15%). data/raw/ 에 employees.csv, performance.csv, attrition.csv 세 파일로 저장해줘.
>
> 저장 후 기본 통계를 요약해줘. 부서별 인원, 평균 성과 점수, 이직률."

---

## 직접 해보기

**준비 (터미널에 복붙)**

> 아래 코드로 HR 분석용 샘플 데이터 3종을 즉시 생성합니다.

```bash
mkdir -p ~/hr-project/data/raw ~/hr-project/data/output ~/hr-project/charts ~/hr-project/reports
cd ~/hr-project
python3 -c "
import pandas as pd, random; from datetime import date, timedelta; random.seed(42)
depts=['개발','마케팅','영업','운영','인사']; levels=['주니어','시니어','리드']
emps,perf,attr=[],[],[]
for eid in range(500):
    dept=random.choice(depts); level=random.choices(levels,weights=[5,3,2])[0]
    hire=date(2020,1,1)+timedelta(days=random.randint(0,1460))
    emps.append({'employee_id':f'E{eid:03d}','department':dept,'level':level,'hire_date':str(hire)})
    for q in ['2023-Q1','2023-Q2','2023-Q3','2023-Q4']:
        s=round(max(1.0,min(5.0,random.gauss(3.2,0.8))),1)
        perf.append({'employee_id':f'E{eid:03d}','period':q,'score':s,'rating':'우수' if s>=4 else '보통' if s>=2.5 else '미흡'})
    if random.random()<0.15:
        attr.append({'employee_id':f'E{eid:03d}','leave_date':str(date(2023,1,1)+timedelta(days=random.randint(0,365))),'reason':random.choice(['이직','개인사유','계약만료'])})
pd.DataFrame(emps).to_csv('data/raw/employees.csv',index=False)
pd.DataFrame(perf).to_csv('data/raw/performance.csv',index=False)
pd.DataFrame(attr).to_csv('data/raw/attrition.csv',index=False)
print(f'생성 완료: 직원 {len(emps)}명 / 성과 {len(perf)}건 / 이직 {len(attr)}건')
"
claude
```

**클로드에게 이렇게 말합니다**
```
HR 분석 샘플 데이터 생성해줘.
- 직원 500명
- 부서: 개발/마케팅/영업/운영/인사
- 직급: 주니어/시니어/리드
- 분기별 성과 점수 1~5
- 이직률 약 15%
- employees.csv, performance.csv, attrition.csv → data/raw/
- 생성 후 기본 통계 요약 (부서별 인원, 평균 성과, 이직률)
```
