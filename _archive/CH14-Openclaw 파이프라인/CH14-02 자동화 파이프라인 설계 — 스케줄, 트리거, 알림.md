# CH14-02 자동화 파이프라인 설계 — 스케줄, 트리거, 알림

## 📌 클립 정보
- **예상시간:** 17분
- **유형:** 화면 녹화
- **준비물:** 오픈클로 설치, 텔레그램 연동 완료

---

## 세 가지 자동화 패턴 (4분)

오픈클로로 구성하는 주요 자동화 패턴입니다.

**패턴 1 — 시간 기반 스케줄**
"매주 월요일 오전 8시에 주간 마케팅 리포트 생성"
가장 단순하고 예측 가능한 방식입니다.

**패턴 2 — 파일 변경 감지**
"data/raw/ 폴더에 새 파일이 생기면 자동 분석 실행"
데이터가 들어오는 즉시 처리합니다.

**패턴 3 — 메시지 트리거**
"텔레그램에서 '분석 실행' 메시지를 보내면 바로 실행"
사람이 원할 때 즉시 실행합니다.

---

## 스케줄 자동화 설정 방법 (6분)

오픈클로 HEARTBEAT.md에 반복 임무를 정의합니다.

```markdown
## 매일 반복 임무

매일 오전 9시:
1. ~/marketing-project/data/raw/ 최신 CSV 확인
2. 새 파일 있으면 8단계 파이프라인 실행
3. 결과 요약을 텔레그램으로 전송

매주 월요일 오전 8시:
1. 지난 주 마케팅 성과 주간 리포트 생성
2. HR 이직 위험군 업데이트
3. PM 케이피아이 주간 현황 취합
4. 통합 요약 텔레그램 발송
```

텔레그램으로 직접 메시지를 보내면 즉시 실행도 됩니다.

```
# 텔레그램에서 전송
지금 마케팅 파이프라인 실행해줘.
```

오픈클로가 받아서 즉시 분석을 시작합니다.

---

## 알림 메시지 설계 (3분)

결과 알림은 간결하게 설계합니다.

예시 알림 형식:

```
📊 [마케팅 주간 리포트] 2024-01-08 완료

핵심 지표:
• 총 광고비: 12,300,000원
• 평균 알오아이: 143%
• 최고 채널: 검색 (알오아이 210%)

⚠️ 주목: 디스플레이 알오아이 -12% 하락
📁 상세 리포트: reports/weekly_2024_01_08.md
```

이 형식을 CLAUDE.md에 정의하면 에이전트가 자동으로 이 형식으로 전송합니다.

---

## 직접 해보기

**목표**: 매일 자동 실행되는 마케팅 분석 파이프라인을 오픈클로에 등록합니다.

**HEARTBEAT.md에 추가 (메모리 파일)**
```
## 매일 반복 임무
1. ~/marketing-project/data/raw/ 확인
2. 새 파일 있으면 8단계 파이프라인 실행
3. 텔레그램으로 3줄 요약 전송
```

**직접 트리거 테스트 (텔레그램으로)**
```
마케팅 분석 지금 실행해줘. 결과 텔레그램으로 보내줘.
```

→ 오픈클로가 분석을 실행하고 결과를 텔레그램으로 전송합니다.

## 핵심 정리 (30초)

오픈클로 자동화 패턴은 시간 기반, 파일 감지, 메시지 트리거 세 가지입니다.
HEARTBEAT.md에 반복 임무를 정의하면 에이전트가 자동으로 수행합니다.
결과 알림 형식을 CLAUDE.md에 정의하면 일관된 요약이 전송됩니다.
