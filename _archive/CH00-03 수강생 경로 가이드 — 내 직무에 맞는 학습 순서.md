# CH00-03 수강생 경로 가이드 — 내 직무에 맞는 학습 순서

## 📌 클립 정보
- **예상시간:** 10분
- **유형:** 슬라이드 전용
- **슬라이드 수:** 6장

---

## 오프닝 (1분)

이 강의는 총 60개 클립으로 구성됩니다.

처음부터 순서대로 모두 보는 것이 가장 이상적이지만, 현실적으로 직무와 목적에 따라 우선순위가 다릅니다.
이 클립에서는 네 가지 수강생 유형별로 권장 학습 경로를 안내합니다.

---

## 공통 필수 챕터 (2분)

직무에 관계없이 CH00과 CH01은 반드시 먼저 봐야 합니다.

**CH00 — 강의 준비 4클립**
환경 셋업과 강의 구조 이해. 기반이 없으면 이후 내용이 연결되지 않습니다.

**CH01 — 클로드 코드 기본 활용 5클립**
에이전트 구조, 클로드엠디, 플랜 모드, 비용 관리.
이 챕터를 이해해야 이후 챕터의 실습이 가능합니다.

---

## 경로 A — 데이터 분석가 (2분)

**대상**: 에스큐엘, 엑셀, 태블로 등으로 업무 중. 반복 작업 자동화가 목적.

**권장 순서**:
```
CH00 → CH01 → CH02 → CH05 → CH06 → CH10 → CH12
```

**이유**:
- CH02 서브에이전트: 반복 작업을 위임하는 구조 이해
- CH05 엠씨피 연동: 에스큐엘 데이터베이스 연결
- CH06 시각화 전략: 어떤 차트를 자동으로 만들지 설계
- CH10 에이비 테스트, CH12 리텐션 분석: 실제 분석 시나리오 실습

**예상 소요 시간**: 핵심 경로만 약 8시간

---

## 경로 B — 마케터 / 기획자 (2분)

**대상**: 코딩 경험 없음. 데이터 리포트 업무 있음. AI 자동화 시작점을 찾고 있음.

**권장 순서**:
```
CH00 → CH01 → CH02 → CH09 → CH11
```

**이유**:
- CH02 서브에이전트: 반복 요청 처리 구조
- CH09 마케팅 대시보드: 채널별 알오아이, 전환율 시각화 실전 프로젝트
- CH11 피엠 케이피아이: 지표 자동 정리와 보고서 생성

**중요**: 코딩을 몰라도 됩니다. 클로드 코드에게 "이 데이터에서 채널별 클릭률 뽑아줘"라고 말하는 방식입니다. 명령을 어떻게 구성하는지가 핵심입니다.

**예상 소요 시간**: 핵심 경로만 약 6시간

---

## 경로 C — 피엠 (PM) (1분)

**대상**: 데이터를 읽는 것은 가능. 직접 뽑거나 자동화하고 싶음.

**권장 순서**:
```
CH00 → CH01 → CH02 → CH11 → CH10
```

**이유**:
- CH11 피엠 케이피아이: 대시보드 자동 갱신, 지표 모니터링
- CH10 에이비 테스트: 실험 결과 자동 분석과 시각화

**예상 소요 시간**: 핵심 경로만 약 6시간

---

## 경로 D — 개발자 / AI 엔지니어 (1분)

**대상**: 코딩 능숙. 에이전트 시스템 설계와 자동화 파이프라인 구축 목적.

**권장 순서**:
```
CH00 → CH01 → CH02 → CH03 → CH04 → CH05 → CH08 → CH14
```

**이유**:
- CH03 에이전트 팀 코워크: 역할 분리와 병렬 작업 설계
- CH04 멀티 환경: 로컬, 클라우드, 서버 환경 구성
- CH05 엠씨피: 외부 시스템 연결 및 툴 커스터마이징
- CH08 Antigravity: 시각화 자동화 파이프라인
- CH14 오픈클로 파이프라인: 완전 자동화 시스템 완성

**예상 소요 시간**: 핵심 경로만 약 10시간

---

## 마무리 (1분)

본인 직무에 맞는 경로를 확인했습니다.

어떤 경로를 선택하더라도 CH00과 CH01은 반드시 먼저 완료하길 권장합니다.
이 두 챕터를 마치면 이후 어떤 챕터든 독립적으로 진행 가능합니다.

다음 클립은 CH00-04입니다. 개발 환경 셋업을 단계별로 진행합니다.
