# CH10-03 실전 — A/B 테스트 리포트 자동화

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 화면 녹화 중심 (실습)
- **준비물:** CH10-01~02 선행 필수

---

## 학습 목표 선언 (30초)

이 클립을 마치면 한 가지를 할 수 있습니다.

Claude Code로 A/B 테스트 데이터를 입력하면 분석, 시각화, 리포트 생성, 공유까지 자동화할 수 있습니다.

---

## 리포트 템플릿 정의 (4분)

**[화면: CLAUDE.md 작성]**

A/B 테스트 리포트의 표준 구조를 정의합니다:

```markdown
# A/B 테스트 리포트 자동화

## 리포트 구조
1. 실험 개요
   - 테스트 이름, 기간, 대상
   - 가설 (H0, H1)
2. 결과 요약
   - A/B 전환율, 차이
   - p-value, 유의성 판단
3. 시각화
   - 전환율 비교 차트
   - 신뢰구간 차트
4. 결론 및 권장사항
   - 적용 여부 추천
   - 예상 영향 (연간 전환 증가량)

## 출력 형식
- HTML 리포트: output/report.html
- PDF 리포트: output/report.pdf
- Slack 요약: 채널에 자동 발송
```

---

## 전체 파이프라인 실행 (5분)

**[화면: Claude Code 실행]**

**클로드에게 이렇게 말합니다:**
```
A/B 테스트 리포트를 생성해줘.

실험 정보:
- 이름: 결제 버튼 색상 테스트
- 기간: 2024-01-15 ~ 2024-01-28 (14일)
- A: 파란색 버튼 (기존)
- B: 초록색 버튼 (신규)

데이터:
- A: 방문 25,000명, 구매 625명
- B: 방문 25,000명, 구매 775명

리포트에 포함할 것:
1. 통계 분석 (전환율, p-value, 신뢰구간)
2. 차트 3개 (비교, 신뢰구간, 추이)
3. 비즈니스 임팩트 계산 (월간 구매 증가 예측)
4. 최종 권장사항

output/payment-button-test.html로 저장해.
```

Claude Code가 자동으로 전체 리포트를 생성합니다.

## 생성된 리포트 확인 (3분)

**[화면: 브라우저 — 리포트 미리보기]**

생성된 리포트 구조:

```
┌─────────────────────────────────────────────┐
│  📊 A/B 테스트 리포트                       │
│  결제 버튼 색상 테스트                       │
├─────────────────────────────────────────────┤
│  📋 실험 개요                               │
│  기간: 2024-01-15 ~ 01-28 | 샘플: 50,000명  │
├─────────────────────────────────────────────┤
│  🎯 결과 요약                               │
│  A 전환율: 2.50% | B 전환율: 3.10%          │
│  차이: +0.6%p (+24%) | p-value: 0.0003      │
│  결론: ✅ 통계적으로 유의함                  │
├─────────────────────────────────────────────┤
│  📈 시각화                                  │
│  [전환율 비교] [신뢰구간] [일별 추이]        │
├─────────────────────────────────────────────┤
│  💰 비즈니스 임팩트                         │
│  월간 추가 구매: +1,800건                   │
│  연간 추가 매출: 약 5.4억원                 │
├─────────────────────────────────────────────┤
│  ✅ 권장사항                                │
│  B(초록색 버튼)를 전체 적용하세요.          │
└─────────────────────────────────────────────┘
```

## Slack 자동 공유 (2분)

**[화면: Slack 메시지]**

리포트 생성과 동시에 팀에 공유합니다:

**클로드에게 추가 요청:**
```
리포트 요약을 Slack #product 채널에 보내줘.
핵심 수치와 결론, 리포트 링크 포함해서.
```

Slack 메시지 예시:
```
📊 A/B 테스트 완료: 결제 버튼 색상

결과: B(초록색)가 A(파란색)보다 24% 높은 전환율 ✅
통계적 유의성: p < 0.001
권장: B 적용

📎 상세 리포트: https://...
```

```bash
cd ~/ab-test-viz
claude
```

**클로드에게 이렇게 말합니다**
```
A/B 테스트 리포트 생성해줘:

실험: 이메일 제목 테스트
- A: "회원님을 위한 특별 할인"
- B: "오늘만! 50% 할인 쿠폰 🎁"

데이터:
- A: 발송 10,000명, 오픈 1,200명
- B: 발송 10,000명, 오픈 1,580명

분석 + 차트 + 비즈니스 임팩트 + 권장사항 포함해서

```

**확인**
```bash
open output/email-subject-test.html
```

## 핵심 정리 (1분)

A/B 테스트 리포트는 분석, 시각화, 비즈니스 임팩트, 권장사항을 포함합니다.
Claude Code로 데이터만 주면 전체 리포트가 자동 생성됩니다.
Slack 연동으로 팀에 즉시 공유할 수 있습니다.
