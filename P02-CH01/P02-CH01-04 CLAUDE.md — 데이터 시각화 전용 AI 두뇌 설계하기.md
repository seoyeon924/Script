# P02-CH01-04 CLAUDE.md — 데이터 시각화 전용 AI 두뇌 설계하기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 3~4장 + 화면 녹화
- **준비물:** 텍스트 에디터, 샘플 프로젝트 폴더

---

## 오프닝 (1분)

Claude Code를 쓸 때 매 세션마다 프로젝트 맥락을 반복 설명하는 건 비효율적입니다.
CLAUDE.md는 그 맥락을 파일에 저장해두는 방식이에요.
데이터 시각화 프로젝트 전용으로 설계하면 매 분석마다 자동으로 이 규칙이 적용됩니다.

---

## CLAUDE.md에 넣을 내용 (4분)

**① 프로젝트 개요** — 이 프로젝트가 뭘 하는지
**② 폴더 구조** — 데이터, 스크립트 위치
**③ 자주 쓰는 명령어** — 실행, 테스트 명령어
**④ 시각화 규칙** — 차트 선택 기준, 색상, 브랜드 가이드
**⑤ 금지 사항** — 원본 데이터 수정 금지 등

---

## 데이터 시각화 전용 CLAUDE.md 템플릿 (7분)

```markdown
# 프로젝트: [프로젝트명] 데이터 시각화 대시보드

## 프로젝트 개요
[어떤 데이터로 무엇을 시각화하는 프로젝트인지]

## 폴더 구조
- data/raw/       : 원본 데이터 (수정 금지)
- data/processed/ : 전처리 완료 데이터
- charts/         : 생성된 차트 (PNG, HTML)
- reports/        : 최종 리포트 (Markdown)
- scripts/        : 분석 스크립트

## 기술 스택
- Python 3.11, pandas, matplotlib, plotly
- D3.js (인터랙티브 차트)
- Tableau (대시보드)

## 시각화 규칙
- 시간 데이터 → 라인 차트
- 카테고리 비교 (7개 이하) → 세로 막대 차트
- 카테고리 비교 (8개 이상) → 가로 막대 차트
- 구성 비율 → 파이 차트 (5개 이하만)
- 두 변수 관계 → 스캐터 플롯

## 차트 공통 요구사항
- 제목: 데이터에서 발견한 핵심 인사이트 한 줄
- 색상: 강조값 1개만 진한 파랑(#1E3A5F), 나머지 연한 회색(#CCCCCC)
- 한국어 레이블 사용
- 저장: charts/ 폴더에 PNG 및 HTML

## 데이터 처리 규칙
- data/raw/ 파일은 절대 수정하지 않는다
- 전처리 완료 데이터는 data/processed/에 저장
- 결측값: 수치는 평균 대체, 카테고리는 'Unknown'
- 날짜: YYYY-MM-DD 형식으로 통일
```

## CLAUDE.md 계층 구조 (2분)

- `~/.claude/CLAUDE.md` — 글로벌 (내 컴퓨터 전체 적용)
- `my-project/CLAUDE.md` — 프로젝트 (팀 공유, Git 커밋)
- `my-project/CLAUDE.local.md` — 로컬 개인 (나만 적용)

좁은 범위가 넓은 범위보다 우선 적용됩니다.

---

## 핵심 정리 (1분)

CLAUDE.md 하나로 반복 설명이 사라집니다.
시각화 규칙을 정의해두면 이후 모든 분석에서 자동으로 적합한 차트를 선택합니다.
`/init` 명령어로 Claude가 자동으로 초안을 만들어줄 수 있습니다.
