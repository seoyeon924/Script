## 본문

### Claude Code 표준 프로젝트 구조

```
my_project/
│
├── CLAUDE.md                  ← 프로젝트 기억 · 팀 공유
│
├── .claude/
│   ├── settings.json          ← 권한 · Hooks · 환경변수 설정
│   ├── settings.local.json    ← 나만 적용 · .gitignore 처리
│   └── commands/              ← 슬래시 커맨드 정의
│
├── skills/                    ← 작업 유형에 따라 자동 활성화
│
├── agents/                    ← 서브에이전트 정의
│
├── .mcp.json                  ← MCP 서버 연결 설정
│
├── data/
│   ├── raw/                   ← 원본 데이터 (수정 금지)
│   └── processed/             ← 전처리 완료 데이터
│
├── scripts/                   ← 분석 스크립트
├── charts/                    ← 생성된 차트
└── reports/                   ← 최종 리포트
```

### 데이터 시각화 프로젝트 특화 구조

데이터 시각화 프로젝트에서 중요한 원칙:
- `data/raw/` — 원본 데이터는 절대 수정하지 않습니다
- `data/processed/` — 전처리한 데이터를 여기에 저장합니다
- `charts/` — 생성된 PNG, HTML 차트를 저장합니다
- `reports/` — 최종 마크다운 리포트를 저장합니다

### Claude에게 구조 파악 요청하기

새 프로젝트를 시작할 때 Claude에게:
```
이 폴더 구조를 분석하고
데이터 시각화 프로젝트에 맞는 폴더 구조를 만들어줘.
CLAUDE.md도 초안 작성해줘.
```

Claude가 `/init` 명령어로 자동으로 구조를 파악하고 CLAUDE.md를 만들어줍니다.

## 핵심 정리 (30초)

Claude Code 프로젝트의 핵심 파일은 CLAUDE.md와 .claude/settings.json입니다.
데이터 프로젝트는 data/raw → processed → charts → reports 흐름을 따릅니다.
다음 클립에서는 파일 읽기·쓰기·실행과 Plan Mode를 배웁니다.
