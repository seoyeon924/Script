## 오프닝 (1분)

지난 클립에서 파일을 만들고, 데이터를 분석하고, 차트를 그려봤습니다.
이번 클립에서는 한 걸음 물러나서 "프로젝트를 어떻게 구성하면 좋을까"를 생각합니다.

폴더 구조가 엉망이면 Claude도 헤맵니다.
반대로 잘 정리된 구조라면, Claude가 파일들을 읽고 맥락을 파악하는 속도가 훨씬 빠릅니다.

---

## Claude Code가 프로젝트를 파악하는 방법 (2분)

**[화면: 슬라이드]**

Claude Code는 세션을 시작할 때 현재 폴더 안의 파일들을 훑어봅니다.
무엇이 있는지, 어떤 프로젝트인지를 파악한 뒤 작업을 시작합니다.

이때 참고하는 것들:
1. **CLAUDE.md** — 프로젝트 규칙과 기억 (다음 클립에서 만들 예정)
2. **폴더 이름** — data, scripts, charts 같은 이름으로 역할을 추론
3. **파일 목록** — 어떤 데이터가 있는지 파악

폴더 구조가 명확할수록 Claude가 잘못된 파일을 건드리는 실수가 줄어듭니다.

---

## 데이터 시각화 표준 폴더 구조 (3분)

**[화면: 슬라이드]**

이 강의에서 사용할 폴더 구조입니다.

```
my-viz-project/
│
├── CLAUDE.md                  ← 프로젝트 기억 · 규칙 · 팀 공유 가능
├── .claude/
│   └── settings.json          ← 권한 · MCP 연결 설정
│
├── data/
│   ├── raw/                   ← 원본 데이터 (절대 수정 금지)
│   └── processed/             ← 전처리 완료 데이터
│
├── scripts/                   ← 분석·전처리 Python 스크립트
├── charts/                    ← 생성된 차트 (PNG, HTML)
└── reports/                   ← 최종 리포트 (Markdown)
```

각 폴더의 역할을 기억해야 할 한 가지 원칙:

**data/raw/ 파일은 절대 수정하지 않습니다.**

원본 데이터를 건드리면 분석을 처음부터 다시 해야 합니다.
전처리한 결과는 반드시 data/processed/에 별도로 저장합니다.
이 규칙을 나중에 CLAUDE.md에 명시하면 Claude도 이 원칙을 따릅니다.

---

## 실습: 프로젝트 폴더 만들기 (3분)

**[화면: Antigravity 에디터 - Claude Code 채팅 패널]**

직접 만들어봅니다.

```
데이터 시각화 프로젝트용 폴더 구조를 만들어줘.
폴더: data/raw, data/processed, scripts, charts, reports
각 폴더에 역할을 설명하는 README.md도 간단하게 만들어줘.
```

Claude가 폴더를 만들고 각 README.md를 생성합니다.
왼쪽 파일 탐색기에서 구조가 생기는 것을 확인합니다.

이제 Claude에게 프로젝트를 파악해달라고 합니다.

```
지금 이 프로젝트 폴더를 전체 분석해줘.
어떤 구조인지, 어떻게 써야 할지 정리해줘.
```

Claude가 폴더 구조를 읽고 설명합니다.
이게 나중에 CLAUDE.md의 기초가 됩니다.

---

## 팁: Claude에게 프로젝트를 처음 소개할 때 (1분)

새 프로젝트를 시작하거나, 기존 프로젝트에 Claude를 처음 투입할 때 쓰는 요청입니다.

```
이 프로젝트 폴더 전체를 파악해줘.
어떤 파일이 있는지, 데이터는 어떤 형태인지 정리해줘.
그리고 분석을 시작하기 전에 알아야 할 것들을 먼저 물어봐.
```

Claude가 능동적으로 폴더를 훑고, 모르는 것은 질문합니다.
"이 날짜 컬럼이 어떤 시간대 기준인가요?" 같은 구체적인 질문이 나옵니다.
이 과정을 거치면 이후 작업 정확도가 크게 올라갑니다.

---

## 핵심 정리 (30초)

데이터 시각화 프로젝트의 기본 구조: data → scripts → charts → reports.
data/raw는 수정 금지, 전처리 결과는 data/processed에 저장.
새 프로젝트 시작할 때 Claude에게 폴더를 먼저 파악시키면 이후 작업이 훨씬 빨라집니다.

다음 클립에서는 파일 읽기·쓰기·실행과 Plan Mode를 배웁니다.
