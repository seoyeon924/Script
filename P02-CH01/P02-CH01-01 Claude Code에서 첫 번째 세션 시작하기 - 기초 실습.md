## 오프닝 (1분)

환경이 갖춰졌습니다. 이번 클립에서는 Claude Code가 실제로 어떻게 동작하는지 확인합니다.

파일을 만들고, 데이터를 읽고, 차트를 그리는 과정을 처음부터 직접 해봅니다.

## Claude Code의 동작 구조 (2분)

**[화면: 슬라이드]**

Claude Code는 어떤 원리로 작동할까요?

크게 세 단계로 생각하면 됩니다.

```
요청 → 파악 → 행동 → 확인 → 반복
```

1. **요청**: 채팅 패널에 원하는 것을 씁니다.
2. **파악**: Claude가 현재 폴더 안의 파일들을 읽고 상황을 파악합니다.
3. **행동**: 파일을 만들거나 수정하거나 코드를 실행합니다.
4. **확인**: 결과를 보여주고, 추가 피드백을 기다립니다.

이 과정이 자동으로 반복됩니다. 중간에 승인이 필요한 작업은 물어봅니다.

Claude Code가 쓰는 핵심 도구 세 가지:

| 도구 | 역할 | 예시 |
|------|------|------|
| Read | 파일 내용을 읽어서 이해 | CSV, 코드, 문서 읽기 |
| Write / Edit | 파일 생성 또는 수정 | 차트 코드 저장 |
| Bash | 터미널 명령어 실행 | Python 스크립트 실행 |

이 도구들을 Claude가 알아서 조합해서 씁니다.
우리는 그냥 원하는 것을 말하면 됩니다.

## 첫 번째 실습: 파일 만들기 (2분)

**[화면: Antigravity 에디터 - Claude Code 채팅 패널]**

채팅 패널에 입력합니다.

```
안녕. 현재 폴더 경로를 알려줘.
그리고 hello.txt 파일을 만들어서 "Claude Code 첫 실행 완료"라고 저장해줘.
```

Claude가 무엇을 하는지 보세요.

1. 먼저 현재 폴더 위치를 파악합니다.
2. Write 도구로 hello.txt를 만듭니다.
3. 완료 메시지를 보여줍니다.

왼쪽 파일 탐색기에서 hello.txt가 생긴 걸 확인합니다.
파일을 클릭하면 내용도 바로 확인됩니다.

**포인트**: 우리가 명령어 하나 입력하지 않았습니다.
자연어로 말했을 뿐인데, Claude가 파일을 만들었습니다.

## 두 번째 실습: 데이터 분석 맛보기 (4분)

**[화면: Antigravity 에디터]**

이번에는 데이터를 다뤄봅니다.

먼저 샘플 데이터를 만들어달라고 합니다.

```
마케팅 채널별 월별 매출 데이터를 샘플로 만들어줘.
채널은 SNS광고, 검색광고, 이메일, 직접유입 4개,
1월부터 6월까지 6개월치로 CSV 파일로 저장해줘.
파일명은 marketing_data.csv로 해줘.
```

Claude가 데이터를 만들고 CSV로 저장합니다.
파일 탐색기에서 marketing_data.csv를 클릭해서 내용을 확인합니다.

이제 이 데이터로 차트를 만들어봅니다.

```
방금 만든 marketing_data.csv를 읽어서
채널별 6개월 매출 추이를 선 그래프로 만들어줘.
PNG 파일로 저장해줘.
```

Claude가 하는 것들:
1. marketing_data.csv를 Read 도구로 읽습니다.
2. Python 코드를 작성합니다.
3. Bash 도구로 코드를 실행합니다.
4. PNG 파일을 저장합니다.

터미널 하단에서 Claude가 코드를 실행하는 과정이 보입니다.
왼쪽 파일 탐색기에 PNG 파일이 생기면 클릭해서 결과를 확인합니다.

**포인트**: CSV를 던져주면, 읽기 → 코드 작성 → 실행 → 저장이 자동으로 연결됩니다.
이것이 Claude Code로 데이터 분석을 하는 기본 패턴입니다.

## 세션과 컨텍스트 이해 (1분)

채팅이 진행될수록 Claude는 지금까지 한 작업의 맥락을 기억합니다.
앞에서 만든 파일을 다시 언급하지 않아도 "아까 그 차트" 식으로 이어서 작업할 수 있습니다.

하지만 컨텍스트 창에는 한계가 있습니다.
작업이 너무 길어지면 오래된 내용부터 잊기 시작합니다.

이럴 때는 채팅 패널에서 `/compact`를 입력합니다.
지금까지 대화를 압축해서 컨텍스트를 효율적으로 관리합니다.

```
/compact
```

## 핵심 정리 (30초)

Claude Code는 채팅 패널에서 자연어로 요청하면, 파일을 읽고 → 코드를 실행하고 → 결과를 저장합니다.
터미널은 Claude가 작업하는 과정을 확인할 때 자동으로 사용됩니다.

다음 클립에서는 프로젝트 폴더 구조를 어떻게 잡으면 좋은지 배웁니다.
