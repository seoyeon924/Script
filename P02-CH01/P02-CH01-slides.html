# 마케팅 성과 분석 — 데이터 시각화 프로젝트
## 폴더 구조
- data/raw/ : 원본 데이터 (절대 수정 금지)
- data/processed/ : 전처리 완료 데이터
- charts/ : 생성된 차트 (PNG, HTML)
- reports/ : 최종 리포트 (Markdown)
## 기술 스택
- Python 3.11, pandas, numpy
- matplotlib (정적 차트), plotly (인터랙티브)
## 시각화 규칙
- 시간 흐름 → 라인 차트
- 카테고리 비교 (7개 이하) → 세로 막대 차트
- 비율/구성 → 파이 차트 (5개 이하만)
## 차트 공통 요구사항
- 제목: 데이터 인사이트 한 줄
- 강조색: #1E3A5F, 나머지: #CCCCCC
- 레이블: 한국어 사용
- 저장: PNG/HTML 모두 charts/에
## 데이터 처리 원칙
- data/raw/ 수정 절대 금지
- 전처리 결과 → data/processed/ 저장
- 결측값: 수치는 중앙값, 카테고리는 'Unknown'
- 날짜 형식: YYYY-MM-DD로 통일
## 리포트 형식
- reports/에 Markdown(.md)으로 저장
- 구성: 요약 → 채널별 분석 → 인사이트 → 추천 액션
