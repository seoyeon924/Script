프롬프트 1 — 공식 구조 생성
데이터 시각화 프로젝트를 Claude Code 공식 구조로 세팅해줘.

루트에 CLAUDE.md(팀용)와 CLAUDE.local.md(개인용 템플릿) 만들고,
.claude/ 안에 rules/, hooks/ 폴더도 만들어줘.
data/raw, data/processed, scripts, charts, reports 폴더도 포함.

CLAUDE.md에는 이 프로젝트 규칙을 써줘:
- data/raw/ 파일은 절대 수정 금지
- 차트 레이블은 한국어
- @.claude/rules/ 형식으로 규칙 파일 import 예시 포함

.gitignore에 CLAUDE.local.md와 .claude/settings.local.json 추가해줘.
