# P02-CH03-01 서브에이전트 구조 이해 & 데이터 분석용 에이전트 만들기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 4장 + 화면 녹화
- **준비물:** Claude Code 설치 완료

---

## 서브에이전트란 무엇인가 (4분)

Claude Code는 기본적으로 하나의 에이전트가 작업 전체를 처리합니다.
그런데 작업 규모가 커지면 한계가 생깁니다.

예를 들어, 100개 CSV 파일을 모두 분석해야 한다고 가정합니다.
하나의 에이전트가 100개를 순서대로 처리하면 시간이 오래 걸립니다.
컨텍스트 창도 빠르게 채워집니다.

**비유하자면:**
팀장이 혼자 보고서 100개를 쓰는 대신, 팀원 10명에게 10개씩 나눠주는 방식입니다.

Claude Code에서:
- 팀장 역할 = 메인 에이전트 (오케스트레이터)
- 팀원 역할 = 서브에이전트 (워커)

---

## Task 도구 — 서브에이전트를 실행하는 방법 (4분)

Claude Code는 서브에이전트를 실행할 때 Task 도구를 사용합니다.
사용자가 이렇게 말하면:

```
data 폴더의 CSV 파일들을 각각 서브에이전트로 분석해줘
```

Claude가 내부적으로 Task 도구를 만들어서 파일 수만큼 서브에이전트를 실행합니다.

**중요한 세 가지 특성:**
1. 서브에이전트는 독립적인 컨텍스트를 가집니다
2. 서브에이전트끼리는 직접 통신하지 않습니다
3. 결과는 파일로 저장해서 공유합니다

---

## 데이터 분석용 첫 서브에이전트 실행 (5분)

샘플 CSV 파일 3개가 있다고 가정합니다:
- `data/jan.csv`, `data/feb.csv`, `data/mar.csv`

```
data 폴더에 있는 CSV 3개를 각각 서브에이전트로 분석해줘.
각 파일의 총 판매량, 평균 단가, 최다 판매 상품 상위 3개를 계산하고
output/ 폴더에 파일명_result.json으로 저장해줘.
```

Claude Code가 Task 도구를 3번 사용해서 서브에이전트를 실행합니다.
각 서브에이전트가 독립적으로 파일을 처리하고 결과를 저장합니다.

```
채널별 총 전환 수와 평균 전환율을 계산하고
output/ 폴더에 월별_분석결과.json으로 저장해줘.
```

## 핵심 정리 (30초)

서브에이전트는 메인 에이전트가 Task 도구를 통해 생성하는 독립 에이전트입니다.
독립적인 컨텍스트를 가지며 병렬로 실행됩니다.
결과는 파일을 통해 공유합니다.
