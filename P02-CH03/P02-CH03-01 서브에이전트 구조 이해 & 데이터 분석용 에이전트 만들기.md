# P02-CH03-01 서브에이전트 구조 이해 & 데이터 분석용 에이전트 만들기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 3장 + 화면 녹화 (Antigravity 에디터)
- **준비물:** Claude Code 설치 완료, data-viz-project 폴더 세팅

---

## 오프닝 (1분)

지금까지 Claude 하나가 모든 작업을 처리했습니다.

이번 챕터에서는 다릅니다.

여러 Claude가 각자 역할을 맡아서 동시에 작업하는 구조를 만듭니다.

왜 필요할까요? 데이터 분석 실무를 생각해보면 이렇습니다.

- 파일이 10개 있고 각각 분석이 필요합니다
- 한 명이 순서대로 처리하면 10배 시간이 걸립니다
- 10명에게 하나씩 나눠주면 동시에 끝납니다

Claude Code에서도 같은 원리입니다.
메인 Claude가 작업을 나누고, 서브에이전트들이 동시에 처리합니다.

---

## 서브에이전트 작동 원리 (4분)

**[화면: 슬라이드]**

구조는 이렇습니다.

```
[사용자 요청]
      |
[메인 에이전트 - 오케스트레이터]
  작업 분석 → 서브에이전트 생성 → 결과 취합
      |            |            |
[서브에이전트1]  [서브에이전트2]  [서브에이전트3]
  jan.csv 분석    feb.csv 분석    mar.csv 분석
      |            |            |
[결과 파일로 저장 → 메인에이전트가 취합]
```

서브에이전트의 세 가지 특성을 기억하세요.

**첫째, 독립적인 컨텍스트입니다.**
서브에이전트는 메인의 대화 내용을 모릅니다.
메인이 지시 내용을 통째로 전달해야 합니다.
그래서 프롬프트에 "이 CSV 파일을 분석해줘"가 아니라 분석 규칙까지 구체적으로 넣어야 합니다.

**둘째, 병렬 실행입니다.**
여러 서브에이전트가 동시에 돌아갑니다.
10개 파일을 10개 에이전트로 처리하면 시간이 거의 동일합니다.

**셋째, 파일 통신입니다.**
서브에이전트끼리 직접 이야기하지 않습니다.
결과를 파일로 저장하고, 메인이 읽어서 합칩니다.
output/ 폴더가 에이전트 간 소통 창구 역할을 합니다.

---

## 서브에이전트 실행 방법 (3분)

**[화면: 슬라이드]**

사용자가 이렇게 요청하면:

```
data 폴더의 CSV 파일 3개를 각각 분석해줘.
```

Claude가 내부적으로 Task 도구를 사용합니다.

Task 도구는 새로운 Claude 인스턴스를 만들어서 독립적으로 실행합니다.
채팅 패널에서 "Spawning subagent..." 같은 메시지가 보이면 서브에이전트가 실행 중인 것입니다.

사용자가 Task 도구를 직접 호출하지 않아도 됩니다.
자연어로 요청하면 Claude가 알아서 서브에이전트를 만들어 실행합니다.

---

## 실전: 데이터 분석용 서브에이전트 실행 (5분)

**[화면: Antigravity 에디터 - 채팅 패널]**

먼저 샘플 데이터를 만듭니다.

```
아래 3개 파일을 샘플 데이터로 만들어줘. data/ 폴더에 저장.

- jan_sales.csv: 1월 마케팅 채널별 클릭수, 전환수, 매출 (30행)
- feb_sales.csv: 2월 같은 구조
- mar_sales.csv: 3월 같은 구조

채널: SNS광고, 검색광고, 이메일, 직접유입
```

데이터가 준비되면 서브에이전트로 병렬 처리를 요청합니다.

```
data/ 폴더의 CSV 파일 3개를 각각 서브에이전트로 병렬 분석해줘.

각 서브에이전트는:
- 채널별 전환율 계산 (전환수 나누기 클릭수)
- 가장 성과 좋은 채널 1위
- 가장 성과 낮은 채널 1위
를 계산하고 output/[파일명]_result.json으로 저장.

3개 모두 완료되면 output/ 폴더의 결과를 종합해서
1분기 채널 성과 요약을 알려줘.
```

채팅 패널에서 서브에이전트가 실행되는 과정이 보입니다.
세 파일이 동시에 처리되고, 결과 JSON 3개가 output/ 폴더에 생성됩니다.

## 서브에이전트 vs 직접 처리 비교 (1분)

**[화면: 슬라이드]**

| | 직접 처리 | 서브에이전트 |
|---|---|---|
| 파일 10개 처리 | 순서대로, 10배 시간 | 병렬, 1배 시간 |
| 컨텍스트 사용 | 1개 창에 모두 쌓임 | 각 에이전트가 독립 |
| 오류 발생 시 | 전체 중단 | 해당 파일만 실패 |
| 적합한 경우 | 단순 작업, 파일 1~2개 | 반복 작업, 파일 다수 |

파일이 3개 미만이면 굳이 서브에이전트를 쓸 필요가 없습니다.
반복적이고 파일이 많을수록 효과가 커집니다.

## 클립 정리 (1분)

서브에이전트는 메인 에이전트가 Task 도구로 생성하는 독립 에이전트입니다.

정리하면 세 가지:
1. 독립적 컨텍스트 — 메인의 대화 내용을 모르므로 지시를 충분히 담아야 함
2. 병렬 실행 — 여러 파일을 동시에 처리해 시간 절약
3. 파일 통신 — 결과를 파일로 저장해서 메인이 취합

자연어로 요청하면 Claude가 알아서 서브에이전트를 만들어 실행합니다.
다음 클립에서는 에이전트에게 역할을 명확히 부여하는 팀 설정을 배웁니다.
