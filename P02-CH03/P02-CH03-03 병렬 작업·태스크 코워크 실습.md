## 병렬 처리의 이점 (2분)

월별 판매 데이터 12개 파일이 있고, 각 파일 분석에 2분이 걸린다고 가정합니다.

- 순차 처리: 12 × 2 = 24분
- 병렬 처리: 이론상 2분

---

## 병렬 설계 3가지 패턴 (4분)

### 패턴 1 — 분할·처리·합산 (가장 일반적)

```
메인 에이전트
├── 서브에이전트 A → jan.csv 분석 → jan_result.json
├── 서브에이전트 B → feb.csv 분석 → feb_result.json
└── 서브에이전트 C → mar.csv 분석 → mar_result.json
        ↓
메인 에이전트 → 3개 결과 합산 → 분기별 최종 리포트
```

### 패턴 2 — 역할 분리 파이프라인

```
데이터 수집 에이전트 → raw_data.csv
        ↓
전처리 에이전트 → cleaned_data.csv
        ↓
분석 에이전트 → analysis_result.json
        ↓
리포트 에이전트 → final_report.md
```

### 패턴 3 — 병렬 검토 (앙상블)

같은 작업을 여러 에이전트가 독립적으로 처리하고 결과를 비교합니다.

---

## 실습 — 12개 월별 파일 병렬 분석 (4분)

```bash
claude
```

```
data/monthly/ 폴더에 있는 CSV 파일 목록을 먼저 확인하고,
각 파일을 서브에이전트로 병렬 처리해줘.
CLAUDE.md 규칙에 따라 output/results/에 각각 저장하고,
전체 완료 후 성공/실패 파일 목록을 알려줘.
```

**병렬 처리 주의사항:**
- 파일 충돌 방지: 각 서브에이전트가 독립된 출력 파일을 갖도록 설계
- 파일명 규칙: `jan_result.json`, `feb_result.json` (공통 `result.json` 금지)
