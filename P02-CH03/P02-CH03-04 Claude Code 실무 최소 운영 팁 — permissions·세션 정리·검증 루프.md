## 오프닝 (30초)

## 본문

### 팁 1 — Permissions 설정

`.claude/settings.json`으로 허용/차단 명령어를 관리합니다.

```json
{
  "permissions": {
    "allow": [
      "python3 scripts/*.py",
      "pandas",
      "plotly"
    ],
    "deny": [
      "rm -rf",
      "sudo"
    ]
  }
}
```

데이터 시각화 작업에 필요한 명령어만 허용하고 위험한 명령어를 차단합니다.

### 팁 2 — 세션 정리

긴 세션은 컨텍스트가 쌓여서 성능이 저하될 수 있습니다.

```
/clear  # 대화 기록 초기화 (CLAUDE.md는 유지)
/exit   # 세션 종료
```

작업 단위를 나눠서 새 세션으로 시작하는 것이 좋습니다.

### 팁 3 — 검증 루프

중요한 작업은 Claude에게 검증을 요청합니다.

```
방금 생성한 대시보드의 수치가
원본 data/raw/campaigns.csv의 합계와 일치하는지 검증해줘.
불일치하는 항목이 있으면 목록으로 알려줘.
```

### 팁 4 — 비용 관리

- 긴 파일을 통째로 넘기지 말고 필요한 컬럼만 전달합니다
- 반복 작업은 CLAUDE.md에 규칙으로 정의해서 매번 설명하지 않습니다
- 큰 작업은 청크로 나눠서 처리합니다

### 팁 5 — 안전한 실습 환경

```bash
# 항상 Git이 있는 환경에서 작업합니다
git init
git add .
git commit -m "실습 시작 전 백업"
```

실수가 생겨도 이전 상태로 복구할 수 있습니다.
