Permissions · 세션 관리 · 검증 루프
실무 최소 운영 팁 16
안전 설정
행동 범위 제어
.claude/settings.json
{
  "permissions": {
    "allow": [
      "Read(*)",
      "Write(data/processed/**)",
      "Write(runs/**)",
      "Bash(git *)"
    ],
    "deny": [
      "Write(data/raw/**)",
      "Bash(rm -rf *)"
    ]
  }
}
deny — 원본 보호
data/raw/ 수정 불가 · 원본 덮어쓰기 복구 불가
allow — 작업 공간 허용
processed/·runs/ Claude 자유 작업 영역
팀 공유
settings.json git 커밋 → 팀 권한 통일
실무 최소 운영 팁 17
세션 관리
/clear · /compact
/clear

작업 완전 전환 시
/compact
