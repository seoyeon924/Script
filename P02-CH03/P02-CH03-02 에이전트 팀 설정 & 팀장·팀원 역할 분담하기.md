# P02-CH03-02 에이전트 팀 설정 & 팀장·팀원 역할 분담하기

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 3장 + 화면 녹화
- **준비물:** 텍스트 에디터, 프로젝트 폴더

---

## 오프닝 (30초)

서브에이전트는 같은 작업을 여럿이 동시에 처리합니다.
에이전트 팀은 다른 역할을 각자가 전문적으로 처리합니다.
이 클립에서는 팀장·팀원 역할을 CLAUDE.md에 정의하는 방법을 배웁니다.

---

## 3대 역할 유형 (4분)

어떤 복잡한 작업이든 세 가지 역할로 분해할 수 있습니다.

**기획자 에이전트 (Planner)**
작업 전체를 이해하고 계획을 수립합니다.
무엇을 해야 하는지 판단하고 다른 에이전트에게 지시합니다.

**실행자 에이전트 (Executor)**
기획자의 지시를 받아 실제 작업을 수행합니다.
파일 읽기, 계산, 코드 실행, 데이터 변환 등을 담당합니다.

**검토자 에이전트 (Reviewer)**
실행자의 결과를 검토하고 품질을 확인합니다.
오류나 누락을 발견하고 피드백을 줍니다.

---

## CLAUDE.md로 팀 구조 정의하기 (7분)

```markdown
# 마케팅 분석 에이전트 팀

## 팀 구성

### 에이전트 1 — 데이터 분석가
**역할**: 데이터 처리 전담
**전문 분야**: CSV 로딩, 수치 집계 (ROI, CTR, CVR), 이상치 탐지
**접근 가능 경로**: data/raw/, data/processed/
**결과 저장**: output/analysis/analysis_result.json

### 에이전트 2 — 비즈니스 인사이트 분석가
**역할**: 분석 결과 해석 전담
**전문 분야**: 패턴과 트렌드 해석, 비즈니스 맥락 도출, 액션 권고사항
**입력**: output/analysis/analysis_result.json
**결과 저장**: output/insights/insights.md

### 에이전트 3 — 리포트 작성가
**역할**: 최종 리포트 작성 전담
**전문 분야**: 팀 눈높이 문서 작성, 표와 차트 구성, 요약
**입력**: output/analysis/ + output/insights/
**결과 저장**: output/reports/final_report.md

## 운영 규칙
- 에이전트 1 완료 후 에이전트 2 시작
- 에이전트 2 완료 후 에이전트 3 시작
- 원본 데이터(data/raw/) 수정 절대 금지
```

---

## 직접 해보기

```
내 마케팅 분석 프로젝트를 위해
CLAUDE.md에 3-에이전트 팀 구조를 설계해줘.

역할:
- 분석 에이전트: data/ 폴더 CSV 처리, ROI·CTR·CVR 계산
- 인사이트 에이전트: 분석 결과 해석, 권고사항 도출
- 리포트 에이전트: output/reports/에 마크다운 리포트 저장

각 에이전트의 입출력 경로도 명확하게 정의해줘.
```

---

## 핵심 정리 (30초)

기획자(Planner), 실행자(Executor), 검토자(Reviewer)의 3대 역할로 에이전트 팀을 설계합니다.
각 에이전트의 역할, 전문 분야, 입출력 경로를 CLAUDE.md에 명시합니다.
역할이 분리될수록 각 에이전트가 깊이 집중하므로 결과 품질이 높아집니다.
