## 오프닝 (30초)

(PM 대시보드를 실제 업무에서 어떻게 활용하고 데이터 기반 의사결정을 하는지 시연)

## 본문

### 시나리오 1 — DAU 급락 원인 분석

```
오늘 DAU가 전주 대비 30% 하락했습니다.
user_logs.csv를 분석해서 원인을 찾아줘.

분석 항목:
- 어떤 피처 사용이 줄었는가
- 어떤 코호트(가입 시기)에서 이탈이 많은가
- 특정 기기/OS에서만 발생하는가
- 전일 대비 데이터 패턴 이상 없는가
```

### 시나리오 2 — 피처 출시 성과 측정

```
3월 15일 '추천' 피처를 출시했습니다.
출시 전후 2주 데이터를 비교해서
피처 성과를 측정해줘.

측정 항목:
- 피처 사용률 (출시 전 vs 후)
- 피처 사용 사용자의 리텐션 차이
- 피처가 DAU에 미친 영향
```

### 시나리오 3 — 분기 리뷰 자동화

```
1분기 PM KPI를 분석하고 분기 리뷰 자료를 만들어줘.

포함:
- 분기별 핵심 지표 변화
- 목표 대비 달성률
- 개선된 지표 3개, 악화된 지표 2개
- 2분기 우선순위 제안

reports/q1_review.md + charts/q1_dashboard.html
```

## 핵심 정리 (30초)

PM 대시보드는 지표 이상 탐지 → 원인 분석 → 피처 성과 측정 → 분기 리뷰의 흐름으로 활용합니다.
Claude Code와 함께라면 "왜 이 지표가 떨어졌는가"에 빠르게 답할 수 있습니다.
이것으로 Part 05 CH03 PM Metric 분석 대시보드를 마칩니다.
