# CH07-01 D3.js란 무엇인가 — 데이터로 그림을 그리다

## D3.js가 필요한 이유 (4분)

맷플롯립과 플롯리로 대부분의 차트를 만들 수 있습니다.
그런데 실무에서 이런 요구가 생깁니다.

"우리 브랜드 색상으로 정확히 이 모양의 차트를 만들어주세요."
"마우스를 올리면 이런 식으로 움직이게 해주세요."
"태블로에 없는 이 차트 유형이 필요합니다."

맷플롯립과 플롯리는 제공하는 차트 유형 안에서만 커스터마이징이 됩니다.
디쓰리제이에스는 다릅니다.

**예를 들면 이렇습니다.**

맷플롯립은 완성된 가구를 파는 가게입니다.
색상과 크기를 고를 수 있지만 기본 형태는 정해져 있습니다.
디쓰리제이에스는 목재와 공구를 주는 작업실입니다.
원하는 모양을 처음부터 만들 수 있습니다.
대신 더 많은 지식이 필요합니다.

디쓰리제이에스(D3.js)는 이 이름이 **Data-Driven Documents**의 약자입니다.
데이터가 문서를 만든다는 뜻입니다.
데이터 값에 따라 에이치티엠엘 요소를 직접 조작합니다.

---

## D3.js의 핵심 개념 (6분)

디쓰리제이에스를 이해하는 데 세 가지 개념이 중요합니다.

**SVG입니다.**

에스브이지(SVG)는 Scalable Vector Graphics의 약자입니다.
브라우저에서 선, 원, 사각형, 경로를 그리는 방식입니다.
이미지가 아니라 코드로 그리기 때문에 크기를 키워도 선명합니다.

디쓰리제이에스는 에스브이지 요소를 데이터에 맞게 자동으로 생성합니다.

예를 들어 막대 차트에서 `<rect>` 태그 하나가 막대 하나입니다.
데이터 값이 클수록 `height` 속성이 커집니다.
디쓰리제이에스가 이 계산을 자동으로 합니다.

**스케일(Scale)입니다.**

데이터 값(예: 매출 1,500,000원)을 화면 픽셀(예: 240픽셀)로 변환하는 함수입니다.
디쓰리제이에스의 스케일 함수가 이 변환을 처리합니다.

```javascript
const xScale = d3.scaleBand()
  .domain(['SNS', '검색', '이메일'])  // 데이터 값
  .range([0, 600])                    // 화면 범위(픽셀)
```

**데이터 바인딩입니다.**

데이터 배열과 에이치티엠엘 요소를 연결합니다.
데이터가 바뀌면 화면이 자동으로 업데이트됩니다.

이 세 가지를 클로드 코드가 대신 처리합니다.
개념만 이해하면 코드는 에이전트에게 맡깁니다.

---

## 클로드 코드로 D3.js 차트 생성하기 (5분)

클로드 코드에게 디쓰리제이에스 차트를 요청하는 방법입니다.

핵심은 세 가지를 명시하는 것입니다.

먼저 차트 유형과 데이터 구조.
다음으로 인터랙션 방식 (툴팁, 클릭, 호버 등).
세 번째로 디자인 기준 (색상, 크기, 폰트).

지시 예시입니다.

> "data/campaigns.csv를 읽어서 디쓰리제이에스로 채널별 매출 막대 차트를 에이치티엠엘로 만들어줘. 조건은 이렇게 해줘. 먼저 에스브이지 크기 800×500. 다음으로 막대에 마우스 올리면 채널명, 매출, 알오아이가 툴팁으로 표시. 세 번째로 가장 높은 막대는 파랑 (#2563EB), 나머지는 회색. 네 번째로 클릭하면 해당 채널 데이터를 콘솔에 출력. 파일은 charts/d3_bar.html로 저장해줘."

---

## 직접 해보기

**목표**: 클로드 코드로 첫 번째 디쓰리제이에스 차트를 생성합니다.

**준비 (터미널에 복붙)**
```bash
mkdir ~/d3-test && cd ~/d3-test
mkdir -p data charts
printf "채널,매출\nSNS,3200000\n검색,4100000\n이메일,1800000\n디스플레이,2600000" > data/sales.csv
claude
```

**클로드에게 이렇게 말합니다**
```
data/sales.csv를 읽어서 디쓰리제이에스로 채널별 매출 막대 차트를 만들어줘.
- SVG 크기: 800×500
- 마우스 오버 시 채널명과 매출 툴팁 표시
- 최고 매출 채널만 파랑, 나머지 회색
- charts/d3_bar.html로 저장
```

**결과 확인**
```bash
open charts/d3_bar.html
```

→ 브라우저에서 막대에 마우스를 올려서 툴팁이 나오는지 확인합니다.
