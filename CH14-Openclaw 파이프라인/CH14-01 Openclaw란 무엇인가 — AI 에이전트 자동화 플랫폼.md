## Openclaw란 무엇인가 (4분)

오픈클로는 에이아이 에이전트를 서비스처럼 운영하는 플랫폼입니다.

지금까지 배운 클로드 코드는 직접 터미널에서 실행하고 지시를 입력했습니다.
오픈클로는 이 과정을 자동화합니다.

**클로드 코드와 오픈클로의 차이:**

| 항목 | 클로드 코드 | 오픈클로 |
|------|-----------|---------|
| 실행 방식 | 터미널에서 직접 입력 | 스케줄에 따라 자동 실행 |
| 트리거 | 사람이 지시 | 시간, 이벤트, 메시지 |
| 결과 전달 | 터미널 출력 | 텔레그램, 슬랙, 이메일 |
| 운영 | 사람이 항상 켜둬야 함 | 백그라운드 자동 실행 |

**구체적으로 말하면,**

클로드 코드는 직접 고용한 직원입니다. 지시를 내리면 일합니다.
오픈클로는 그 직원에게 자동화 시스템을 붙인 것입니다.
매일 오전 9시에 자동으로 출근해서 정해진 일을 하고 결과를 보고합니다.

---

## Openclaw 핵심 기능 (4분)

**크론(Cron) 스케줄러입니다.**
"매일 오전 8시에 실행" 같은 반복 작업을 등록합니다.
새 데이터가 오면 자동으로 분석이 시작됩니다.

**채널 연동입니다.**
텔레그램, 슬랙으로 결과를 자동 전송합니다.
"분석 완료됐습니다. 결과: SNS 알오아이 80%"처럼 직접 알림이 옵니다.

**워크스페이스 격리입니다.**
프로젝트별로 에이전트 환경이 독립됩니다.
마케팅 분석 에이전트와 인사 분석 에이전트가 섞이지 않습니다.

---

## 첫 번째 자동화 작업 설정 지시 (4분)

오픈클로에서 클로드 코드를 활용하는 방법입니다.

오픈클로 워크스페이스를 열고 CLAUDE.md에 작업 지시를 작성합니다.
크론 스케줄을 설정합니다.

```bash
# 매일 오전 9시에 마케팅 분석 자동 실행
openclaw cron add --every 1d --message "data/raw/ 최신 파일로 8단계 파이프라인 실행해줘" --announce
```

이렇게 하면 매일 오전 9시에 클로드 코드가 자동으로 분석을 실행하고 텔레그램으로 결과를 알려줍니다.

---

## 직접 해보기

**목표**: 오픈클로에서 첫 번째 자동화 크론 작업을 등록합니다.

**준비 (터미널)**
```bash
# 오픈클로 상태 확인
openclaw status

# 크론 작업 목록 확인
openclaw cron list
```

**클로드에게 이렇게 말합니다 (텔레그램으로)**
```
매일 오전 9시에 ~/marketing-project의 최신 CSV로
마케팅 분석 파이프라인 실행해줘.
결과를 텔레그램으로 요약 보내줘.
```

→ 오픈클로가 크론 작업을 등록하고 다음 날 오전 9시에 자동 실행됩니다.

## 핵심 정리 (30초)

오픈클로는 클로드 코드 에이전트를 자동화 서비스로 운영하는 플랫폼입니다.
크론 스케줄, 채널 연동, 워크스페이스 격리가 핵심 기능입니다.
한 번 설정하면 매일 자동으로 분석하고 결과를 알려줍니다.
