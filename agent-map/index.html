⚒ How It Works

Input

CSV, Excel, DB 연결, API 등 데이터만 넣으면 전체 파이프라인이 자동 실행됩니다.

pipeline.run( data="sales_2024.csv", goal="매출 하락 원인 분석" )

Pipeline Flow

1
Ingestion — 데이터 연결 및 로드
2
EDA — 자동 탐색적 분석
3
Preprocessing — 정제 및 피처 생성
4
Problem — 분석 질문/가설 수립
5
Metrics — KPI 정의 및 목표 설정
6
Analysis — 쿼리/통계/코호트/퍼널
7
Dashboard — 시각화 자동 생성
8
Experiment — A/B 테스트 설계
9
Report — 인사이트 + 리포트
10
Actions — 실행 계획 도출
