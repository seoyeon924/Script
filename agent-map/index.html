데이터 플로우

1
Client가 데이터 분석 요청을 보냄
"매출 트렌드 분석해줘"
2
Orchestrator가 요청을 파싱하고
적절한 에이전트 팀을 구성
3
각 Department의 에이전트들이
병렬로 작업 수행 (분석→시각화→리포트)
4
Output이 생성되고
클라이언트에게 전달
5
모든 결과물이 Knowledge Base에
저장되어 시스템이 학습 (Feedback Loop)

React Flow 구현 예시

import ReactFlow from 'reactflow'; const nodes = [ { id: 'client', position: { x: 0, y: 200 }, data: { label: 'Client' } }, { id: 'orchestrator', position: { x: 200, y: 200 }, data: { label: 'AI Agent' } }, // ... more nodes ]; const edges = [ { id: 'e1', source: 'client', target: 'orchestrator', animated: true }, ]; <ReactFlow nodes={nodes} edges={edges} fitView />

핵심 기능

✓ 드래그 & 드롭 — 노드 위치 자유 이동
✓ 연결선 자동 업데이트 — 노드 이동 시 따라옴
✓ 줌 & 팬 — 마우스 휠 / 드래그
✓ 미니맵 — 전체 구조 한눈에
✓ 커스텀 노드 — 부서/에이전트 카드
✓ 애니메이션 — 데이터 흐름 시각화

확장 아이디어

• 실시간 에이전트 상태 표시 (활성/대기)
• 클릭 시 에이전트 상세 정보 패널
• 에이전트 간 메시지 흐름 애니메이션
• 비용/토큰 사용량 실시간 표시
• 에이전트 추가/삭제 편집 모드
