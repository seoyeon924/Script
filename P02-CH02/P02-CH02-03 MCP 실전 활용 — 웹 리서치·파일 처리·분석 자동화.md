# P02-CH02-03 MCP 실전 활용 — 웹 리서치·파일 처리·분석 자동화

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 화면 녹화 (Antigravity 에디터 중심)
- **준비물:** Firecrawl MCP 연결 완료 (이전 클립 선행)

---

## 오프닝 (1분)

이번 클립에서는 MCP를 실제 데이터 분석 작업에 어떻게 쓰는지 확인합니다.

세 가지 실전 시나리오를 다룹니다.

1. **웹 리서치 자동화** — 여러 페이지 수집 → 비교 분석 리포트 생성
2. **파일 처리 자동화** — 폴더 안 파일 일괄 처리
3. **분석 파이프라인** — 수집 → 전처리 → 시각화 한 번에

복잡한 코드 없이 채팅 지시만으로 이 모든 게 가능합니다.

---

## 시나리오 1: 경쟁사 분석 리포트 자동화 (5분)

**[화면: Antigravity 에디터]**

마케팅 팀에서 주 1회 경쟁사 분석 리포트를 만들어야 하는 상황입니다.
지금까지는 각 사이트를 직접 돌아다니며 수동으로 정리했습니다.

이걸 Claude Code + Firecrawl MCP로 자동화합니다.

채팅 패널에 입력합니다.

```
아래 3개 URL에서 각각 최신 블로그 포스트 제목 5개와 주요 내용을 수집해줘.
- [경쟁사A URL]
- [경쟁사B URL]
- [경쟁사C URL]

수집 후 세 곳을 비교해서:
1. 각사가 최근 집중하는 주제
2. 공통적으로 다루는 키워드
3. 우리가 참고할 수 있는 인사이트
를 reports/competitor_weekly.md에 정리해줘.
파일 맨 위에 오늘 날짜를 넣어줘.
```

Claude가 세 사이트를 순서대로 방문하면서 데이터를 모읍니다.
각 단계가 채팅 패널에 표시되므로 어디서 시간이 걸리는지 바로 알 수 있습니다.

완료 후 reports/competitor_weekly.md를 열어 결과를 확인합니다.

**이게 자동화가 되면:**
이 프롬프트를 Claude Code Skill로 저장해두면 매주 명령어 하나로 같은 리포트가 생성됩니다. (다음 클립에서 다룹니다)

## 시나리오 2: 폴더 내 파일 일괄 처리 (4분)

**[화면: Antigravity 에디터]**

분석가라면 이런 상황이 익숙합니다.
월별 CSV 파일 12개가 폴더에 있고, 모두 같은 형식으로 전처리해야 합니다.

```
data/raw/ 폴더에 있는 CSV 파일들을 확인하고,
각 파일에 대해 아래 작업을 수행해줘:
1. 컬럼명 한글 → 영어로 통일 (매출→revenue, 날짜→date, 채널→channel)
2. date 컬럼을 datetime 형식으로 변환
3. revenue 컬럼에서 쉼표와 원화 기호 제거 후 float로 변환
4. 전처리된 파일을 data/processed/ 폴더에 같은 파일명으로 저장

전처리 완료 후 각 파일별 행 수, 결측값 수, 날짜 범위를 요약해서 알려줘.
```

Claude가 폴더를 스캔하고 파일 수에 맞게 반복 처리합니다.

수동으로 하면 파일 12개 × 작업 5단계 = 60번의 반복 작업입니다.
Claude에게 지시 한 번으로 끝납니다.

> **팁:** 파일이 많을수록 효과가 큽니다. 100개 파일도 같은 방식으로 처리됩니다.

## 시나리오 3: 수집 → 전처리 → 시각화 원스톱 파이프라인 (4분)

**[화면: Antigravity 에디터]**

앞에서 배운 것들을 하나로 연결합니다.

```
아래 순서로 작업해줘:

1단계: 웹 수집
- [공공데이터 URL]에서 2024년 월별 통계 데이터를 스크래핑해줘
- data/raw/stat_2024.csv로 저장

2단계: 전처리
- 날짜 형식 통일, 수치 타입 변환, 결측값 처리
- data/processed/stat_cleaned.csv로 저장

3단계: 시각화
- 월별 추이 라인 차트 생성
- 항목 비교 막대 차트 생성
- 두 차트를 charts/ 폴더에 PNG로 저장

4단계: 요약
- 주요 인사이트 3가지를 뽑아서 reports/stat_summary.md에 정리
```

Claude가 1~4단계를 순서대로 수행합니다.
중간에 오류가 생기면 스스로 수정하고 다음 단계로 넘어갑니다.

완료 후 전체 작업 결과를 확인합니다:

```
지금까지 만든 파일들을 폴더별로 정리해서 보여줘.
```

## MCP 활용 시 주의할 점 (1분)

**웹 크롤링 윤리:**
- robots.txt를 확인하는 습관을 갖는 것이 좋습니다
- 데이터 수집 빈도를 과도하게 높이지 않기
- 개인정보가 포함된 데이터 수집 주의

**API 비용:**
- Firecrawl 무료 티어: 월 500페이지
- 대규모 크롤링은 유료 플랜 필요
- 꼭 필요한 페이지만 선택적으로 수집

## 핵심 정리 (1분)

MCP 실전 활용 세 가지 패턴을 정리합니다.

1. **웹 리서치 자동화**: 여러 URL 수집 → 비교 분석 → 리포트 저장
2. **파일 일괄 처리**: 폴더 스캔 → 규칙 적용 → 결과 저장
3. **원스톱 파이프라인**: 수집 → 전처리 → 시각화 → 요약을 한 번에

공통 패턴은 단계를 명확히 구분해서 지시하는 것입니다.
"1단계, 2단계, 3단계" 형식으로 지시하면 Claude가 순서를 지키면서 처리합니다.

다음 클립에서는 이 작업들을 재사용 가능한 Skills로 저장하는 방법을 배웁니다.
