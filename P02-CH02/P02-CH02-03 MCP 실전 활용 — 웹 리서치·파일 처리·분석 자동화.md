## 오프닝 (30초)

(여러 MCP를 조합해서 복잡한 분석 워크플로우를 자동화하는 실전 시연)

## 본문

### 시나리오: 경쟁사 분석 자동화

여러 MCP를 조합한 실전 파이프라인입니다.

```
1. Firecrawl MCP → 경쟁사 3곳 웹사이트 크롤링
2. Filesystem MCP → 수집 데이터 저장
3. Claude 분석 → 가격 비교 표 생성
4. Plotly → 비교 차트 생성
5. 결과 → reports/competitor_analysis.md
```

### 파이프라인 실행 예시

```
다음 작업을 순서대로 실행해줘:
1. Firecrawl로 [URL1], [URL2], [URL3] 제품 가격 수집
2. 가격 비교 표 작성 → data/raw/prices.csv
3. 채널별 가격 분포 차트 생성 → charts/price_comparison.html
4. 분석 리포트 작성 → reports/competitor_analysis.md
```

### Google Sheets 연동

```bash
# Google Sheets MCP 연결
claude mcp add --transport stdio gsheets -- npx -y @anthropic/mcp-google-sheets
```

```
Google Sheets의 [스프레드시트 ID] 파일을 읽어서

새 시트에 분석 결과도 추가해줘.
```

## 핵심 정리 (30초)

여러 MCP를 조합하면 웹 수집 → 파일 처리 → 분석 → 리포트 파이프라인이 완전 자동화됩니다.
CLAUDE.md에 MCP 사용 규칙을 정의하면 매번 설명 없이도 자동 활용합니다.
다음 클립에서는 Skills 탐색 및 설치 방법을 배웁니다.
