# P01-CH01-02 왜 AI + 데이터 시각화인가 — 수작업 vs Claude Code 워크플로우

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 + 화면녹화

---

## 오프닝 (30초)

데이터 분석 현장에서 반복되는 일이 있습니다.
매주 같은 CSV 파일을 열고, 같은 방식으로 집계하고, 같은 형식의 리포트를 만드는 작업입니다.
Claude Code는 이 구조를 바꿉니다.

---

## 수작업 워크플로우의 문제 (4분)

**일반적인 마케팅 분석가의 월요일 아침입니다.**

1. 5개 채널 CSV 파일을 각각 다운로드합니다
2. Excel에서 VLOOKUP으로 합치고 피벗 테이블을 만듭니다
3. 차트를 수동으로 그리고 색상을 맞춥니다
4. PowerPoint 슬라이드에 복사·붙여넣기합니다
5. 숫자가 바뀌면 1번부터 다시 합니다

이 작업에 평균 3~4시간이 걸립니다.
데이터가 수정되면 전체를 반복해야 합니다.

---

## Claude Code 워크플로우 (5분)

**같은 작업을 Claude Code로 처리하면:**

```
"data/raw/에 있는 5개 채널 CSV를 합쳐서
채널별 ROI, CTR, CVR을 계산하고
인터랙티브 대시보드를 만들어줘.
색상은 브랜드 가이드 파란색 계열로."
```

Claude Code 동작 순서:
1. 파일 시스템에서 5개 CSV를 직접 읽습니다
2. pandas로 집계 코드를 작성하고 실행합니다
3. Plotly로 인터랙티브 차트를 생성합니다
4. `charts/dashboard.html`로 저장합니다

**소요 시간: 3~5분**

---

## ChatGPT vs Claude Code — 구조적 차이 (4분)

| 항목 | ChatGPT | Claude Code |
|------|---------|------------|
| 파일 접근 | 업로드 필요 | 파일시스템 직접 읽기 |
| 코드 실행 | 코드 예시 제공 | 실제 실행 |
| 결과물 | 텍스트/코드 | 실제 파일 생성 |
| 반복 작업 | 매번 새로 입력 | CLAUDE.md 규칙 자동 적용 |

ChatGPT는 텍스트를 주고받는 대화 도구입니다.
Claude Code는 실제 파일을 읽고 쓰고 실행하는 에이전트입니다.

---

## 핵심 정리 (30초)

AI + 데이터 시각화의 핵심은 "반복 작업의 자동화"입니다.
수작업 3~4시간이 Claude Code로 5분 이내로 줄어듭니다.
다음 클립에서는 좋은 시각화의 원칙을 배웁니다.
