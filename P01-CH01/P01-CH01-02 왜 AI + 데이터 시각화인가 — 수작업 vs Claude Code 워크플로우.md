## [슬라이드 s5 — 클립 오프닝 섹션 브레이크]

자, 이번 클립에서는 저희가 왜 AI랑 데이터 시각화를 같이 쓰는지를 이야기할 건데요.

지금 하시는 작업 방식을 한 번 떠올려보세요. 매주 같은 파일 열고, 같은 방식으로 집계하고, 또 같은 형태로 리포트 만드는 그 작업이요.

클로드코드가 이 구조를 어떻게 바꾸는지를 지금부터 같이 보겠습니다.

---

## [슬라이드 s6 — 수작업 분석 5단계]

마케팅 분석가의 월요일 아침을 한 번 상상해보겠습니다.

채널이 5개면 CSV 파일도 5개입니다. 다 따로따로 다운로드해야 하고요. 엑셀에서 VLOOKUP으로 합치고 피벗 만들고, 차트 직접 그리고 색상 맞추고, PPT에 복사 붙여넣기하고.

그런데 숫자 하나가 바뀌면요? 1단계부터 다시 합니다.

이 작업이 평균 3~4시간이에요. 매주요.

---

## [슬라이드 s7 — Claude Code 워크플로우]

같은 작업을 클로드코드로 하면 어떻게 달라지는지 보겠습니다.

안티그래비티 에디터 채팅 패널에 이렇게 입력하면 돼요.

> "data/raw/ 에 있는 5개 채널 CSV를 합쳐서 채널별 ROI, CTR, CVR 계산하고 인터랙티브 대시보드로 만들어줘."

그러면 클로드코드가 알아서 파일을 직접 읽고, 집계 코드 작성하고 실행하고, Plotly로 인터랙티브 차트 만들어서 dashboard.html 파일로 저장합니다.

소요 시간이 3~5분이에요.

파일 업로드 같은 거 없고요. 오류가 나면 알아서 수정해서 재실행합니다. 결과 파일도 자동으로 저장되고요.

---

## [슬라이드 s8 — ChatGPT vs Claude Code]

ChatGPT랑 뭐가 다른지 헷갈리시는 분들이 꽤 있거든요. 정확히 짚고 넘어가겠습니다.

ChatGPT는 대화 도구예요. 코드를 제안해주는데, 그 코드를 직접 실행하는 건 여러분이 해야 합니다. 파일 접근도 수동 업로드만 되고요.

클로드코드는 실행 에이전트예요. 내 컴퓨터 파일시스템을 직접 읽고, 코드를 내 컴퓨터에서 직접 실행하고, 결과 파일을 자동으로 저장합니다.

그리고 CLAUDE.md 라는 파일에 한 번 규칙을 써놓으면, 매번 새로 말하지 않아도 클로드코드가 그 규칙을 영구적으로 적용해요. "차트 색상은 항상 브랜드 파란색 계열로" 같은 걸요.

요청 한 번이면 파이프라인이 자동으로 돌아가는 구조입니다. ChatGPT는 단계마다 개별로 요청해야 하고요.

---

## [슬라이드 s32 — 세 가지 AI 도구 비교]

그런데 여기서 한 가지 짚고 가야 할 게 있어요.

클로드 AI, 커서, 클로드코드. 이 세 가지가 다 비슷해 보이는데 실제로는 완전히 다른 도구거든요.

클로드 AI는 웹 브라우저에서 대화하는 도구예요. 코드 실행이 안 되고요.

커서나 코워크 같은 IDE 통합 도구는 에디터 안에서 AI를 쓰는 건데, 에디터에 열린 파일만 접근할 수 있어요.

클로드코드는 제 컴퓨터 전체 파일시스템을 직접 읽고 쓰고 실행합니다. 비개발자도 쓸 수 있는 게 특징이고요.

같은 Claude 기반이어도 작동 방식이 완전히 달라요. 쓰임새에 맞는 도구를 골라야 결과가 나옵니다.

## [슬라이드 s33 — 코딩 밖 작업도 가능]

클로드코드가 코딩 도구라고 생각하시는 분들이 많은데요. 사실 코딩과 전혀 관계없는 작업도 다 됩니다.

파일을 읽고 실행하는 에이전트이기 때문에, 할 수 있는 범위가 굉장히 넓어요.

CSV 데이터 분석해서 대시보드 만들기는 기본이고요. 회의록 30개를 한 번에 읽어서 결정사항 추출하고 정리하기, 웹 여러 페이지 동시에 탐색해서 경쟁사 분석 보고서 만들기, 주간 보고서 자동화, 에러 메시지 붙여넣으면 버그 수정까지.

이 강의에서 저희가 주로 쓸 건 CSV 데이터를 분석해서 대시보드 만들고, CLAUDE.md로 디자인 규칙을 고정하고, 반복 리포트를 자동화하는 겁니다.

## [슬라이드 s34 — 어떻게 시작할까 + 요금 가이드]

마지막으로 요금 얘기를 하겠습니다. 이게 의외로 중요한 부분이에요.

클로드코드를 쓰려면 claude.ai 구독이 필요한데요.

Pro가 월 20달러고, Max가 월 100달러입니다.

Pro로 시작하시는 분들이 많은데, 집중해서 작업하면 1시간 내로 한도가 차요. 이 강의처럼 이것저것 실습하다 보면 금방 채워지거든요. 잠재력 확인용으로는 괜찮은데, 본격적으로 쓸 거라면 Max를 추천합니다.

Max는 멀티세션 되고, Opus 모델 쓸 수 있고, 에이전트팀도 가능해요. "이게 이렇게까지 되는 거였어?"를 경험할 수 있는 플랜입니다.

클로드코드가 어떻게 작동하는지도 잠깐 보면, Read → Plan → Execute → Verify 순서로 루프를 돌아요. 파일 읽고, 계획 세우고, 실행하고, 검증하는 과정이 자동으로 반복됩니다.

그러면 이 내용을 바탕으로 다음 클립에서는 좋은 데이터 시각화가 어떤 원칙으로 설계되는지 알아보겠습니다.
