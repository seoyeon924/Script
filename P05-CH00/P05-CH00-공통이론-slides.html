시각화 설계 · What
What — 시각화하기 좋은 지표
대시보드에 넣기 좋은 지표의 3가지 특징
①
상대적인 지표 — 비교가 가능해야
시간(전일·주·월·년 대비)·그룹(카테고리·브랜드 평균 대비) 변화율. 비교돼야 인사이트가 나온다.
예시 · 전주 대비 결제 전환율, 전월 대비 수익 증감율, 전년 동일 프로모션 대비 매출 증감율
②
비율 지표 — 참여도를 나타내야
사용자 참여도를 나타내 학습·액션이 가능. 프로덕트의 실질 현황을 반영한다.
예시 · 고객 재방문율, 활성 사용자 비율, 유료 구독 전환율, 장바구니 전환율
③
선행 지표 — 액션이 가능해야
후행지표(매출·수익)에 앞서는 지표. 개선 방법이 명확해 실제 액션에 반영하기 쉽다.
예시 · 유료 구독 배너 클릭 전환율, 광고 소재별 클릭 전환율, 회원가입 배너 클릭 전환율

차트 선택 기준
분석 의도로 고르고, 사람의 인지 정확도로 거르기
분석 의도 → 차트
  • 비교 · 누가 더 큰가 — 정렬 막대
  • 추세 · 어떻게 변했나 — 선
  • 상관 · 둘이 관련 있나 — 산점도
  • 부분-전체 · 구성 비율 — 누적 막대·도넛
사람이 정확히 읽는 순서
위치 → 길이 → 각도 → 면적 → 색
정확 ——————→ 부정확
각도·면적은 부정확하게 읽힘 — 그래서 파이보다 막대, 비교는 길이로.
공통 이론 · 인사이트 ①
인사이트 도출 ① — 분석으로 좁혀가기
수집된 값은 정보, 분석을 거쳐야 인사이트
인사이트는 "이해를 바꾸는 발견"
  • 단순 집계·보고는 정보 — 가정이나 의사결정을 바꿀 때 인사이트
  • 대시보드는 정보를 보여주고, 인사이트는 그 위에서 사람이 만든다
드릴다운으로 성과의 출처를 좁힌다
  • 전체 → 세그먼트 → 카테고리 → 채널로 한 단계씩 분해
  • 평균 뒤에 숨은 편차를 연다 — 같은 카테고리도 채널 따라 성과가 갈림
분류 표기가 일관돼야 쪼갤 수 있다
  • 채널·카테고리·기간처럼 나누는 기준을 미리 정해 똑같이 기록
  • 같은 걸 'Email'·'이메일'로 다르게 적으면 한 묶음으로 안 잡혀 드릴다운 불가
공통 이론 · 인사이트 ②
인사이트 도출 ② — 발견 · 의미 · 액션
관찰과 해석을 분리하고, 액션까지 적는다
발견
  • 데이터에서 보이는 것을 해석 없이 그대로 기록 (수치·패턴만)
  • 관찰에 의견을 섞으면 추측이 근거처럼 보임
의미
  • 왜 중요한지 · 비즈니스 임팩트를 규모로 환산
  • 발견과 해석을 분리해야 의사결정이 근거를 가짐
액션
  • 무엇을 · 누가 · 언제까지 + 우선순위(P1·P2·P3)
  • 차트 제목도 주제가 아니라 결론으로 ("이메일이 매출의 절반")
공통 이론 · 분석 주의
분석 시 주의할 점 — 5가지
자동 생성된 수치를 그대로 결론으로 쓰기 전에
1. 전후 비교 ≠ 인과
  • 계절성·동시 진행 활동·외부 요인이 섞임
  • 통제집단을 둔 A/B 실험으로 효과 분리
2. 유의하다 ≠ 효과가 크다
  • 큰 표본은 사소한 차이도 유의하게 나옴
  • 효과크기·신뢰구간·표본을 함께 확인
  • ‘유의하지 않음’이 ‘효과 없음’은 아님
3. 엿보기(peeking)·다중 비교
  • 조기 종료·여러 지표 동시 비교는 위양성
  • 표본을 미리 정하고 다중비교 보정
4. 상관 ≠ 인과 (교란변수)
  • 숨은 제3의 변수가 둘 다 끌어올릴 수 있음
  • 광고비↔매출도 잘 팔리는 카테고리 효과일 수 있음
5. 평균의 함정 · % vs %p
  • 평균은 분산·이상치를 은폐(심슨의 역설)
  • 8.7%→25.4%는 16.7%p 상승이지 191% 아님
공통 이론 · 인사이트
비교를 통한 인사이트
시각화의 기본은 "비교" — 비교해야 지표의 좋고 나쁨을 해석한다
① 비율로 바꿔서 보기
범주 간 값의 스케일 차이가 크면 절대값으로는 좋고 나쁨을 판단하기 어렵다. 비율(전년 대비 증감율 등)로 바꾸면 규모가 작은 범주의 성장도 드러난다.
예 · 절대 매출은 작은 Labels가 전년 대비 +37%로 최고 성장
② 전체·유사 카테고리와 비교
전체 평균과 비교하고, 단가·성격이 비슷한 다른 카테고리·브랜드끼리 묶어 비교해 평가한다.
예 · 전체 카테고리 평균 증감율 대비, 유사 브랜드 대비
절대값 순위 → 증감율 순위
