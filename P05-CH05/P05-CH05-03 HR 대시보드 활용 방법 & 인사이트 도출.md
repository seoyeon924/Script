# P05-CH05-03 HR 대시보드 활용 방법 & 인사이트 도출

## 📌 클립 정보
- **예상시간:** 15분
- **유형:** 슬라이드 + 화면녹화

## 오프닝 (30초)

(HR 대시보드를 통해 이직 패턴을 발견하고 채용 전략을 개선하는 방법 시연)

## 본문

### 시나리오 1 — 이직 패턴 분석

```
HR 데이터를 분석해서 이직이 가장 많이 발생하는 패턴을 찾아줘.

분석 항목:
- 어느 부서에서 이직률이 가장 높은가
- 어떤 직급/근속 연수에서 이직이 집중되는가
- 이직 사유 중 가장 많은 비율은 무엇인가
- 이직 전 성과 점수 추이 패턴은 어떤가
```

### 시나리오 2 — 채용 퍼널 효율화

```
채용 데이터를 분석해서 채용 효율을 개선할 방향을 제안해줘.

분석 항목:
- 어느 단계에서 탈락률이 가장 높은가
- 채용 채널별 최종 합격률 비교
- Time-to-Hire가 가장 긴 부서는 어디인가
- 우수 인재(성과 상위 20%)의 채용 채널 특성은?
```

### 시나리오 3 — 월간 HR 리포트 자동화

```
이번 달 HR KPI를 분석하고 경영진 보고용 리포트를 작성해줘.

포함:
- 전사 이직률 (전월 대비)
- 부서별 성과 등급 분포
- 채용 진행 현황 (공고 수, 면접 수, 합격 수)
- 이직 위험 고위험 직원 현황
- 다음 달 HR 액션 플랜 3가지

reports/monthly_hr_report.md로 저장
```

---

## 핵심 정리 (30초)

HR 대시보드로 이직 패턴 발견 → 채용 퍼널 효율화 → 월간 리포트 자동화의 흐름으로 활용합니다.
Claude Code가 민감한 HR 데이터를 로컬에서 안전하게 분석하고 리포트를 자동 생성합니다.
