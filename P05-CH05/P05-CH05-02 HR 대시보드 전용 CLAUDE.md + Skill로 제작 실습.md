## 본문

### HR 전용 CLAUDE.md

```markdown
# HR 분석 대시보드

## 핵심 계산식
- 이직률 = 이직자 수 / 평균 재직자 수 × 100
- 채용 전환율 = 다음 단계 진행자 / 현재 단계 지원자 × 100
- Time-to-Hire = 채용 공고일 ~ 입사일 (영업일 기준)
- 성과 등급 기준: 점수 4.0 이상 = 우수, 2.5~3.9 = 보통, 2.4 이하 = 미흡

## 대시보드 구성
1. 채용 퍼널 차트 (단계별 전환율)
2. 부서별 이직률 히트맵
3. 성과 분포 박스 플롯
4. 이직 위험도 스코어링 테이블

## 이탈 위험 기준
- 근속 2년 이하 + 성과 하락 추이: 고위험
- 동일 직급 체류 3년 이상: 주의
- 최근 2분기 성과 점수 < 2.5: 즉각 면담 필요
```

### 대시보드 제작 실습

```
data/raw/의 employees.csv, performance.csv, attrition.csv로 HR 대시보드를 만들어줘.

포함:
1. 부서별 인원 구성 도넛 차트
2. 분기별 성과 분포 박스 플롯
3. 부서별 이직률 막대 차트
4. 이직 위험도 상위 10명 테이블 (근속, 성과 추이, 위험도 점수)

charts/hr_dashboard.html로 저장
```

## 핵심 정리 (30초)

HR 전용 CLAUDE.md에 이탈 위험 기준과 성과 등급 계산식을 정의합니다.
이직 위험도 스코어링으로 HR팀이 선제적으로 대응할 수 있습니다.
