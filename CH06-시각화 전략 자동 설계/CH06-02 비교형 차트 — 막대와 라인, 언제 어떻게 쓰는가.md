# CH06-02 비교형 차트 — 막대와 라인, 언제 어떻게 쓰는가

## 📌 클립 정보
- **예상시간:** 14분
- **유형:** 슬라이드 3장 + 화면 녹화
- **준비물:** 파이썬 (맷플롯립, 판다스), 클로드 코드

---

## 막대 차트 vs 라인 차트 — 결정 기준 (4분)

가장 많이 쓰는 두 차트입니다.
그런데 혼용하는 경우가 많습니다.

**막대 차트를 쓰는 경우:**

항목 사이의 크기를 비교할 때입니다.
항목들은 서로 독립적입니다.
순서가 의미 없거나, 알파벳·크기 순으로 정렬합니다.

예시:
- 채널별 광고비 비교 (에스엔에스, 검색, 이메일)
- 지역별 판매량 비교 (서울, 부산, 대구)
- 상품 카테고리별 매출 비교

**라인 차트를 쓰는 경우:**

시간에 따른 변화를 볼 때입니다.
엑스축의 항목들이 연속적으로 연결됩니다.
앞뒤 값의 흐름이 중요합니다.

예시:
- 월별 매출 추이 (1월→2월→3월 흐름)
- 일별 방문자 수 변화
- 분기별 전환율 트렌드

**핵심 판단 기준 한 줄:**
항목이 독립적이면 막대, 시간 순서가 있으면 라인입니다.

---

## 막대 차트 실전 — 클로드에게 지시하는 방법 (4분)

막대 차트 생성 지시 예시입니다.

> "data/campaigns.csv를 읽어서 채널별 총 광고비를 막대 차트로 그려줘. 가장 높은 채널만 진한 파랑으로 강조하고, 나머지는 연한 회색으로 표시해줘. 제목은 '채널별 광고비 비교'가 아니라 데이터에서 발견한 인사이트 한 줄로 써줘. 차트는 charts/channel_spend.png로 저장해줘."

지시 시 세 가지를 명시합니다.

먼저 강조 방식입니다. 어떤 값을 돋보이게 할지 알려줍니다.
다음으로 제목 방식입니다. 기술적 제목이 아닌 인사이트 기반 제목을 요청합니다.
세 번째로 저장 경로입니다. 어디에 저장할지 지정합니다.

---

## 라인 차트 실전 — 트렌드 시각화 (4분)

라인 차트 생성 지시 예시입니다.

> "data/monthly_sales.csv를 읽어서 월별 매출 라인 차트를 그려줘. 전월 대비 가장 많이 오른 달을 점으로 강조 표시해줘. 차트 아래에 평균선도 추가해줘. charts/monthly_trend.png로 저장해줘."

라인 차트에서 자주 쓰는 추가 요청입니다.

- 이동 평균선 추가: "7일 이동 평균선도 함께 표시해줘."
- 목표선 추가: "목표값 1억 원 기준선을 빨간 점선으로 추가해줘."
- 구간 강조: "4월부터 6월 구간을 연한 회색으로 음영 처리해줘."

## 직접 해보기

**목표**: 같은 데이터로 막대 차트와 라인 차트를 각각 생성합니다.

**준비 (터미널에 복붙)**
```bash
mkdir ~/chart-test && cd ~/chart-test
mkdir -p data charts
printf "월,채널,매출\n1월,SNS,3200000\n1월,검색,4100000\n2월,SNS,3800000\n2월,검색,3900000\n3월,SNS,4200000\n3월,검색,4300000" > data/sales.csv
claude
```

**클로드에게 이렇게 말합니다 (두 번 요청)**
```
# 요청 1: 막대 차트
data/sales.csv에서 3월 채널별 매출을 막대 차트로 그려줘.
매출이 높은 채널 파랑, 나머지 회색. charts/bar.png 저장.

# 요청 2: 라인 차트
같은 데이터로 SNS와 검색 채널의 월별 매출 트렌드를
라인 차트로 그려줘. charts/line.png 저장.
```

→ 두 차트를 비교하면서 차이를 확인합니다.

## 핵심 정리 (30초)

항목 비교는 막대, 시간 흐름은 라인입니다.
강조 방식과 인사이트 제목을 지시에 포함하면 차트 품질이 높아집니다.
같은 데이터라도 질문이 다르면 차트 유형이 달라집니다.
