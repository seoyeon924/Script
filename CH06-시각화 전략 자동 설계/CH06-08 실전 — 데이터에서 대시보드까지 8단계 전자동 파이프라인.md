## 왜 8단계가 필요한가 (3분)

"이 데이터 분석해줘"라고 지시하면 어떻게 될까요.

에이전트가 나름대로 분석을 합니다.
그런데 결과가 기대와 다를 수 있습니다.
어떤 질문에 답하려는 건지 모르기 때문입니다.
어떤 지표를 봐야 하는지 모르기 때문입니다.

**실제 상황으로 보면,**

"요리해줘"라는 지시와, "건강을 위해 채소 중심으로 단백질 30그램 이상, 칼로리 500 이하 점심을 만들어줘"라는 지시의 차이입니다.
에이전트에게도 목적과 기준을 명확히 전달해야 좋은 결과가 나옵니다.

8단계 파이프라인은 이 구조를 시스템화합니다.
에이전트에게 매번 설명하지 않아도 됩니다.
CLAUDE.md에 한 번 정의하면 모든 분석에 자동으로 적용됩니다.

---

## 8단계 파이프라인 구조 (4분)

**[화면: 파이프라인 도식]**

```
① 문제 정의
   "이 데이터로 무엇을 알아야 하는가?"
        ↓
② 데이터 전처리
   결측값 처리 / 형식 통일 / 이상치 제거
        ↓
③ 지표 설계
   분석에 사용할 KPI와 계산 방식 정의
        ↓
④ 방법론 선택
   어떤 분석 기법을 사용하는가
        ↓
⑤ 인사이트 도출
   데이터에서 발견한 패턴과 의미 해석
        ↓
⑥ 데이터 시각화
   인사이트를 차트로 표현
        ↓
⑦ 대시보드 생성
   여러 시각화를 하나의 화면으로 구성
        ↓
⑧ 보고서 생성
   분석 과정과 결과를 문서화
```

각 단계를 하나씩 설명합니다.

**① 문제 정의**
가장 먼저 "이 분석이 어떤 질문에 답하는가"를 명확히 합니다.
예: "지난 분기 광고비 대비 전환율이 가장 높은 채널은 어디인가?"

**② 데이터 전처리**
원본 데이터는 항상 오류가 있습니다.
결측값이 있는 행 처리, 날짜 형식 통일, 이상치 탐지 및 처리를 합니다.

**③ 지표 설계**
분석에 쓸 지표와 계산 공식을 정의합니다.
예: 알오아이 = (매출 - 광고비) / 광고비 × 100

**④ 방법론 선택**
어떤 분석 기법을 쓸지 결정합니다.
예: 채널별 집계, 시계열 분석, 코호트 분석, 에이비 테스트

**⑤ 인사이트 도출**
숫자를 해석합니다.
"알오아이가 가장 높은 채널은 에스엔에스, 가장 낮은 채널은 디스플레이"처럼 의미 있는 문장으로 표현합니다.

**⑥ 데이터 시각화**
인사이트를 뒷받침하는 차트를 생성합니다.
차트 유형은 CLAUDE.md의 시각화 규칙에 따라 자동 선택합니다.

**⑦ 대시보드 생성**
여러 차트를 하나의 에이치티엠엘 파일로 묶습니다.
인터랙티브 필터와 요약 지표(케이피아이 카드)를 포함합니다.

**⑧ 보고서 생성**
분석 과정 전체를 마크다운 문서로 정리합니다.
배경, 방법론, 결과, 결론, 다음 단계 권고사항을 포함합니다.

## CLAUDE.md — 파이프라인 템플릿 정의 (3분)

이 8단계를 CLAUDE.md에 한 번 작성해두면 이후 모든 분석에 자동 적용됩니다.

```markdown
## 데이터 분석 파이프라인 (8단계)

새 데이터 분석 요청을 받으면 반드시 아래 순서를 따릅니다.

### ① 문제 정의
- 분석 목적을 한 문장으로 명시합니다
- 핵심 질문 3개를 도출합니다

### ② 데이터 전처리
- data/raw/ 파일을 읽고 구조를 파악합니다 (수정 금지)
- 결측값: 수치는 평균 대체, 카테고리는 'Unknown' 처리
- 날짜: YYYY-MM-DD 형식으로 통일
- 이상치: IQR 1.5배 이상은 플래그 처리 후 분석자 판단
- 전처리된 데이터를 data/processed/ 에 저장합니다

### ③ 지표 설계
- 주요 KPI와 계산 공식을 명시합니다
- 예: 알오아이 = (매출 - 광고비) / 광고비 × 100

### ④ 방법론
- 분석 기법을 선택하고 이유를 한 줄로 설명합니다
- 집계 / 시계열 / 코호트 / 상관관계 / 에이비 테스트 중 선택

### ⑤ 인사이트 도출
- 발견한 패턴을 사실 기반으로 서술합니다
- "~로 보입니다" 대신 "~입니다" 형식 사용
- 인사이트는 최소 3개, 최대 7개 도출합니다

### ⑥ 데이터 시각화
- 인사이트별 차트를 생성합니다
- 차트 유형: 시각화 규칙 섹션 참고
- 저장 위치: charts/ 폴더

### ⑦ 대시보드
- 플롯리로 인터랙티브 대시보드를 생성합니다
- 상단: KPI 카드 (핵심 지표 3~5개)
- 본문: 차트 2~3개
- 저장: charts/dashboard.html

### ⑧ 보고서
- 마크다운으로 분석 보고서를 작성합니다
- 구성: 배경 → 방법론 → 주요 결과 → 인사이트 → 권고사항
- 저장: reports/analysis_report.md
```

## 핵심 정리 (30초)

8단계 파이프라인은 문제 정의 → 전처리 → 지표 설계 → 방법론 → 인사이트 → 시각화 → 대시보드 → 보고서 순서입니다.
이 구조를 CLAUDE.md에 정의하면 에이전트가 매번 자동으로 따릅니다.
새 데이터가 들어올 때마다 목적만 알려주면 나머지는 에이전트가 처리합니다.
