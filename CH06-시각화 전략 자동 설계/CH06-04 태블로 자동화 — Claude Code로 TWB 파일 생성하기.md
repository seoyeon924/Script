# CH06-04 태블로 자동화 — Claude Code로 TWB 파일 생성하기

## 📌 클립 정보
- **예상시간:** 14분
- **유형:** 슬라이드 2장 + 화면 녹화
- **준비물:** 태블로 퍼블릭 또는 태블로 데스크톱, 클로드 코드

---

## 태블로 자동화의 원리 (4분)

태블로 워크북 파일(.twb)은 엑스엠엘(XML) 형식입니다.
텍스트 편집기로 열면 사람이 읽을 수 있는 구조입니다.

이것이 자동화의 핵심입니다.

**쉽게 보면,**

레고 설명서가 있으면 그대로 조립하면 됩니다.
태블로 워크북도 설계 구조가 문서화되어 있습니다.
클로드 코드가 이 구조를 분석하고, 새 데이터에 맞게 엑스엠엘을 생성합니다.

태블로 자동화 흐름입니다.

```
씨에스브이 데이터
    ↓
클로드 코드 (데이터 구조 분석)
    ↓
TWB 파일 생성 (XML 작성)
    ↓
태블로에서 열기
```

---

## 태블로 XML 구조 이해 (3분)

태블로 워크북의 주요 구성 요소입니다.

```xml
<workbook>
  <datasources>
    <!-- 데이터 소스 정의 -->
    <datasource name="campaigns">
      <connection class="textscan" filename="campaigns.csv" />
    </datasource>
  </datasources>
  <worksheets>
    <!-- 시트(차트) 정의 -->
    <worksheet name="채널별 매출">
      <table>
        <view>
          <!-- 행: 채널, 열: 매출 -->
          <dimensions-used>...</dimensions-used>
          <measures-used>...</measures-used>
        </view>
      </table>
    </worksheet>
  </worksheets>
</workbook>
```

클로드 코드에게 이 구조를 설명하고 자동 생성을 요청합니다.

---

## 실전 — 태블로 워크북 자동 생성 지시 (5분)

클로드에게 이렇게 지시합니다.

> "data/campaigns.csv를 분석해서 태블로 워크북 파일을 생성해줘. 시트 3개를 만들어줘. 첫 번째 시트: 채널별 총 매출 막대 차트. 두 번째 시트: 월별 매출 트렌드 라인 차트. 세 번째 시트: 채널별 알오아이 비교. 파일을 charts/analysis.twb로 저장해줘."

에이전트가 씨에스브이 구조를 파악하고, 각 시트에 맞는 엑스엠엘 구조를 작성합니다.

생성된 파일을 태블로에서 바로 열 수 있습니다.

---

## 태블로 템플릿 재활용 전략 (1분)

기존 워크북을 템플릿으로 활용하는 방법도 있습니다.

기존에 잘 만들어진 태블로 대시보드가 있다면, 그 파일을 클로드에게 전달합니다.

> "기존 analysis_template.twb 파일을 참고해서, 새 데이터 campaigns_2024.csv에 맞게 수정한 워크북을 생성해줘. 색상과 레이아웃은 기존 템플릿과 동일하게 유지해줘."

에이전트가 기존 구조를 분석하고 새 데이터에 맞게 재작성합니다.
디자인 일관성을 유지하면서 새 데이터를 적용합니다.

## 직접 해보기

**목표**: 씨에스브이 데이터를 기반으로 태블로 워크북 파일을 자동 생성합니다.

**준비 (터미널에 복붙)**
```bash
cd ~/chart-test
claude
```

**클로드에게 이렇게 말합니다**
```
data/sales.csv를 분석해서 태블로 TWB 파일을 생성해줘.
- 데이터 소스: data/sales.csv (상대 경로)
- 시트 1: 월별 매출 라인 차트 (X축: 월, Y축: 매출)
- 시트 2: 채널별 매출 막대 차트 (X축: 채널, Y축: 매출)
charts/dashboard.twb로 저장해줘.
```

→ 생성된 .twb 파일을 태블로 퍼블릭에서 열어서 확인합니다.

## 핵심 정리 (30초)

태블로 워크북은 엑스엠엘 구조이기 때문에 클로드 코드가 텍스트 파일로 생성할 수 있습니다.
씨에스브이와 요구 사항을 주면 에이전트가 워크북을 자동으로 작성합니다.
기존 템플릿을 참고해서 새 데이터에 맞게 재작성하는 방식도 효과적입니다.
